# Wet combat Foley

Original recordings by Spring Spring (Julie Damsgaard), from [Various Sound Effects on OpenGameArt](https://opengameart.org/content/various-sound-effects-0). The source page labels these files CC0. Downloaded 2026-09-26; the six original WAV files are kept here for reproducible processing.

Used files: `snd_splathit.wav`, `snd_splat.wav`, `snd_splurt.wav`, `snd_bulletcrackle.wav`, `snd_yoghurtblast.wav`, `dull_explosion.wav`.

`scripts/layer-wet-combat-sfx.mjs` cuts, filters, and layers short excerpts over the existing dry combat stems. The output files are in `assets/audio/sfx/clear/`. UI and magic-stone sounds do not use these recordings.
