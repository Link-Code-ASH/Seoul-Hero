# 빈손 SD 캐릭터 원화 작업

- 이 폴더에서 플레이어·인간형 NPC·각성자 원화를 제작하거나 수정하기 전에 [CHARACTER_GUIDE.md](CHARACTER_GUIDE.md)를 읽는다. 송진우 실파일의 실제 몸·얼굴 각도, 카메라와 눈 방향을 그대로 기준으로 삼는다. 정면에 가까운 부드러운 3/4에서 살짝 우하단을 보게 하며 강한 옆얼굴이나 오른쪽 끝으로 몰린 동공은 피한다.
- 인물별 현대 서울 일상 콘셉트를 먼저 정하고 승인된 계획에 따라 내장 이미지 생성 도구로 제작한다. 실제 결과를 직접 보고 눈맞춤·안경·모자의 눈 가림을 확인한다.
- 원본 PNG와 전체 프롬프트·출처·수정 기록을 보존한다. 새 원화는 별도 이름이나 제작 묶음 폴더에 저장한다. 방향 수정 전 원본은 `revisions/v01/` 등에 보존한 뒤 대표 파일에 수정본을 연결한다.
- 원화 제작 승인과 게임 런타임 연결 범위를 구분한다. 이번 승인 묶음은 [seoul-civilians-01 계획](../../design/characters-sd/seoul-civilians-01/PLAN.md)의 신규 원화 10명이며, 저장 목적지는 `seoul-civilians-01/`이다.
