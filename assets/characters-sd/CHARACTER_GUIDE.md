# 서울 히어로 빈손 SD 캐릭터 제작 방법

작성일: 2026-10-12. 플레이어·인간형 NPC·각성자 원화를 새로 만들거나 고칠 때 이 문서를 먼저 읽는다. 런타임 공용 모션과 연결 방법은 [SD_PIPELINE.md](../../godot/docs/SD_PIPELINE.md)를 함께 따른다.

## 기준 원화

[song_sd_01.png](song_sd_01.png)는 송진우의 현행 빈손 SD 원화다. 생성에 실파일을 참조 이미지로 제공하고 **그림체·비율·외곽선·셀 채색·실제 몸과 얼굴의 회전각·카메라·눈 방향**의 기준이라고 명시한다. 방향은 텍스트로 더 강하게 돌리지 말고 송진우 실파일과 같게 맞춘다. 신규 인물에게 송진우의 얼굴·검정 헝클어진 머리·파란 재킷·전술 끈·다이아몬드 장식을 복제하지 않는다. 옛 전투 원화나 art-library의 인물은 생활복 아이디어와 정체성 참고에만 사용한다.

현역은 기존 송진우·강태훈·박도준과 신규 10명을 합친 플레이어 13명, 길드 NPC 한서아 1명이다. 모두 단일 빈손 PNG와 공용 SD 모션을 사용한다. 윤하린은 개성이 약하다는 사용자 판단으로 2026-10-12 퇴역했다. 과거 생성 출처와 퇴역 기록은 이력으로 보존하며 신규 인물의 기준으로 재사용하지 않는다.

## 형태와 출력

- 머리카락을 포함한 머리는 전신 높이의 약 **60%**, 전체는 약 **1.7등신**이다. 몸통은 작고 팔다리는 아주 짧다.
- 짧은 두 팔을 몸 옆에 편안하게 두고 **두 빈손을 보이게** 한다. 작은 신발 두 개가 분리되며 밑창 높이가 같아야 한다.
- 굵고 둥근 짙은 외곽선, 큰 색면, 단순한 셀 채색과 절제된 하이라이트를 사용한다. 옷 주름과 작은 장식은 줄인다.
- 인물별 **전신 투명 PNG 한 장**을 만든다. 머리와 두 신발이 잘리지 않게 사방 여백을 남긴다. 알파가 실제 투명해야 하며 바닥 그림자·발광 배경·후광은 그리지 않는다.
- 무기·공구·책·휴대전화·상품·상자 등 손에 든 소품과 캐릭터 주변 부유 장비를 넣지 않는다. 직업은 머리·얼굴·옷의 큰 형태와 색으로 표현한다.
- 프레임 시트·여러 시점·부위 파츠·개별 공격 포즈는 만들지 않는다. 본체 공용 최소 모션과 공격 투사체/VFX는 기존 런타임 구조를 사용한다.

## 몸·머리·동공의 방향

방향의 최우선 기준은 **송진우 실파일의 실제 각도와 눈 방향**이다. 정면에 가까운 부드러운 3/4에서 살짝 화면 우하단을 보는 정도로 맞춘다. 몸과 얼굴을 대각선 남동쪽으로 강하게 돌리거나 먼 쪽 눈을 일부러 좁히지 않는다.

1. 몸은 송진우와 같은 약한 회전각의 편안한 대기 자세다. 카메라 높이와 보이는 앞면의 비율도 기준 원화에 맞춘다.
2. 머리는 정면에 가까운 부드러운 3/4다. 얼굴과 양눈이 넓게 보이게 하고, 강한 옆얼굴·과도하게 좁아진 먼 쪽 눈·깊이 숙인 머리는 피한다.
3. 동공은 송진우처럼 살짝 아래로 향한다. 두 눈이 같은 지점을 보되 홍채를 오른쪽 끝으로 몰지 않는다. 관객이나 카메라와 눈을 맞추지 않는다.

카메라를 보는 동공, 과도한 옆얼굴, 오른쪽 끝으로 쏠린 홍채, 몸·머리 방향 불일치, 서로 다른 곳을 보는 두 눈은 채택하지 않는다. 안경은 투명 렌즈로 동공이 읽혀야 하고, 모자 챙과 앞머리는 두 눈을 가리지 않아야 한다. 생성 설명이 맞더라도 실제 그림에서 눈맞춤이나 송진우보다 강한 옆보기 방향이 보이면 수정한다.

**2026-10-12 사용자 피드백:** 첫 10명은 송진우보다 너무 옆쪽을 봤다. `LOWER RIGHT / southeast`, `farther eye narrower`, 오른쪽으로 치우친 홍채를 강조하는 지시는 이 오차를 키울 수 있으므로 철회한다. 송진우 실파일과 나란히 보며 실제 회전각과 양눈의 노출 정도를 먼저 비교한다.

## 개성 설계

각성 전 현대 서울에서 볼 수 있는 일상부터 정한다. 이름·나이·직업·성격·얼굴 표정·머리 실루엣·복장 큰 형태·주색을 짧게 기록하고, 여러 명을 만들 때 서로 비슷해지는 조합을 비교한다. 개성은 직업 소품이나 전투 장비보다 **머리 실루엣 + 상의 형태 + 색 조합**으로 먼저 읽히게 한다. 작은 장식은 1~2개로 제한한다. 성별과 나이는 눈썹·볼·헤어·작은 얼굴 선으로 표현하며 공통 SD 신체 비율을 유지한다.

승인한 첫 신규 묶음의 10명 콘셉트와 송진우 분석은 [seoul-civilians-01/PLAN.md](../../design/characters-sd/seoul-civilians-01/PLAN.md)에 있다. 같은 계획서의 **생성용 공통 프롬프트 초안**에 인물별 외모·일상복·색·표정을 더한다. 해당 초안은 출발점이며 실제 생성에 사용한 전체 프롬프트는 별도로 저장한다.

## 제작과 확인 순서

1. 승인된 콘셉트와 수량, 저장 목적지, 송진우 참조 역할을 확인한다. 내장 `image_gen` 도구로 **인물별 한 장씩** 생성하고 투명 배경을 요청한다.
2. 여러 명을 만들 때는 **맨얼굴·안경·모자 조건의 3명**을 먼저 만든다. 이번 묶음은 정민석·이소민·오지은이다. 실제 결과를 직접 보고 방향·동공·비율을 확인한 뒤 같은 기준으로 나머지를 이어간다. 이미 승인된 수량을 제작하는 중간에 반복 승인 요청을 만들지 않는다.
3. 큰 크기와 전투에 가까운 높이 약 45px에서 송진우와 비교한다. 얼굴·동공 방향, 두 빈손, 짧은 팔다리, 두 신발, 인물별 실루엣을 본다. 밝은·어두운 배경으로 실제 알파와 가장자리도 확인한다. 이 확인은 원화 검토이며 게임 플레이 QA를 뜻하지 않는다.
4. 시선이나 형태가 틀리면 내장 이미지 도구에 수정 대상과 송진우 실파일을 제공하고 바꿀 요소와 유지할 요소를 명시한다. 수정 전 원본과 이력은 `revisions/v01/` 등에 보존하고, 최종 대표 PNG에는 확인한 수정본을 연결한다. 이미지 편집을 임의의 코드 처리로 대체하지 않는다.
5. 최종 개별 PNG, 비교 갤러리, 실제 전체 프롬프트와 생성 출처·참조 역할·수정 이력·파일명을 저장한다. 요청 수량과 최종 파일 수를 맞추고, 생성 중인 파일을 완료로 기록하지 않는다.

## 저장과 승인 경계

이번 10명은 `assets/characters-sd/seoul-civilians-01/`에 저장한다. 파일명은 승인 계획의 `lee_somin_sd_01.png` 등 인물별 이름을 사용한다. 같은 폴더의 `prompts/`와 `provenance.json`에 실제 생성 기록을 두고, 비교 갤러리는 `design/characters-sd/seoul-civilians-01/`에 둔다.

2026-10-12 최초 승인은 **10명 콘셉트에 따른 원화 제작·지정 폴더 저장·비교 갤러리**에 대한 제작 허가였다. 사용자 방향 피드백을 반영한 수정본 v02 10명을 제작한 뒤, 후속 요청으로 이름·배경·고유 능력까지 게임에 연결했다. 최초 원화는 `revisions/v01/`에 보존하며 수정본 실제 프롬프트는 `prompts/<id>-v02.txt`에 있다.

신규 10명은 기본 해금되어 기존 저장에서도 바로 선택할 수 있다. 강태훈·박도준의 기존 Godot 뽑기 정책은 유지한다. [src/data/characters/index.ts](../../src/data/characters/index.ts)가 이름·배경·능력 원본이며, 기존 선택·전투·성장·자료집·아바타·조각 목록에 데이터로 연결한다. 고유 패시브는 기존 20스탯과 설치물 무기 피해 조건을 사용하고 별도 무기나 리그를 추가하지 않는다. 게임 플레이와 밸런스 QA는 사용자가 담당한다.
