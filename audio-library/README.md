# 서울 히어로 사운드 라이브러리

450개 편집본: UI 60 / 무기 120 / 적중·폭발 90 / 마법 70 / 적·경고 60 / 환경 루프 50.

`index.html`을 브라우저에서 열면 검색·필터·청음이 가능하다. 파일 URL을 제한하는 환경에서는 저장소 루트에서 실행한다.

```sh
python -m http.server 4175 --bind 127.0.0.1 --directory audio-library
```

그 뒤 `http://127.0.0.1:4175/`를 연다. 페이지 진입 시 오디오를 다운로드하지 않고 클릭한 소리만 로드한다. 선택한 효과음의 주 재료·보조 질감을 각각 비교할 수 있다. 원본 미리듣기는 사용 구간에 샘플레이트 변환, 안전 음량, 끝단 페이드만 적용했다.

## 산출물

- `sounds/`: 48kHz/16bit WAV 완성본 450개. 단발 모노, 8초 환경 루프 스테레오.
- `source-previews/`: 선택한 원본 구간 비교용 WAV. 전체 원본을 복사하지 않는다.
- `comparisons/`: 발사·적중 시차, 전투음 겹침·경고, UI 순서 샘플과 재현 이벤트 목록.
- `inventory.json`: 원본 WAV 346개 분석과 SHA-256. 선택하지 않은 원본도 포함한다.
- `manifest.json`: 출력별 사용 구간, 원본 SHA-256, 레이어·처리 설정, 출력 해시, 게임 적용 여부.
- `game-mapping.json`: 기존 게임 SFX 30종에 연결된 94개 파일.
- `verification.json`: 제작 파일 확인 수치와 미검증 범위.
- `provenance/`: 원본 번들에 동봉된 라이선스·Readme 사본. 원본 녹음 저작자 정보는 팩 이름과 원본 경로로 보존한다.

## 재제작

Python 3.12 + NumPy. `scripts/audio-library/recipes.py`에서 용도별 소스와 길이·음역을 정하고 아래를 실행한다.

```sh
python scripts/audio-library/build.py build --source "C:\Users\geniu\Music"
```

게임 연결도 함께 생성한다. `src/data/audio.ts`의 gain·반복 제한은 수동으로 관리한다. 단순 음량·피치 변경으로 파일 수를 늘리는 대신 다른 원본·동작 구간·레이어 조합을 사용한다. 긴 원본의 구간 선택은 에너지 변화에 기반하므로 청취 후 시작점이나 질감을 조정할 여지가 있다.

이 폴더는 게임 제작용 작업 라이브러리이며 게임 번들에 포함하지 않는다. 실제 적용본만 `assets/audio/sfx/sourced/`에 복사한다. 소스 번들과 이전 생성 출처는 수정하지 않는다.

**청취 평가 대기:** 파일 분석과 편집 결과이며, 제작 에이전트가 실제 소리를 듣거나 게임을 플레이한 결과가 아니다. 사용자 청취를 통해 개별 음색과 믹스를 평가한다. 비교 샘플도 게임의 AudioPolicy나 BGM까지 재현한 녹음은 아니다.
