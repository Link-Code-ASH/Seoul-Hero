# Premium UI v5

Read-only design prototype. Production game code, navigation and saves are untouched.

- Five independent background scenes and six independently randomized atmosphere modes: rain, wind, energy, snow, mist, embers. Background names rain/wind/energy are legacy asset filenames and do not determine the atmosphere.
- Preview selectors allow each scene/effect to be inspected independently via scene/effect URL parameters.
- Facility objects sit over a soft alpha diffusion material, without individual surrounding frames.
- Generated material images cover the top controls and the new operation deployment button. Deployment object is modern field equipment, not a fantasy portal. Label: 작전 투입.
- Archive details use Features / Common growth / Branch A / Branch B tabs. Growth rows page in groups of three; detail areas never scroll. Only the weapon name list scrolls.
- Gameplay data remains the source of numerical values. Editorial flavor lines are mockup proposals.

Assets: built-in image_gen. Full prompts and source paths in assets/generated-v5.json; reused v4 and v3 provenance retained. Motion respects reduced-motion and hidden document state.

No gameplay testing or physical mobile device verification.
