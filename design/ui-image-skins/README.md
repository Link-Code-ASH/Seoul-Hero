# 서울 히어로 이미지 UI A/B 시안

2026-10-02 · 915×412 · 게임 적용 전 검토용

이번 작업은 타이틀·로비·게이트24 상점의 A/B 시안 6개입니다. 전투 규칙·저장·런타임 UI·콘텐츠 manifest는 연결하지 않습니다. 배경·캐릭터·상품은 기존 원화를 읽고, 프레임과 버튼은 built-in imagegen으로 만든 PNG를 사용합니다. 글자는 실제 TTF로 렌더링합니다.

| --- | --- | --- | --- | --- | --- |
| A | 에나멜·유리 / 아이보리·청회색·청록·주황 | SF 싸락눈 | 성곡 명조 | Paperlogy | Barlow Condensed |
| B | 채색 테두리 / 크림·남색·보라·금색 | BMJUA | 해옹산스 | Paperlogy | Barlow Condensed |

`index.html`은 6개 이미지를 나란히 비교하는 갤러리입니다. `screenshots/`에 915×412 원본, `assets/`에 PNG 아틀라스, `skins.json`에 각 원본 영역·9분할 모서리·안전 여백을 보존합니다. 원본 1536×1024 PNG는 모서리와 테두리를 4배 소스 샘플링으로 표시하고 중간 면만 9분할합니다. `PROMPTS.md`와 `provenance.json`은 생성 출처, `fonts/README.md`는 실제 폰트 역할·출처를 기록합니다.

프레임은 제작한 이미지가 기본입니다. SVG·코드 프레임이나 평면 박스의 광택으로 대체하지 않습니다. 설명 중앙 면은 조용하게 두고 제목·버튼·테두리에 재질을 집중합니다. 제목에는 공용 아이콘을 넣지 않습니다.

사용자가 방향을 명시적으로 승인한 뒤 게임의 9분할 소재와 나머지 화면에 연결합니다. 이 시안 폴더만으로 적용하지 않습니다.

확인 범위와 미확인 항목은 QA.md, 실제 글꼴 맞춤 진단은 screenshots/layout.json에 보존합니다.

## 사용자 피드백 반영 조합

C 수정 시안은 B의 폰트·색감에 A의 나사형 프레임을 조합합니다. 기존 A/B 원본과 캡처는 유지합니다. 로비의 공통 받침을 제거하고 시설 5개를 각각 테두리 없는 옅은 유리 표면으로 구분합니다. 추가 PNG는 hybrid-buttons.png와 lobby-glass.png이며 프롬프트와 출처를 같은 기록에 추가했습니다. c 시안도 게임 런타임에 연결하지 않았습니다.

## 적용 완료

사용자가 C안을 명시적으로 승인해 Godot 타이틀·로비·상점에 구현했습니다. 실제 캡처는 godot/exports/image-skin-c에 있으며 다른 화면은 phase2 시안으로만 제시합니다. 상단의 A/B/C preview-only 설명은 당시 시안 제작 범위에 대한 기록입니다. 현재 연결 책임과 범위는 godot/docs/UI_GUIDE.md를 따릅니다.
