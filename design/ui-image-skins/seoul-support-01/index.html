사용한 PNG와 제작 기록

아래는 실제 화면에서 사용한 분리 PNG입니다. 기능 글자는 이미지에 구워 넣지 않고 Godot에서 렌더링했습니다.

배경 생성 원본은 1919×820·1866×843으로 약 2배 해상도입니다. 요청한 4배 배경 원본에는 미달하며, 3660×1648 합성 마스터와 구분해 보존했습니다. 분리 장치와 정보판은 실제 표시 원화 크기의 4배 이상입니다.

원본·표시 크기·안전 영역 · 제작 프롬프트·출처 · 915×412 런타임 캡처·수명 확인 · 4배 런타임 캡처 확인

정적 화면 7장·움직임 5개·네이티브 프레임 330장. 915×412 배치 확인 12개와 4배 배치 확인 7개에서 누락 원화·텍스트 배치 오류가 없으며 메뉴 순간 입자는 최대 12개입니다. 중복 요청·숨김·화면 이탈 등 해당 UI 수명 확인 12개를 검토용 콜백으로 확인했습니다. 원본 프레임을 덧그리거나 보정하지 않고 무손실 WebP로 묶었습니다. 실제 저장·지급·추첨은 캡처에서 차단했습니다. 전체 테스트·전투 플레이·모바일 터치·실기기·성능·청감 검사는 수행하지 않았습니다.
