- 상점은 실제 불사 성냥96·금고 장부48·보복 퓨즈52·전술 발목 보호대19를 4개 한 줄로 표시한다. 복합 효과·패널티·긴 이름·보유/상한·잠금·재화 부족을 유지한다. 잠긴 금고 장부는 구매 가능 상태를 유지한다.
- 실제 본문/상태 글자 최소14px, 구매·잠금 영역44px. 실제 Font 메트릭과 할당된 Label 영역을 screenshots/layout.json에 기록했다.
- 프레임 테두리가 로비 메뉴 이름·보유 아이템을 덮는 첫 캡처 문제를 수정했다. B안 중간 장식은 imagegen으로 제거하고 코너 원본 분할 영역을 늘려 모서리 비율을 보존했다.
- 여섯 최종 PNG를 원본 크기로 직접 보고 문구 잘림·겹침·정렬·이미지 선명도를 확인했다.

필요한 독립 시안 스크립트 오류 확인 및 캡처만 수행했다. render.log의 shader-cache 경로·Windows 인증서 저장소 메시지는 캡처를 막지 않았으며 스크립트·폰트·이미지 로드 오류는 없었다.

실제 플레이·터치·청감·환경 애니메이션 동작·다른 화면 크기·전체 테스트·빌드·성능 검사는 수행하지 않았다. 현재 산출물은 승인 전 시안이다. 사용자가 방향을 명시적으로 컨펌한 뒤 9분할 런타임 연결을 진행한다.

## B 디자인 + A 프레임 수정 시안

사용자 피드백에 따라 B의 BMJUA·해옹산스·보라 강조와 A의 나사형 PNG 프레임을 조합했다. 추가 버튼 원화와 테두리 없는 유리 원화는 built-in imagegen으로 제작했고 원본/프롬프트/출처를 보존했다. 기존 6개 A/B PNG와 layout.json은 변경하지 않았다.

C 타이틀·로비·상점은 915×412, 본문 최소14px, 글자 맞춤 진단0건이다. 로비 공통 프레임은 제거하고 5개의 독립 유리 표면을 배치했다. PNG 원본 알파에 표시 불투명도0.28을 적용해 옅은 글래스모피즘으로 표현했으며 배경 흐림도 해당 표면 안에서만 적용했다. 모든 기능 글자는 실제 폰트이다. layout-c.json과 render-c.log에 확인 근거를 보존한다.

게임·저장·콘텐츠 데이터는 연결하지 않았다. 이번 수정도 정적 시안과 필요한 스크립트 오류만 확인했으며 실제 플레이·터치·전체 테스트·빌드는 수행하지 않았다.
