# 로비 메뉴 아이콘 · Office Day 01

2026-10-10 제작. 밝은 각성자 협회 사무실 로비용 아이콘 7종이다. 기존 상위 폴더의 크림 카드·주황/민트 버튼과 색감 및 부드러운 입체 표현을 맞췄다.

## 파일

모든 개별 아이콘은 **512×512, 8bit RGBA PNG**다. 피사체를 중앙 최대 408×408px(약 80%) 안에 배치하고 각 방향에 최소 52px의 투명 여백을 확보했다. 9-slice를 사용하지 않고 비율을 유지해 축소한다.

| 파일 | 내용 | 42px 육안 확인 |
|---|---|---|
| icon_association.png | 민트 리본과 사원증 클립이 달린 남색 방패 배지 | 방패·리본 구분 |
| icon_archive.png | 포스트잇과 클립이 꽂힌 남색 바인더 | 바인더와 종이 면 구분 |
| icon_settings.png | 크림 톱니바퀴와 렌치 | 톱니와 대각선 도구 구분 |
| icon_deploy_gate.png | 연보라 게이트와 주황 출동 화살표 | 차원문·화살표 식별, 60px에서 더 선명 |
| icon_sound_on.png | 남색 스피커와 민트 음파 두 줄 | 스피커·음파 식별 |
| icon_sound_off.png | 같은 스피커와 산호색 X | ON과 OFF 명확히 구분 |
| icon_operator_headset.png | 크림/남색 헤드셋·마이크·빨간 램프 | 헤드셋·마이크 식별, 램프는 미세한 색 포인트 |

소리 꺼짐은 켜짐 원화의 음파만 X로 바꾸는 이미지 편집으로 만들었다. 두 출력은 같은 원본 추출 영역과 같은 축소·배치 값을 사용하여 상태 전환 시 스피커 크기와 위치가 유지되도록 했다.

## 모음과 작은 크기 검수

- `contact_sheet.png`: 1200×870. 기본 바탕 **#FBF6EC**, 아이콘 7종과 파일명, 기존 크림 원형 버튼 위 42px 축소본을 모았다.
- 같은 모음 오른쪽 아래에 **#FF9A4D** 주황 바탕의 출동 아이콘을 추가했다. 아래쪽에는 기존 크림 버튼 위 42px 전체 세트와 주황 바탕 위 출동 60px도 실었다.
- `_raw/preview_42px.png`: 800×150. 확대 없이 직접 확인하기 위한 42px 검수 스트립이다. 번호 1~7은 위 표 순서다.
- 원화와 최종 모음, 42px 스트립을 직접 열어 확인했다. 작은 크기에서는 질감과 클립 같은 미세 장식보다 방패·바인더·톱니·게이트·스피커·헤드셋의 큰 형태가 우선 읽힌다.
- 출동 화살표는 크림 전면과 남색 측면이 주황 바탕에서 분리된다. 검수 모음의 글자와 번호는 안내 라벨이며 개별 아이콘에는 없다.

## 검수 결과

- **7/7**: 지정 파일명, 512×512 크기, RGBA 형식 확인.
- **7/7**: 실제 alpha=0 배경과 중간 alpha 픽셀 존재, 네 가장자리의 모든 픽셀 alpha=0 확인. 가짜 체크무늬 없음.
- **7/7**: 글자·숫자·로고 없음. 산호색 X는 요청된 음소거 기호다.
- 실루엣을 따라 그린 외곽선은 없으며, 밝은 가장자리와 남색 측면은 재질의 면·명암 표현이다.
- 크기·배치·알파 픽셀 수·SHA-256은 `_raw/validation.json`에 기록했다.
- 이 검수는 생성 소재 및 축소 합성 이미지 기준이다. Godot 런타임 연결이나 실제 모바일 화면 테스트는 수행하지 않았다.

## 생성 출처와 재출력

OpenAI **내장 image_gen**으로 생성했다. CLI 이미지 생성이나 SVG 대체물을 사용하지 않았다.

- `_raw/manifest.json`: 각 파일의 최종 생성/편집 프롬프트와 생성 원본 경로.
- `_raw/icon_*.png`: 생성 원본 보존.
- `_raw/export.ps1`: 원본의 투명 여백을 정리하고 비율을 유지해 중앙 408px 안에 리샘플링한 출력 및 검수 모음 생성 스크립트.
- 상위 폴더의 `button_round_normal.png`는 검수 모음의 배치 참고에만 사용했으며 개별 아이콘 PNG에는 합성하지 않았다.
