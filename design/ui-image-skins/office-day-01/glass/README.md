유리판 7종의 내부는 실제 반투명이다. 일반 상태는 140~150/255(약 55~59%), 눌림은 정확히 +15인 155~165/255(약 61~65%)다. 외부는 alpha=0이며 외부 그림자가 없다. 실루엣에 걸친 1px 안티앨리어싱 픽셀은 면적 커버리지에 따라 내부보다 알파가 낮다. 꺾쇠는 유리판이 아닌 독립 표시 조각으로, 밝은 부분은 alpha=255까지 사용한다.

## 윤곽과 배치

좌표는 최종 원본 PNG 기준이며 원점은 왼쪽 위다.

- 메뉴 일반/호버 꼭짓점: (28,4), (448,4), (424,93), (4,93). 상단을 오른쪽으로 **24px** 민 평행사변형이다.
- 출동 일반 꼭짓점: (40,4), (520,4), (484,209), (4,209). 상단을 오른쪽으로 **36px** 민 평행사변형이다.
- 원형 일반: 중심 (56,54), 반지름 50px.
- 눌림은 동일 캔버스에서 위 윤곽과 원화를 **y+3px** 이동한다. 눌림 이동과 “동일 윤곽” 요구를 함께 반영한 것으로, 이동 보정 후 윤곽은 완전히 같다.
- 메뉴 아이콘 안전 영역: (42,10,76,76). 민트 막대는 x≈130에 세로 정렬했다. 제목 권장 영역: (150,18,225,60). 오른쪽 끝은 비워 두었다.
- 출동 아이콘 안전 영역: (56,30,150,150). 제목 권장 영역: (228,45,215,95). 민트 그라데이션과 하단 빛줄을 제외하면 빈 유리다.
- 눌림에 텍스트·아이콘을 함께 맞추려면 게임에서도 해당 콘텐츠만 y+3px 이동한다. PNG에는 글자나 기능 아이콘이 없다.

1830×474px 비교판이다. 양쪽 모두 9종 전체를 같은 위치와 75% 크기로 합성했다.

1. 왼쪽: 프로젝트의 `godot/assets/ui/office-day-01/lobby_office_bg_soft.png`를 **915×412**로 축소한 실제 게임 배경.
2. 오른쪽: **#FBF6EC** 밝은 크림 바탕, 동일한 915×412 비교 영역.

상단 48px은 배경 이름을 적은 검수용 머리글이다. 소재별 라벨 역시 비교판에만 있고 개별 PNG에는 없다. 이는 조각 비교판이며 실제 로비 배치 시안이나 런타임 캡처는 아니다.

## 검수 결과

- **9/9** 파일명·크기·RGBA 확인.
- **9/9** 실제 alpha=0 픽셀 존재, 네 가장자리 전체 alpha=0. 가짜 체크무늬 없음.
- 유리판 7종 내부 alpha 범위 충족. 경계 안티앨리어싱을 제외하고 모든 대응 내부 픽셀에서 눌림 alpha 차이 **+15**, 불일치 **0**.
- 메뉴 normal↔hover 실루엣 불일치 **0픽셀**.
- 메뉴·출동·원형 normal↔pressed는 y 이동 3px 보정 후 각각 실루엣 불일치 **0픽셀**. 크기는 상태별로 동일하다.
- 원화 및 최종 비교판을 직접 열어 확인했다. 사무실의 창틀·조명·가구가 유리 뒤로 보이며, 크림 바탕에서는 상단 굴절광·남색 스모크 면·민트 포인트가 분리된다.
- 눌림은 더 어둡고 상단 반사가 약하며, 호버는 상단 광택이 더 밝다.
- 글자·숫자·로고·기능 아이콘 없음. 요청된 >> / >>> 모양은 별도 꺾쇠 PNG에만 있다.
- 삼중 꺾쇠는 빛 번짐을 줄이는 방향으로 재생성했다.
- Godot 연결, 게임 실행, 실기기 QA는 하지 않았다.

세부 픽셀 검사값은 `_raw/validation.json`에 있다. 이 파일의 coreAlphaMin/Max 필드는 alpha≥140 픽셀을 단순 집계하므로 경계 일부도 포함한다. 눌림 +15 검사는 경계에서 2px 이상 떨어진 내부를 별도로 비교했다.

## 원화 출처와 정밀 출력

OpenAI **내장 image_gen**으로 유리 원화·상태별 편집·꺾쇠를 제작했다. `_raw/manifest.json`에 파일별 생성/편집 프롬프트와 원본 경로를 기록했으며, `_raw/*.png`에 원본을 복사해 보존했다.

생성 원화만으로는 정확한 픽셀 기울기와 내부 알파, 상태별 동일 실루엣을 보장할 수 없어 `_raw/export.ps1`에서 원화의 RGB 재질을 리샘플링하고 공통 실루엣·알파 규격으로 정규화했다. 메뉴 민트 막대 위치도 정렬했다. 새 코드 그래픽으로 재질을 대체하지 않았으며 광택·질감·옆면·민트 효과는 생성된 래스터 원화에서 가져왔다.
