# 게이트24 — 낮의 헌터 편의점 적용

현재 실행 코드의 게이트24를 새로 캡처한 뒤, 같은 상품 구성으로 밝은 편의점 방향을 제작했다. 아이템·무기는 같은 디자인의 두 탭이다. **2026-10-11 사용자 승인 후 Godot에 적용했다.**

## 디자인

- 낮 햇빛, 냉장고, 다채로운 포장 상품이 보이는 편의점 배경.
- 우유빛 진열 칸과 민트 선반 레일, 남색 글자, 노란 가격표.
- 게이트24의 주황 숫자와 다음 웨이브 버튼으로 주요 행동을 강조.
- 상품별 색 띠로 다양성을 주되 설명·패널티·가격을 읽는 영역은 밝고 단정하게 구성.
- 상품 4칸, 좌측 캐릭터·스탯, 상단 탭·재진열·일시정지, 하단 장비·진행 구조를 유지.

concepts/는 915×412 비율을 기준으로 만든 전체 화면 시안이다. 실제 적용에는 글자·아이콘을 제외한 materials/의 별도 제작 PNG를 사용한다. 실행용 복사본은 godot/assets/ui/office-day-01/gate24-bright-01/이며 원본 픽셀과 해시가 같다. 배경만 불투명이고 세 표면 PNG는 실제 알파 0을 포함한다. 패널 내부 알파는 약 253/255이며 진열대·조작부 내부는 255/255이다. 소재에 글자·아이콘·로고와 가짜 체크무늬가 없는 것을 확인했다.

## 분할과 글자 영역

PNG를 다시 그리거나 잘라 파일로 내보내지 않고 HeroImageSkin의 atlas region을 직접 소비한다. 아래 분할은 원본 픽셀, 표시 배율은 4이다. 상태별 입력 크기와 내용 좌표는 동일하다. 전체 역할·상태의 정확한 값은 materials/manifest.json에 기록한다.

등급 띠만 별도 PNG region(120,104,1010,12)에 콘텐츠 등급 색을 곱한다. 본문 크림 표면은 등급으로 물들이지 않는다. hover는 약한 명도 변화, 눌림은 0.94 명도, 비활성은 같은 윤곽의 회색 표면으로 표시한다.

## 확인

- 최신 HeroShopScreen.build를 저장 읽기·쓰기, 경제 콜백, 오디오 콜백, 전투 시뮬레이션 없이 캡처했다.
- 아이템 가격 14 / 11 / 14 / 27, 배터리 패널티 최대 HP -8을 확인했다.
- 무기 가격 23 / 36 / 36 / 44, 마력탄 Lv.3 강화와 나머지 신규 무기 설명을 확인했다.
- 아이템은 작업 장갑, 무기는 마력검에 잠금 표시가 있으며 탭마다 네 잠금 조작부가 보인다.
- 웨이브 06/20, 재화 240, HP 106/106, 보유 아이템 2와 장비 레벨 2/1/1을 두 탭에서 확인했다.
- 915px 표시 폭에서 주요 글자·가격·상품·잠금의 가독성을 육안 확인했다. 기능·터치 입력 QA는 수행하지 않았다.

생성 시안의 글꼴·상품·인물은 원본을 참조한 그림 표현이다. 실제 적용본은 기존 캐릭터·상품 아이콘과 네이티브 BMJUA·해옹산스·Paperlogy·Barlow Condensed를 유지한다. 시안의 광고 문구는 실제 배경에서 제거했다.

## 적용 확인

- godot/scripts/ui/shop_screen.gd와 ui_materials.json의 cstore_bright 전용 역할로 연결했다. 다른 화면의 테마·팔레트와 기존 소재를 보존했다.
- 구매·잠금·재진열·단계 진행·분기 처리와 콘텐츠 가격·수치·저장 형식을 변경하지 않았다.
- Godot 4.7.2 가져오기와 해당 UI 실행이 exit 0으로 끝났으며 오류·경고가 없다.
- 합성 프로필의 실제 화면 7장이 모두 915×412이다. 84개 주요 입력 영역 기록이 44px 이상이며 화면 안에 있다.
- 무료 보급·품절·잠금·재화 부족, 상세창과 hover·눌림·복귀를 확인했다. 기본·복귀 PNG의 SHA256가 같다.
- 캡처 콜백 0회, 실제 저장 읽기·쓰기·오디오 재생·전투 시뮬레이션은 수행하지 않았다. 전투·전체 플레이·실기기 터치 QA는 범위 밖이다.
- 이전 before/ 원본은 그대로 보존했다. 합성 프로필의 현재 스탯은 해당 시점의 콘텐츠를 사용하므로 다른 개발 작업의 수치 갱신이 변경 전 캡처와 다를 수 있다.

프롬프트는 PROMPTS_RUNTIME.md와 PROMPTS_RUNTIME_EDITS.md, 생성 원본·해시는 materials/manifest.json, 캡처 도구는 godot/tools/gate24_bright_capture.gd/.tscn에 있다.
