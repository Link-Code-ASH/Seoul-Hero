# 협회 운영 UI 통일 · 승인 적용

2026-10-11. 사용자가 네 화면 시안을 승인하고 출동 준비의 상·하단 설명 제거, 짧고 선명한 협회 결과 연출을 요청했습니다. 최신 office-day-01 로비의 밝은 사무실, 채워진 유리와 절단면, 선명한 Paperlogy 글자를 설정·자료집·협회·출동 준비에 실제 적용했습니다. 실행용 PNG는 `godot/assets/ui/office-day-01/menu-unified-01/`에 원본과 같은 파일로 복사했습니다.

## 제작과 보존

- 배경 4장과 유리 원화 5장은 내장 **image_gen**으로 각각 제작했습니다. 배경은 같은 생성 원화를 다시 image_gen으로 광학적으로 흐리게 편집해 로비와 맞췄습니다.
- `_raw/manifest.json`: 모든 생성·편집 프롬프트, 원본 경로, 생성 도구. `_raw/*.png`: 생성 원본과 최종 후보. `*_original.png`: 흐림 처리 전 배경 원화.
- `assets/`: 실제 크기로 정규화한 PNG. `prepare_assets.py`는 원본을 보존하고 중앙 피사체 영역의 크롭·리사이즈만 수행합니다. 새 프레임이나 그림을 코드로 그리지 않습니다. 생성 당시 크기와 크롭은 `asset_checks.json`에 있습니다.
- `contact_sheet.png`: 네 업무 공간과 공통 유리 원화. 헤더 후보 원형은 보존하되 실제 시안 헤더는 버튼 원형을 9분할로 확장해 로비와 가까운 완만한 사선을 공유합니다.
- `runtime/before/`: 수정 전 현재 main 씬에서 새로 캡처한 화면 15장. `runtime/preview/`: 같은 합성 프로필을 쓴 실제 Godot 시안과 선택·잠금·조작 상태.
- `runtime/contact_sheet.png`, `before_after.png`, `deployment_steps.png`, `details.png`, `motion_preview.gif`: 네 화면 시안, 전후 비교, 출동 6단계, 상태 확대와 6초 움직임 자료.
- `runtime/applied/`: 승인 후 실제 경로를 사용한 화면·상태·뽑기·강화 캡처와 최종 전후 비교·6초 움직임 보고서. 이전 승인 시안과 변경 전 자료는 보존합니다.

## 화면별 성격과 연결

공통 헤더와 본문 유리, 남색 조작, 폰트 역할을 `HeroDesk`에 모았습니다. 화면 색은 설정 보라 `#7347D7`, 자료집 금색 `#AA741A`, 협회 파랑 `#347BCE`, 출동 산호 `#C64F5F`입니다. 제목과 영문 태그는 같은 색입니다. 배경은 같은 낮 조명·크림 벽·남색 금속·원목·서울 창밖을 공유하지만 업무 공간이 다릅니다.

자료집의 6분류·서류·폴라로이드·파일철은 기존 원본을 유지합니다. 설정의 음량 4개·데이터 기능 6개, 협회 모집/성장·재화/완료 표시, 출동의 6단계·20층 페이지·잠금 열람·실제 선택 분리는 그대로입니다. 편성에는 맵·선택 층수를 함께 표시합니다. 기능 생성 API·저장 형식·콘텐츠 수치를 바꾸지 않았습니다.

`HeroDesk.presentation`은 기본 `true`이며 실제 게임과 `--stage=applied` 캡처가 같은 Godot 내부 PNG 리소스를 사용합니다. 전역 테마는 그대로 두고 공통 네 화면만 스타일 프로필로 연결합니다. 표면은 제작 PNG, 입력·글자·스크롤은 네이티브 Control이 담당합니다. 기본/선택/hover/눌림/비활성은 같은 PNG 기하와 입력 영역을 유지하고 색조·짧은 광택·1.5px 눌림으로 표현합니다. 인물과 아이콘에 반복 이동을 추가하지 않습니다. 유리 표면은 화면 텍스처를 사용하는 클리핑 그룹에 넣지 않습니다.

출동의 상단 안내와 하단 설명을 6단계 모두 제거하고 단계 표시는 같은 하단 판 중앙에 배치했습니다. 잠금 이유는 상세 영역에 유지합니다. 협회 전용 `HeroAssociationFeedback`는 약 2초 뽑기 공개와 약 0.8초 강화·해금 피드백, 이후 2초 완료 표시를 담당합니다. 기존 `supplyLatch`·`supplyFanfare`·`purchase` 음원과 광택·입자 PNG를 재사용합니다. 규칙 처리·저장 성공이 먼저이며, 연출은 지급과 저장을 수행하지 않습니다. 중복 구매 요청을 차단하고 저장 실패는 거래 전 상태로 복구합니다. 공개 중 확인/Escape는 즉시 최종 결과로 전환하고 다음 입력은 닫습니다. 포커스 상실은 무음으로 최종 상태에 정리합니다.

## 소재 확인

9개 PNG의 크기는 위 표와 일치하고 모두 RGBA입니다. 배경 4개는 모든 픽셀 알파 255, 유리 5개는 알파 0 픽셀이 실제로 있으며 가짜 체크무늬가 없습니다. 유리 원형의 중앙 알파는 253~254/255이고 시안의 본문은 0.94 표시 알파를 사용해 약 93% 밀도를 유지합니다. 생성 배경·유리 소재에 읽을 수 있는 글자·숫자·로고가 없는 것을 직접 확인했습니다. 상세 수치는 `asset_checks.json`을 참조합니다.

915×412 실제 적용 경로에서 UI·거래 확인은 모두 통과했고 스크립트·셰이더·소재 로딩 오류는 0개입니다. 실행용 PNG 9개의 SHA-256은 디자인 원본과 모두 일치합니다. 전후 합성 프로필과 15개 화면의 선택값이 일치하며 최신 90개 원본 프레임으로 만든 GIF는 6,000ms입니다. UI 상태·콜백, PNG 규격과 GIF 확인은 `runtime/applied/README.md`와 `runtime/applied/capture_report.json`에 기록합니다. 캡처는 `--ui-preview --guild-office-preview`를 함께 강제해 사용자 프로필 읽기와 쓰기를 차단합니다. 실제 저장 대신 메모리 commit 콜백으로 1회 차감·1회 저장 호출 계약·실패 롤백을 확인합니다. 파일 열기·백업·가져오기·실제 구매 지급·전투 시작은 실행하지 않으며 전체 테스트·전투 플레이·실기기·청음 검증은 하지 않습니다.
