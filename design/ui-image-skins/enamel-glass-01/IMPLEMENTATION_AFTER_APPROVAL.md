# 실제 Godot 연결 완료 — 2026-10-03

사용자가 최신 피드백을 포함해 시안 전체의 실제 적용을 명시적으로 승인했다. 이 폴더의 index.html은 운영 화면 클래스의 실제 캡처를 보여준다. revision-03/은 승인 전 독립 시안을 보존한다.

- HUD: HP 수치24px Rect(20,6,82,28). 마력석·지갑은 같은13px 숫자 행(y8/24px)과12px 아이콘(y14)으로 체력바 가로 범위x20~200 안에 배치한다. 마력석 아이콘x104/숫자x120, 지갑 아이콘x157/숫자x173. HP바는 표시180×10(y37), 네이티브 내부720×40/¼배율이다. 무기6개는x20~182, 원화y62로 바끝47에서15px 떨어진다. 흰색14px 레벨과 WalletIcon 비행 목적지를 유지한다.
- 선택: 고정 서울 배경+유리 PNG+약한 원화 그림자. 4열 목록·드래그·해금 선택·검토 상태를 유지한다. 상세판은 원화76px+핵심 능력, 아래 긴 설명/스탯만 스크롤한다.
- 맵: 상세 텍스트 left32/right20. 편성: 불필요한 심도/20웨이브 표시 삭제, 세 행64px·원화48px·안전여백8px·name16/body14. 성장 원화/단계 중앙, 자료집 책등48px, 일시정지 내용면 중앙 보정.
- 타이틀: 이어할 게임이 있으면 이어하기/새로하기, 없으면 시작하기. 기존 콜백과19px/52px을 유지한다.
- 로비: 왼쪽 glass/tools 제목·재화, 자연 폭 그룹간격6px. 오른쪽 glass/tools 안에 차분한 뉴모피즘 책/톱니/음표 PNG, 최대36px 원화·44px 조작. 음악 실제 상태와 연결한다. 큰 작전 단말190×175, 스캔광 밝기 .25↔.60/2초, 남색 출동 버튼을 사용하고 숨겨지면 갱신을 멈춘다.
- 게이트24: 한국 편의점 PNG·상단 흰 면 한 행·나사 없는 탭/리롤·상품4칸 y84/266px. 구매면110×28의 연한 노란 PNG+44px 입력. 잠금은 우상단과 민트 테두리, 구매 가능 여부는 구매면 활성/회색으로 표시한다. 13px2줄 설명/패널티와 기존 전체 상세를 유지한다. 왼쪽 상태판을 내리고 지갑 표시는 삭제했다. 다음 웨이브는 남색이다.
- 공통: HeroImageSkin은 role별 image_id, 안전 여백, 고밀도 스타일, 선택 상태, 카드 유리/그림자 PNG를 소유한다. PNG 상태는 기하/배경을 유지하고 색만 바꾼다. 기능 글자는 네이티브 B계열 역할 글꼴을 사용한다.

전투 수치·가격·잠금·구매·독립 리롤·해금·저장 형식은 변경하지 않았다. 출동 UI 검토/스크롤 상태는 UI 안에만 있다.
