## 로비와 웹 스캔광

좌우 상단의 유리 면, 흰색 글자와 그림자, 재화 아이콘↔숫자 6px 간격, 기존 하단 시설 5개를 유지한 구성을 확인했습니다. 첩보 단말과 출동 버튼은 제작 PNG를 사용합니다.

공식 로비 PNG는 스캔광 alpha 0.25의 고정 위상입니다. 웹 갤러리의 움직임은 pulse 없는 캡처 위에 동일한 투명 PNG를 고정 배치하고 CSS opacity만 0.25↔0.60으로 바꾸는 2초 시안 표현입니다. 색상·크기·위치·PNG 형상은 바꾸지 않으며 움직임 줄이기 설정에서는 0.25로 고정합니다. 실제 게임 애니메이션이나 GIF/영상 검증 결과로 간주하지 않습니다.

## 적용 경계와 미확인

UI 테마와 화면 연결은 게임에 적용하지 않았습니다. 공용 마력석 원화만 게임의 해당 이미지 연결에 반영했으며, 전투·가격·저장 규칙은 유지합니다. 기존 런타임 갤러리는 유지합니다.

상점의 12,345,678(12345678) 가격은 배치 확인용 수치입니다. 이전안은 [revision-01/index.html](revision-01/index.html)에 보존했습니다.

실제 게임 연결, 선택·구매·잠금 입력, 실기기 터치, 청감, 전투 플레이, 성능, 전체 테스트·빌드는 수행하지 않았습니다. 원본 게임 UI 수정·런타임 연결·실제 게임 캡처는 사용자 승인 후 진행합니다.
