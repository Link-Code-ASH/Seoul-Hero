지금까지 승인한 디자인과 최신 피드백을 실제 게임 화면에 연결했습니다. 아래 이미지는 시안 프로젝트가 아닌 운영 화면 클래스에서 캡처했습니다.

Galaxy S24 Ultra 가로 기준 915×412 · 제작 PNG 소재 · 네이티브 글꼴 · 로비 스캔광/환경 효과는 게임에서 움직이며 이 갤러리는 정지 캡처입니다.

실제 적용 화면의 배치 기록을 불러오는 중입니다.

큰 숫자·잠금·구매 불가 등 추가 상태

8자리 가격은 배치 확인용 메모리 데이터입니다. 실제 가격 데이터는 변경하지 않았습니다.

큰 재화·낮은 HP8자리 가격 배치구매 불가 상태각성자 잠금무기 잠금축복 없음성장 불가HP 0%HP 50%HP 100%

필요한 이미지 가져오기·스크립트 오류와 요청한 UI 범위를 확인했습니다. 실기기·전투 플레이·청감·전체 테스트·빌드·성능 검사는 수행하지 않았습니다.
