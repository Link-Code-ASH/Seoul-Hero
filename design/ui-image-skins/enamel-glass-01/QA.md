# 실제 UI 적용 확인 — 2026-10-03

## 실행과 산출물

- Godot4.7.2 Compatibility로 신규 이미지 가져오기와 실제 UI 캡처 실행. 실행을 막는 스크립트/셰이더/이미지 오류 없음.
- 운영 화면 클래스/콘텐츠를 사용한다. Profile.writable=false, saveWrites=false, simulation=false. 인메모리 데이터로 선택·잠금·구매·리롤·음량 콜백만 확인했다.
- 기본915×412, HP/음량 확대 확인은1830×824. 67개 화면/상태 캡처를 runtime-captures/에 보존했다. 기능 텍스트1634개 측정의 영역 초과0건. 최초04차 UI 범위 확인187개/187개 통과(최신 HUD 재확인은 아래05차 기록). 이 숫자를 전체 테스트 또는 실제 플레이 결과로 해석하지 않는다.

## 직접 이미지 확인

915×412 최종 HUD·로비·상점2탭·선택3종·편성·성장·자료집·설정·일시정지·타이틀2상태를 직접 보았다. 맵/심도도 운영 클래스 캡처로 보존했다.

- HUD: 재화 한 행이 체력 표기 옆·HP 바보다 위에 있으며 모두 바의 가로 범위 안에 있다. 무기6개와 레벨은 HP 아래, 짧은 HP 바와 중앙 시간 사이 전장을 확보했다. HP0/50/100% 및2배 확인. WalletIcon 목적지 연결 유지.
- 로비: 차분한 단색 뉴모피즘 PNG3개와44px 입력 영역, 제목/재화 유리면, 자연 폭 숫자, 큰 작전 단말과 남색 버튼. 실제 스캔광 tween은 게임에서 동작하며 갤러리는 정지 PNG다.
- 상점: 헤더는 흰 내용면 중앙. 노란 구매면/회색 비활성/민트 잠금 구분,110×28가격면/44px 입력,4상품 내부 스크롤 없음. 큰 재화·8자리 가격·복합 효과·패널티의 프레임 안전 간격과 정렬을 확인했다. 8자리 가격은 메모리 fixture만 변경했다. 55아이템+10무기 전체 짧은 문구는 실제13px 라벨로 두 줄 영역을 측정했다.
- 선택: 서울 배경의 원본/영역/배치가 선택 전후 동일하다. 원화 옆 핵심 정보를 고정하고 긴 내용만 스크롤한다. 선택/잠금 검토/배포 구분과 상세 갱신, 터치·마우스 드래그 후 선택 억제·스크롤 복원·PC 휠을 확인했다.
- 편성: 세 행의 원화/16px 이름/14px 설명이 안쪽 영역을 벗어나지 않는다. 하단 심도/20웨이브 문구 삭제. 성장 원화/단계 중앙, 책등48px 여백, 일시정지 광학 중앙을 확인했다.
- 타이틀: 이어하기/새로하기 또는 시작하기. 동일19px/52px 크기를 확인했다. 마우스 툴팁 없음.

## 미확인 범위와 실행 환경

실기기·실제 터치 플레이·전투 플레이·청감·전체 테스트·빌드·성능 검사는 실행하지 않았다. Windows root certificate store 읽기 경고가 남았지만 로컬 UI 가져오기/캡처를 차단하지 않았다. 에디터 설정 저장 경고는 샌드박스 바깥 경로이며 실제 게임 저장 쓰기와 관계없다. 캡처는 작업 폴더에 로그를 기록했다.

운영 저장·밸런스·가격·콘텐츠 ID·전투/구매/잠금 규칙 변경 없음. 이전 시안은 revision-03/에 보존한다.

## 05차 HUD 높이 보정

최신 사용자 피드백에 따라 마력석·지갑을 한 줄(13px 숫자/12px 아이콘)로 합치고 HP바를27px, 무기 줄을25px 올렸다. 두 재화의 아이콘과 숫자 전체를 HP바 가로 범위x20~200 안에 두고 체력 수치24px을 유지했다. 실제 HUD9상태(큰 숫자/지갑 회수/HP0·50·100%의1배·2배)를 다시 캡처했고 글자 영역 초과0건, HUD 범위 확인22/22 통과했다. 기본/큰 숫자 캡처를 직접 보아 한 줄 배치와 무기 간격을 확인했다. 이번 재확인은 HUD에 한정했다. hud-layout.json은 이 실행 기록이며 layout.json은 변경 없는 이전 화면과 최신 HUD 기록을 합친 갤러리 기록이다.
