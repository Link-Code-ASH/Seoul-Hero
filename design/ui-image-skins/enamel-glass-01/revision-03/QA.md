## 로비와 웹 스캔광

왼쪽 유리 정보판의 흰색 글자와 그림자, 재화 아이콘↔숫자 6px 간격, 하단 시설 5개·첩보 단말·출동 버튼은 유지합니다. 오른쪽 메뉴는 182×48 유리 면 하나에 제작 PNG 책·톱니·음악 일러스트 3개를 배치합니다. 각 원화는 실제 알파 경계의 종횡비를 유지해 36×36 범위 안에 맞추며, 조작 영역 44×44와 같은 중심입니다. 메뉴 텍스트·툴팁·개별 프레임을 추가하지 않습니다. 실제 메뉴 기능과 음악 상태를 연결하지 않는 동결 시안입니다.

공식 로비 PNG는 스캔광 alpha 0.25의 고정 위상입니다. 웹 갤러리의 움직임은 pulse 없는 캡처 위에 동일한 투명 PNG를 고정 배치하고 CSS opacity만 0.25↔0.60으로 바꾸는 2초 시안 표현입니다. 색상·크기·위치·PNG 형상은 바꾸지 않으며 움직임 줄이기 설정에서는 0.25로 고정합니다. 실제 게임 애니메이션이나 GIF/영상 검증 결과로 간주하지 않습니다.
