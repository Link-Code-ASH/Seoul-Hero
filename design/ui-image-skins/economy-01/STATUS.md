# 재화 개편 시안

2026-10-05. built-in image_gen으로 길드 재화 8종을 제작했다. PNG 원본·전체 프롬프트·출처는 assets/ui/economy-01에 보존한다. runtime의 네 화면은 Godot Compatibility에서 합성 메모리 상태로 렌더링했다. 사용자 저장은 변경하지 않았다.

경제 로직·저장 v4 이관·기존 화면의 비용 및 보상 텍스트는 구현했다. 2026-10-05 사용자의 “적용해” 승인으로 HeroMetaScreens.ECONOMY_UI_APPROVED=true를 적용했다. 새 협회 목록/상세·회수 스크롤·길드 전체 재화·보급 확률 화면과 길드 재화 8종 이미지가 게임에 연결된다.

사용자가 긴 소수점 표시를 줄이도록 요청했다. 정수 우선·일반 효과 소수 한 자리·작은 효과 최대 두 자리로 표시하고, 점감 보너스에는 ‘약’을 붙인다. 0으로 반올림되는 미세한 증가량은 ‘0.01 미만’으로 표시한다. 회수 누적 시간은 시간·분으로 표시한다. 내부 정산 수치와 확률은 보존했다.

콘텐츠 exporter 완료: 이미지 누락 0. 변경 스크립트의 로드를 막던 시안의 타입 추론 오류를 수정하고 네 화면을 렌더링했다. 자동 테스트·전체 빌드·실제 플레이·터치·Android QA는 수행하지 않았다. 저장 이관·중복 지급·시간 경계의 실제 QA는 ECONOMY.md와 구현 계획의 확인 기준을 따른다.
