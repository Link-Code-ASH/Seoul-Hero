## 보기

- `index.html`: 승인한 독립 시안과 실제 게임 화면 캡처.
- `../../..\Play-Seoul-Hero.cmd`: 현재 워크트리 게임 실행. 이미 실행 중이면 닫고 다시 실행합니다.
- `Preview-Guild-Offices.cmd`: 직접 스크롤하고 사무실을 선택하는 독립 Godot 시안.
- F1: 초기 / F2: 3층 확장 / F3: 시설 관리 / F4: 직원 / F5: 작업 / F6: 운영실.
- 왼쪽은 터치·마우스 세로 드래그/휠과 사무실 선택만 합니다. 8px부터 드래그가 선택을 취소합니다.
- 오른쪽의 관리·직원·작업 탭에서 행동하며 내용만 별도 스크롤합니다. 닫으면 오른쪽이 비워집니다.
- 운영실은 전체 직원·작업·보상 수령·작전 투입을 맡습니다. 다른 시설은 해당 시설 업무를 표시합니다.
- Escape: 패널 닫기, 패널이 없으면 시안 종료.
