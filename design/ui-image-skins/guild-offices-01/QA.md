# 고정 패널 연결 확인

2026-10-05 · Godot 4.7.2 Standard / Compatibility

## 실제 게임 연결

- 사용자 승인 후 현재 워크트리의 main.gd에 HeroGuildOfficeScreen을 연결했습니다. 기존 Play-Seoul-Hero.cmd는 변경 없이 최신 소스를 실행합니다. 본 폴더에는 반영하지 않았습니다.
- Godot 이미지 가져오기와 실제 메인/길드 스크립트 로드를 확인했습니다. 최종 화면 클래스의 초기·확장·관리·직원·작업·운영실 6종 915×412 캡처는 runtime/에 있습니다. 저장 검증/캡처 플래그는 실제 Profile 파일 접근 전에 별도 메모리 상태를 만듭니다. 사용자 저장을 읽거나 쓰지 않았습니다.
- 건물 547×335와 오른쪽 330×335 공간은 고정입니다. 선택 전 오른쪽은 배경이며 하단 버튼은 없습니다. 제목·탭을 고정하고 내용만 내부 스크롤합니다. 운영실 캡처는 수령·작전 투입이 보이도록 내부를 스크롤했습니다.
- v2 → v3 메모리 이관 검증: 31개, 실패 0개. 새 3칸, v1 교체, v2 4/8칸 보존과 공사 슬롯, v3 슬롯 8, 기존 필드·작업 시각 보존, 미래 버전 거부 및 해금 층 단조 증가를 확인했습니다.
- 실행 환경의 root certificate store 경고는 있었으나 스크립트 로드와 PNG 캡처는 정상 종료했습니다.
- 전체 테스트·자동 플레이·수동 플레이 QA·실제 모바일 검증은 수행하지 않았습니다. 실제 조작 감각과 경영 동작은 사용자가 플레이하며 확인합니다.

## 독립 시안 보존

승인한 독립 시안은 approved-preview.html과 *-fixed.png에 남아 있습니다. Preview-Guild-Offices.cmd는 계속 실제 Profile/autoload/저장을 사용하지 않고 메모리만 변경합니다. 이전 수정 전 시안은 revision-01에 보존했습니다.

사용자 확인: 패널 개폐 시 건물 배율·위치 유지, 빈 오른쪽 입력 분리, 사무실 전환·탭·내부 스크롤, 운영실 공통 기능, 층 해금, 시설 이동·직원 배치·탐험 복귀·공사 완료 후 직원 위치 유지.


## 2026-10-05 · 본 개발 폴더 길드 병합

055e 워크트리의 최신 고정 사무실 리뉴얼을 3방향 병합했다. 기존 VFX·회수·보급을 유지하고 생성 데이터는 exporter로 갱신했다. 본 개발 폴더에서 다시 만든 메모리 상태의 915×412 런타임 캡처 6장을 runtime/에 갱신했다. main의 읽기 전용 길드 로드와 메모리 저장 이관 31항목(실패 0)을 확인했다. 원본 워크트리·사용자 저장 파일은 수정하지 않았다. 실제 저장/장시간 생산/모든 경영 동작/전투 플레이/실기기/전체 테스트·빌드는 미확인이다. 병합/복구 기록은 godot/docs/GUILD_INTEGRATION.md에 있다.
