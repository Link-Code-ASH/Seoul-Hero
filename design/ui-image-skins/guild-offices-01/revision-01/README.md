# 층당 사무실 3개 · 독립 시안

915×412 가로 기준. 기존 현대 서울 방 원화와 빈손 SD의 공용 걷기·접지 그림자를 사용합니다. 게임·저장·밸런스와 분리된 Godot 프로젝트이며 버튼은 시안 메모리만 바꿉니다.

## 보기

- `index.html`: 초기 본부, 3층 확장, 오른쪽 관리창 캡처.
- `Preview-Guild-Offices.cmd`: 직접 스크롤하고 방을 선택하는 시안.
- F1: 초기 1층 / F2: 3층 확장 / F3: 관리창.
- 건물을 터치·마우스로 세로 드래그하거나 휠로 이동합니다. 8px부터 스크롤하며 드래그는 방 선택을 취소합니다.
- 빈 방은 건설, 시설은 관리, 잠긴 층은 해금 조건을 엽니다. 오른쪽 내용은 별도로 스크롤합니다.
- Escape는 관리창 닫기, 창이 없으면 시안 종료입니다.

## 승인 후 연결

사용자가 이 새 시안을 승인한 뒤에만 현재 워크트리의 게임·콘텐츠·v3 저장 이관에 연결합니다. `Play-Seoul-Hero.cmd`와 본 폴더는 아직 변경하지 않았습니다. 연결 사항은 `IMPLEMENTATION_NOTES.md`에 기록합니다.

원화는 수정하지 않은 기존 PNG 사본입니다. 레벨 변형 아틀라스 4열과 화면의 사무실 3열은 별개입니다. 생성 프롬프트·라이선스·이전 시안은 원래 폴더에 보존되어 있으며 `provenance.json`이 출처를 기록합니다.
