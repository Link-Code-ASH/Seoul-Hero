## 수행한 범위
- 신규 투명 PNG8팩의 원본 영역·알파·9분할 연결과 필요한 Godot 가져오기/스크립트 실행 확인.
- 별도 정적 Godot 프로젝트로 게임 화면11종, 소재보드1종, 확인용2종을 PNG로 캡처.

- 실제 PNG를 읽고 화면별 위계, 원화/글자 대비, 제목·본문 정렬, 필수 문구·선택·잠금 상태를 시각 검토.
- 실제 B 글꼴의 높이·줄 수·폭과44px 조작 영역을 측정. 글자 측정만으로 디자인 확인을 대체하지 않음.

## 미확인 범위
실제 플레이·터치·청감·동적 숫자 갱신·성능·전체 테스트·빌드·회귀 검사는 수행하지 않았다.
844×390/PC runtime 화면으로 확장하지 않았다. 이번 승인 요청은915×412 독립 시안이다.
현재 PNG는 실시간 전투 화면의 캡처가 아닌 정적 fixture다. 그림과 전투 상태를 오해하지 않도록 갤러리에 표시했다.
선택·구매·잠금·일시정지·저장·마력석 비행 목적지의 런타임 연결은 컨펌 후 기존 연결을 보존하며 별도로 구현한다.
