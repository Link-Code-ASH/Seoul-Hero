# 공용 운영 UI 시안 규칙

2026-10-05 · 최신 사용자 계획 기준. 여섯 대표 화면과 소재판은 **“좋아 좋아 적용해”**로 승인됐다. 아래 규칙을 Godot 런타임에 연결하며 실제 확인 기록은 `runtime/QA.md`에 둔다. 승인 시안의 이미지와 소스는 보존한다.

## 기준 화면과 색

- 가로 915×412, 전체 배경과 안전 영역을 유지한다. 공통 헤더 y=12~64, 본문 y≥72. 긴 목록·설명만 내부 스크롤한다.
- 대표 화면은 길드·로비·게이트24·각성자 선택·자료집·HUD다. 게이트24는 기존 상점 이름을 유지한다. HUD·상점·타이틀의 승인된 밀도는 예외다.
- 길드는 왼쪽 건물과 오른쪽 관리 공간을 항상 확보한다. 선택·닫기로 건물 배율·스크롤 위치를 바꾸지 않으며 관리·직원·작업은 고정 패널 안에서 전환한다.

## 두 PNG 시트와 역할

구조 시트에는 `ops/header`, `ops/info`, `ops/row`, `ops/popup`, 조작 시트에는 `ops/primary`, `ops/secondary`, `ops/tab`, `ops/icon`을 둔다. 표면·프레임·조작 영역만 래스터 원화로 만들며 글자·숫자·기능 아이콘의 의미는 네이티브 텍스트와 기존 승인 아이콘이 맡는다. 가변 크기는 명시적인 9분할로, 고정 크기는 원래 비율로 표시한다.

생성 원본은 `assets/structures-generated.png` 1254×1254와 `assets/controls-generated.png` 1448×1086이며 원본을 그대로 보존한다. 추출한 각 `*-native.png`에서 생성 원화의 모서리·테두리와 래스터 질감을 보존하여 9분할로 확장한 `*-4x.png`를 표시용 마스터로 사용한다. 이 작업은 기존 래스터의 준비 과정이며 새 프레임을 코드로 그리거나 새로운 4K 디테일을 생성하는 작업이 아니다. 크기·원본 영역·추출 영역·분할·안전 여백은 `provenance.json`과 시안 전용 `materials.json`에 기록한다.

일반·선택·잠금·누름·비활성·위험은 같은 기본 기하·테두리·9분할·글자 영역을 유지한다. 선택은 민트 강조와 기존 선택 테두리, 누름은 얕은 명도 변화, 비활성은 채도·명도와 상태 글자, 위험은 위험색과 명확한 동사로 표시한다. 선택 탭을 주 행동 소재로 교체하거나 선택 목록을 진행 단계 원화로 교체하지 않는다.

## 기존 승인 소재의 범위

- 기존 선택 카드의 원본·유리·선택 테두리와 캐릭터·아이템 원화를 보존한다.
- 자료집 책등과 `codex/panel` 책 프레임은 자료집에 유지한다.
- 편의점 냉장 진열대·가격·잠금 원화와 `cstore/*`는 게이트24 상점에서만 사용한다.
- 회수·보급 원화와 `support/panel`은 해당 지원 장면에서만 사용한다.
- `spy/deploy`는 로비의 작전 단말에서만 사용한다.
- 기존 HP바·슬라이더·스크롤·구분선·정보 아이콘은 승인 소재를 재사용한다. 공용 행동·탭·패널은 새 `ops/*` 역할을 따른다.

## 텍스트와 기능 이름

화면 제목 24px·섹션 18px·버튼/탭 16px·본문 14px·보조 13px·기본 숫자 18px. 제목 BMJUA, 섹션 해옹산스, 본문/버튼/탭 Paperlogy, 숫자 Barlow Condensed를 사용한다. HUD·상점·타이틀의 기존 밀도 예외를 유지하고 글자가 늘면 내용을 위한 공간이나 내부 스크롤을 확보한다.

기존 화면·콘텐츠 이름을 유지한다. 준비 화면 진입은 `출동 준비`, 최종 행동은 `작전 투입`이다. 행동은 `직원 배치`, `채용`, `연구 시작`, `작업 가속`, `보상 수령` 등 기능을 설명하는 동사로 표기한다. 탭은 `관리`, `직원`, `작업`처럼 내용 이름을 쓴다. 일반 입력 영역은 44px 이상, 상태 변화 때 글자 위치와 크기는 고정한다.

팝업은 제목과 하단 행동을 먼저 확보하고 긴 본문만 내부 스크롤한다. 기능 글자·숫자를 PNG에 굽지 않으며 효과·조건·패널티를 줄이거나 숨기지 않는다. 모호한 아이콘만으로 명령하지 않고 기존 정보·의미가 있는 아이콘을 사용한다.

## 이 단계의 산출과 경계

두 생성 원본·추출 원본·4배 표시용 PNG 마스터·영역/9분할/안전 여백 메타데이터·프롬프트/출처, 여섯 독립 시안 화면과 소재판, 로컬 갤러리를 이 폴더에 둔다. 시안의 버튼·탭·시설 선택은 메모리 안에서만 동작하고 실제 Profile·출동·지급·추첨·저장을 연결하지 않는다.

새 PNG 외관 승인 전에는 `godot/scripts`, `godot/data`, 런타임 이미지 manifest와 실제 게임 호출을 변경하지 않는다. 승인 후 할 일은 [IMPLEMENTATION_AFTER_APPROVAL.md](IMPLEMENTATION_AFTER_APPROVAL.md)에만 기록한다. 전체 테스트·빌드·수동 플레이 QA를 기본 절차로 추가하지 않는다.
