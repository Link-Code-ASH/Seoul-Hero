# 도시 작전풍 UI 실제 연결 · 2026-10-05

사용자 승인: **“좋아 좋아 적용해”**. 승인 시안과 원본은 `approved-drafts.html`, 기존 `captures`에 보존했다. 현재 갤러리는 실제 Godot 화면 클래스의 캡처다.

## 구현

- `HeroImageSkin`의 ops 헤더·정보판·행·팝업·주/보조 버튼·탭을 연결했다. 상태는 같은 PNG 기하를 유지하며 색조·채도로 구분한다. 재화 묶음은 네이티브 HBox의 자연 폭과 6px 간격을 사용하고 숫자 변경에도 함께 정렬된다.
- 길드 본부·출동 6단계·전략지원·협회·설정·전투 팝업을 공통 역할로 맞췄다. 로비·타이틀·HUD의 전용 배치를 유지하고 상점의 편의점 진열대, 자료집 책등, 회수/보급 원화와 연출을 보존했다.
- BMJUA 제목24, 해옹산스 섹션18, Paperlogy 버튼16/본문14/보조13, Barlow 숫자18을 적용했다. 기존 타이틀19·상점 요약13/가격16·HUD 재화13/레벨14 예외를 유지했다. 능력치 명칭은 `HeroUI.STAT_NAMES`를 공유한다.
- 네이티브 PanelContainer의 프레임은 PNG StyleBoxTexture로 연결했다. 자식 NinePatch가 내용 컨테이너로 배치되어 프레임/글자가 어긋나는 실제 렌더링 문제를 수정했다.
- 생성 원본 2시트, 추출 PNG, 4배 9분할 마스터7종, 프롬프트·해시·분할·안전 여백을 보존하고 이미지 manifest/exporter/Godot 가져오기를 연결했다. 4배 마스터는 생성 모서리와 테두리를 보존한 래스터 확장본이다.

## 확인

- Godot 4.7.2 Compatibility 실제 렌더러로 UI 화면34장, 별도 길드 상태6장, 회수/보급7장을 캡처했다. 대표 각성자·자료집·HUD·상점은 844×390과1830×824에서도 비교했다. 기본 화면·새 정보판·책등·편성·일시정지·팝업과 큰 가격 및 작은/PC 캡처를 직접 이미지로 확인했다.
- 34장 캡처의 실제 전체 텍스트 맞춤 진단0건. 65종 상품의 이름·효과·패널티 전수 측정, 큰 재화·8자리 정확한 가격·잠금·구매 불가·무기6개와 레벨·미해금 상세·생환·분기·조합을 포함한138개 UI 진단이 통과했다. 스크롤 밖의 내용은 해당 영역 안에서만 이어진다.
- 회수/보급 표시12개와 중복 요청·숨김/일시 중단·재개·확인 후 재지급 없음·화면 이탈 취소12개 확인이 통과했다. 실제 지급 대신 고정 메모리 콜백을 사용했다.
- `--ui-preview --guild-office-preview`로 Profile 사용자 파일 읽기·쓰기와 전투 시뮬레이션을 차단했다. 새로운 이미지7종 외 콘텐츠 데이터는 작업 전과 동일하다. 저장 형식·가격·전투·길드 규칙·오디오 데이터는 변경하지 않았다.
- 필수 이미지 누락 및 스크립트/셰이더 실행 차단 오류는 없다. 환경의 사용자 로그·편집기 설정·셰이더 캐시 쓰기 제한 및 인증서 메시지는 있었다.

## 확인하지 않은 범위

실제 전투 플레이·터치·실기기·청감·성능·전체 테스트/빌드는 수행하지 않았다. 실제 경제·성장·생환·조합·정산을 실행하거나 사용자 저장을 복사/초기화하지 않았다. 코드 검토와 화면 진단을 실제 플레이 검증으로 간주하지 않는다.
