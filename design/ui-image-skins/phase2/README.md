# 승인된 C 디자인의 다음 메뉴 시안

이 폴더는 게임과 분리된 Godot 프로젝트다. 제작 중인 메뉴를 승인된 C PNG 프레임과 B 글꼴 역할로 비교하기 위한 915×412 정적 시안이며, 프로덕션 화면에 적용하지 않았다. 생산 프로젝트, 자동 로드, 저장 어댑터, 시뮬레이션, 오디오를 불러오지 않는다. 기존 상점·로비·타이틀 아홉 캡처는 변경하지 않았다.

| 파일 | 범위 |
|---|---|
| 01-deployment-depth.png | 광화문 지도, 실제 웨이브 수, 심도별 체력·생성 배율, 기본 진행도의 잠금 |
| 02-character-weapon.png | 실제 SD 각성자 4명과 시작 무기 6종, 추가 시작 무기 1종 안내 |
| 03-growth.png | 전략지원 탭, 풍요의 매듭의 실제 효과·해금/성장 비용, 조각 부족 상태 |
| 04-archive-item.png | 자료집 분류, 금고 장부의 조건·한도·소비 시 감소·패널티·가격 |
| 05-settings.png | 설정 기본 음량 4종, native HSlider + PNG 트랙/손잡이, 백업 버튼 |
| 06-hud-pause.png | 광화문 정지 장면, HP·웨이브·재화·6슬롯 HUD, 일시정지 팝업 |

본문과 보조 문구는 최소 14px, 모든 조작 시안 영역은 최소 44px 높이로 배치했다. 표면/버튼은 기존 PNG의 NinePatchRect이며 native Label과 FontFile로 글자를 렌더링한다. StyleBoxFlat과 SVG 프레임을 사용하지 않는다. 숫자는 Barlow Condensed, 제목은 해옹산스, 조작 글자는 Paperlogy 5, 본문은 Paperlogy 4를 사용한다. 폰트의 출처와 허가 정보는 ../fonts/README.md를 따른다.

데이터는 ../../.. 상위 저장소의 godot/data/content.json을 읽는다. 기본 Meta(심도1, 조각0)와 초기 전투(송진우/마력탄, HP100/100, 재화0)를 예시로 사용한다. 보상·해금·수치·전투 규칙을 추가하거나 바꾸지 않는다. 현재 실제 시작 무기는 마력 샷건을 포함해 7종이므로 요청된 6종 진열 외 추가 1종 안내가 있다. 축복 목록과 자료집 목록은 시안용 일부이며 전체 목록은 구현 승인 후 기존 스크롤 흐름에 연결한다.

실행: Godot 콘솔 실행 파일에 --path design/ui-image-skins/phase2 --resolution 915x412 --position 10000,10000 --audio-driver Dummy -- --capture 를 전달한다. 캡처는 captures/에만 기록한다. --capture 없이 시작하면 제작 완료 안내 후 종료한다.

font-fit.json은 사용 글꼴의 실제 줄 높이와 줄 간격을 할당 영역에 비교하고, 한 줄 문구는 실제 폭을 비교한 기록이다. 이 확인은 정적 시안의 문구 가독성에 한정하며 실제 플레이·터치·저장·다른 화면비 QA는 수행하지 않았다.
