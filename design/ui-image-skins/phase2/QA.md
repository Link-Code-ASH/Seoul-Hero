# Phase2 시안 확인

915×412에서 여섯 정적 PNG를 직접 열어 확인했다. 125개 native Label의 실제 글꼴 높이·줄 간격·한 줄 폭을 할당 영역과 비교한 font-fit.json은 0건이다. 전체 글자 크기는 14px 이상이다.

| 화면 | 직접 확인한 범위 |
|---|---|
| 출동·심도 | 지도·게이트 그림과 숫자 분리, 심도1 선택/나머지 잠김, 체력·생성 배율 정렬 |
| 각성자·무기 | SD 네 명의 이름·특성 및 시작 무기 여섯 칸 이름의 가독성 |
| 전략지원·성장 | 선택 탭/축복, +3.5%와 +6.0% 효과, 0조각·해금 불가, 단계별 비용 |
| 자료집·상세 | 금고 장부의 전체 조건·최대치·소비 시 감소·패널티, 가격48/상한1 |
| 설정 | 네 기본 음량, native 슬라이더의 PNG 트랙·손잡이, 백업 버튼 |
| HUD·일시정지 | 고정 장면·HP/웨이브/재화/6슬롯, 팝업 제목·계속/종료 버튼 |

첫 시안의 심도 숫자와 게이트 그림이 겹치는 부분을 분리했고, 아이템 설명의 단어 중간 줄바꿈을 문장 경계로 바꿨다. 변경한 정적 시안을 다시 저장한 최종 PNG를 확인했다.

생산 프로젝트/자동 로드/저장 어댑터/전투 시뮬레이션/오디오 재생은 불러오지 않았다. 기존 아홉 캡처를 보존했다. 실제 플레이·터치·저장·PC/작은 화면비 확인과 전체 테스트·빌드는 수행하지 않았다.

Godot 콘솔은 로컬 shader cache 및 certificate store 접근 안내를 출력했지만 캡처와 글꼴 기록을 모두 저장하고 exit0으로 종료했다. 실행을 막는 스크립트·리소스 오류는 없었다.
