# VFX 재탄생 01 · 실제 적용 확인

2026-10-04. 915×412, Godot 4.7.2 OpenGL Compatibility의 실제 런타임 화면 클래스에서 캡처했다. 저장 쓰기와 전투 시뮬레이션은 차단하고 메모리 검토 상태의 표시 시간만 진행했다.

## 산출물과 확인

- 네이티브 캡처 1,320프레임을 수정 없이 무손실 WebP 15개로 묶었다. 마력검 8방향·실제 Lv.1 쿨타임 간격, 이동하는 번개 접점, 마력탄·관통탄·산탄·포탑·적 탄의 연속 리본, 머리 위 표창, 폭격·지뢰·마력장, 적 행동·보스, 획득, 6무기 혼합 장면과 로비·선택·상점·성장·보급·결과를 제공한다. 이전 적용 영상 4개도 함께 보존한다.
- 전투 9장면의 일시정지·표시 상한·웨이브 정리와 메뉴 6장면의 일시정지·반복 입력 상한·화면 이탈 예약 취소·숨김 정리, 총 51개 표시 확인을 통과했다. `capture.json`의 maximumEffects/Particles/Shots는 전투 계수다. 메뉴는 별도 UI 상한 검사로 확인하며 이 전투 계수의 0을 메뉴 효과 없음으로 해석하지 않는다.
- 캡처 중 전투 최대 효과 6개·입자 39개·탄 표시 37개였다. 상한 64/192/160과 메뉴 입자 48·로비 160을 유지한다. 이 수치는 고정 검토 장면의 관찰값이며 실기기 성능 결과가 아니다.
- 실제 이미지로 검기의 주·보조 곡선과 잔광, 번개의 정확한 접점, 설치물의 뒤쪽 레이어, 6무기 장면의 HUD·위험 영역, 카드 배경 고정, 상점 구매 가격, 선택·획득·성장·보급·결과의 원화 중심 정렬을 확인했다. 밝은 지면에서 검흔 대비, 아틀라스 마스크, 겹친 원화 전환, 보상빛 기준점을 보정한 뒤 해당 장면을 다시 캡처했다.
- 필요한 스크립트와 셰이더를 실제 렌더링했다. 최종 캡처 종료 코드 0이며 실행 차단 스크립트/셰이더 오류가 없다. 인증서 저장소 읽기와 캐시 쓰기 제한 메시지는 환경 경고다. 로컬 프로필의 더 새로운 저장 형식 경고도 있었으며 자동 덮어쓰기 차단을 유지하고 원본 저장은 수정하지 않았다.

## 유지 사항과 구현 선택

피해·사거리·공격 횟수·쿨타임·가격·오디오 호출·게임 RNG·저장 버전은 유지한다. 적 탄의 새 표시 ID는 별도 카운터로 생성하고 저장에서 제외하며 복원 후 다시 만든다. 원화·사운드 에셋과 공용 `src/data` 밸런스 파일은 변경하지 않았다.

곡선·연결·펄스·궤적은 CanvasItem 셰이더와 짧은 리본을 사용한다. 광편은 독립 CPUParticles 벽시계 대신 풀의 Sprite 슬롯을 전투 dt로 움직여 일시정지·배속과 표시 시간을 맞췄다. 새 일러스트/생성 프롬프트는 없고, 승인된 PNG를 마스크로 재사용했다. 작성한 셰이더·비주얼 데이터 해시는 `provenance.json`, 확장 책임은 `godot/docs/VFX_PIPELINE.md`에 기록했다.

## 범위의 한계

영상은 실제 렌더러의 검토용 상태이며 전투 플레이 녹화가 아니다. 성공 효과의 런타임 콜백 연결은 구현했지만 모든 메뉴 동작을 터치로 전수 플레이하지 않았다. 자료집·분기·각 무기/축복 선택의 공용 반응은 연결했으며 각각의 별도 영상은 만들지 않았다. 실제 전투·Galaxy S24 Ultra·청감·장기 저장 회귀·전체 테스트·빌드·성능 검사는 실행하지 않았다.
