# 2.5D 길드 본부 시안

2026-10-04 · 새 시안 승인 대기. 현재 게임·사용자 프로필·출동 저장은 변경하지 않는다.

넓은 실내 바닥 위에 시설별 독립 투명 PNG를 배치하고 SD 각성자가 걸어 다니는 경영 화면이다. 카메라 높이 40°·수평 회전 18°, 왼쪽 위 광원, 밝은 아이보리·목재와 네이비·청록 소재를 공통 기준으로 사용한다. 입체적인 재질 표현을 2D PNG에 담으며 3D 엔진이나 모델은 추가하지 않는다.

- `Preview-Guild-2p5D.cmd` 또는 같은 폴더 `project.godot`: 독립 시안 실행. 실행용 cmd는 확장 본부부터 보여준다. F1은 초기 본부, F2는 확장 본부, F3은 시설 관리창이다. Escape는 관리창을 먼저 닫고, 창이 없으면 시안을 종료한다. `--expanded` 인수로 확장 본부부터 열 수 있다.
- `index.html`: 실제 Paperlogy·Barlow 폰트를 사용하는 로컬 갤러리. 초기·확장·시설 관리 915×412 화면과 에셋 확대판을 보여준다. 화면에 맞추기와 원본 크기 보기를 지원한다.
- `01-initial.png`·`02-expanded.png`·`03-management.png`: 독립 Godot 시안의 초기 본부·확장 본부·관리창 캡처. 원본은 `captures/initial.png`·`expanded.png`·`management.png`다.
- `04-assets.png`: 시설·공사·확장 모듈·공용 실내 바닥 확대판. 원본은 `captures/assets-board.png`다.
- `assets`: 운영실·연구·탐험·생산·회복·공방·생환·분석 시설 8개, 공용 바닥, 공사, 수납장·모니터·코어 확장 모듈 3개까지 총 13개 투명 PNG 원본을 보존한다.
- `prompts.json`: 원본 생성 프롬프트. `generated.json`: 실제 생성 출처. `provenance.json`: 원본 경로·프롬프트·PNG 크기·해시·시안 상태를 함께 기록한다.

독립 시안 프로젝트의 경영 변경은 메모리 상태만 사용하며 현재 게임 저장에 기록하지 않는다. 시안이 승인되기 전에는 main 진입 경로, 런타임 manifest·exporter·Godot 에셋에 연결하지 않는다. 캡처 확인은 실제 플레이·모바일 실기기 검증을 대신하지 않는다.
