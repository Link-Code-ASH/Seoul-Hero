# 2.5D 길드 시안 확인

2026-10-04. 독립 프로젝트의 PNG 13종 가져오기와 스크립트 로드, 915×412 화면 3장 및 1536×1100 원화 보드 캡처를 확인했다. 프레임과 조작은 기존 PNG 소재·네이티브 폰트를 사용한다. 강한 축소에는 밉맵을 생성하고 선형 필터로 표시한다.

이 프로젝트에는 게임 autoload가 없고 Profile·출동 저장을 읽거나 쓰지 않는다. 실제 main 경로·guild_action·runtime manifest·exporter와 본 폴더는 이번 변경에서 수정하지 않았다. 시안 버튼은 표시와 메모리 안내만 바꾸며 경영 규칙 검증 도구가 아니다.

확인 범위: 초기 본부, 8구역 확장 본부, 관리판의 글자/내부 스크롤 영역, 시설 원화 확대판. 터치 실기기·플레이 QA·전체 테스트는 수행하지 않았다.

로컬 샌드박스가 엔진의 user:// 캐시와 편집기 설정 쓰기를 제한했고 Windows 인증서 저장소 경고가 나왔다. 원화 가져오기·스크립트 로드·화면 캡처는 완료되었으며 게임 저장에 접근하지 않았다.

상태: 새 시안 승인 대기. 승인 후 현재 워크트리의 길드 경로에 연결하며 저장 형식과 경영 규칙은 유지한다.
