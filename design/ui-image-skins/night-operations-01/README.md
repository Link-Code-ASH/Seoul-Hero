# A. 서울 야간 작전 — 독립 UI 소재 시안

내장 image_gen으로 생성했다. 게임 연결·자동 테스트·빌드·게임 실행은 하지 않았다. 아래 확인은 PNG 메타데이터·가장자리 알파 픽셀 검사와 생성 결과 육안 확인이다. 미술 평가는 포함하지 않는다.

## icons_extra_04 — 프레임 제거 편집본 (미완성)

- [source/icons_extra_04.png](source/icons_extra_04.png): `icons_extra_03.png`를 내장 image_gen 편집 입력으로 사용했다. 사각 바탕 판·테두리·모서리 장식을 제거한 4×2 아이콘 시트다. 순서는 자료집·보급 티켓·제작·가방 / 닫기·확인·등급 별·전체 스탯이다.
- 실제 해상도 1536×1024, 32비트 RGBA. 네 변의 alpha>0 픽셀 수(위/아래/왼쪽/오른쪽)는 **0/0/1/0**으로, 요청한 가장자리 완전 투명 조건에 실패했다. 아이콘 밖 알파 완전 제거 및 최소 120px 간격도 충족 판정을 내리지 않았다. 승인용 최종본으로 취급하지 않는다.
- SHA-256: `286f7961c2a16106e7f8f7212cb45e321a662e51ae70f9ebc83f538a5f645d57`.
- [prompts/icons_extra_04.txt](prompts/icons_extra_04.txt)에 이 PNG를 생성한 실제 프롬프트 전문을 저장했다. 생성 결과를 그대로 복사했으며 기존 파일은 보존했다. 다른 폴더 수정·빌드는 하지 않았다.

## 프롬프트·출처

- `prompts/<PNG와 같은 파일명>.txt`: 각 호출에 실제 전달한 프롬프트 전문. 공통 스타일·시트 설명·해상도/투명 여백 요청과 수정 지시를 포함한다.
- `provenance.json`: 모든 15개 PNG의 파일 경로, 생성 파일 수정 시각(시간대 포함), 도구, 프롬프트 경로, 실제 해상도, 알파 확인, 가장자리 검사, SHA-256. `icons_extra_04`는 미완성 검사 상태를 추가로 기록했다.
- `_01`은 편집 입력 없이 신규 생성했다. 이후 번호는 직전 번호를 편집 입력으로 사용했다. 원본과 모든 중간 수정본을 보존했다.
- PNG는 생성 결과를 그대로 복사했다. 별도 리사이즈·알파 후처리는 하지 않았다.
