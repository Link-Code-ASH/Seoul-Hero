# 실제 연결 확인 · 2026-10-05

사용자의 “구현해” 승인 후 PNG 4종을 공통 뒤로가기·타이틀 행동·게이트24 조작에 연결했다. 타이틀 로고 면은 `ops/info`, 큰 정보창과 팝업·상점 진열·구매면은 기존 승인 소재다.

실제 `HeroMetaScreens`·`HeroGateScreen`·`HeroShopScreen`·`HeroImageSkin` 클래스를 Godot 4.7.2 Compatibility로 렌더링했다. `--ui-preview --guild-office-preview --compact-controls-preview`로 사용자 저장 읽기·쓰기, 전투 시뮬레이션, 경제·오디오 콜백을 차단했다. 별도 시안 프로젝트의 캡처를 실제 구현으로 사용하지 않았다.

- 915×412 6장, 844×390 2장: 타이틀 이어하기/새로하기·시작하기, 복귀 조작, 상점 두 탭, 구매 불가·74px 아이템/81px 조합, 큰 재화·8자리 가격.
- 실제 소재·폰트 경로·조작 크기·화면 영역·전체 문구 맞춤 검사 59개 통과. 8개 캡처의 글자 잘림·넘침 진단 0건이며 실제 이미지의 여백·선명도·색도 확인했다.
- 타이틀 버튼 19px/52px, 일반 상점 조작 16px/44px, 뒤로 24px/44×44px를 유지했다. 모든 상태에 동일한 PNG 영역·24px 분할·안전 여백을 사용한다.
- 새 청록 버튼이 시안보다 어두워지는 원인을 캡처에서 확인했다. 새 `compact` 소재만 캔버스 색과 텍스처를 한 번씩 적용하도록 상태 셰이더를 보정했다. 기존 승인 표면은 원래 셰이더 경로를 유지한다. 보정 후 8장을 다시 렌더링했고 검사 59개가 통과했다.
- 원본 PNG 4종은 승인 시안과 동일한 해시다. exporter에 새 이미지 ID 4개를 추가했고 누락 0건이다. 콘텐츠 JSON의 이미지 외 모든 데이터는 연결 전과 동일하다.
- 뒤로가기·입장 조건·상점 구매/독립 리롤/잠금/분기/조합 콜백은 기존 경로를 유지했다. 이 캡처에서 실제 버튼을 누르거나 경제 동작을 실행하지 않았다.
- 필요한 가져오기·스크립트·셰이더 실행 차단 오류는 없다. 제한된 환경의 user:// 로그·셰이더 캐시·인증서 경고는 남았으나 렌더링은 정상 완료했다.

실제 사용자 게임·터치·실기기·전투 플레이·전체 테스트·빌드·성능 검사는 수행하지 않았다. `compact-controls-layout.json`과 `verification.json`에 상세 확인 기록을 보존했다.

## 게이트24 상단 프레임 축소 · 추가 피드백

무기/아이템은 보이는 PNG 면을 72×30px, 리롤은 120×30px로 줄였다. 기존 84×44px·140×44px 조작 영역과 글자 16px·중앙 y49는 유지한다. 보이는 면은 y34~64로 제목 영역 y31~66 안에 들어간다. 리롤 화살표는 새 면의 왼쪽 여백 안으로 옮겼다.

같은 저장 차단 캡처 8장을 갱신했다. 915×412와 844×390의 보이는 면 크기·제목과의 세로 범위 검사 12개를 추가해 총 71개가 통과했고, 전체 문구 맞춤 0건이다. 두 크기의 실제 이미지를 직접 확인했다. 새 PNG·콘텐츠·가격·콜백 변경은 없다.
