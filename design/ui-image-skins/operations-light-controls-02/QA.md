# 확인 기록 · 2026-10-05

독립 Godot 4.7.2 Compatibility 프로젝트에서 915×412 시안 6장을 렌더링했다. 타이틀 이어하기/새로하기·시작하기 상태, 복귀 조작, 게이트24 무기/아이템, 소재별 선택·비활성 상태를 포함한다.

- 실제 캡처에서 큰 정보판의 유지, 얇은 조작 프레임, 글자 중앙 정렬과 여백을 확인했다. 타이틀 버튼 19px, 일반 버튼 16px, 44px 조작 영역을 유지한다.
- 소재판의 이전 소재는 승인된 원본을 명시적으로 참조한다. 새 소재와 같은 파일명을 사용해도 이전 프레임이 교체된 것으로 비교되지 않는다.
- 탭 선택은 동일 PNG·분할·안전 여백을 사용하고 색조만 바뀐다. 비활성은 동일 프레임에 채도·명도만 보정한다.
- 74/81px 하단 조작, 긴 상품명, 효과·패널티, 잠금, 구매 불가, 표시용 8자리 가격과 무기 6개를 포함했다. 표시값은 검토용이며 실제 가격·능력치를 수정하지 않았다.
- `captures/layout.json`의 글꼴 높이·줄 수·가로 폭·화면 영역·44px 조작 검사에서 잘림/넘침 0건이다. 실제 이미지를 함께 확인했다.
- 게임 스크립트·데이터·씬·셰이더·공용 콘텐츠 원본 182개 해시가 작업 전후 동일하다. 저장·게임·오디오 autoload는 이 프로젝트에 없다.
- 새 PNG는 생성 원본·추출 원본·4배 표시용 마스터로 분리했다. `provenance.json`에 실제 생성 크기와 사용 영역, 안전 여백을 기록했다.
- 스크립트·소재 누락이나 렌더링 차단 오류는 없었다. 제한된 실행 환경의 user:// 로그·셰이더 캐시·인증서 저장소 경고는 남았으나 캡처는 정상 완료했다.

게임 연결·구매/리롤/복귀 콜백·실제 터치·전투 플레이·실기기·성능·전체 테스트·빌드는 확인 범위가 아니다. 새 소재 승인 후 런타임 역할에 연결한다.

검사 결과: `verification.json`. 재생성은 `prepare_assets.py`와 독립 프로젝트의 `-- --capture`를 사용한다. 라이브 소스 검사는 `check_preview.py`이다.
