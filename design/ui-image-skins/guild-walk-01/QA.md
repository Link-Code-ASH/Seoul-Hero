# 걷는 길드 시안 확인

2026-10-04 · 사용자가 “이 시안으로 게임에 연결해줘”라고 승인했다. 현재 워크트리의 런타임 길드 경로에 연결하며 본 폴더와 사용자 저장을 직접 변경하지 않는다. 아래 캡처 결과는 승인 전 독립 시안 기준이다.

- 필요한 Godot 클래스 등록·스크립트 로드: 통과.
- 915×412 독립 상태의 초기 1층·확장 2층·관리창·전체 보기 캡처: 통과.
- 캡처에서 발견한 TextureRect 기본 최소 크기와 월드/HUD 표시 순서를 수정해 다시 캡처함.
- 시안은 `--ui-preview`로 프로필/출동 저장을 쓰지 않음. 시안 변경은 메모리 본부에만 적용.
- 전체 테스트·자동 이동 QA·수동 플레이·터치 실기기·장시간 플레이·청음: 수행하지 않음.
- 사용자 확인 항목: 방 클릭 후 도착 시 창 열기, 다른 층 승강기 경로, 수동 이동 취소, 창 조작 시 이동 잠금, Escape 우선 닫기, 전체 보기 전환, 직원 배치·탐험 출입, 공사 완료 후 위치 유지.

기존 `ui_preview` 길드 fixture의 퇴역 API 참조를 현 승인 화면으로 바꾸고 해당 씬 단일 `guild` 캡처를 로드함. 로드 오류 없음. 기존 화면 자체의 텍스트 겹침 경고 1건은 새 걷는 시안 경로에 해당하지 않으며 이번 작업에서 전체 UI 회귀를 확장하지 않음. CLI `--check-only --script`는 프로젝트 오토로드를 제공하지 않아 사용하지 않고 씬 로드로 확인함.

승인 연결: 구조 PNG·atlas 영역·승인 출처를 assets와 Godot 사본에 보존했고 exporter에 추가했다. exporter 1회 실행 성공, 이미지 누락 없음. 길드 v2·출동 v3 형식과 경영 데이터는 변경하지 않는다. 연결 후 씬 로드 확인은 실행 연결 작업에서 별도로 기록한다.

2026-10-04 연결 후 확인: 승인 구조 PNG의 Godot 가져오기 및 기존 main `--open=guild` 경로 읽기 전용 로드 90프레임 통과. 스크립트·이미지 로드 오류 없음. 현재 워크트리만 변경했고 영구/출동 저장 형식과 사용자 저장을 수정하지 않음. 전체 테스트·수동 플레이 QA는 추가하지 않음. 독립 캡처 도구도 승인된 런타임 구조 이미지/영역을 읽도록 연결함.
