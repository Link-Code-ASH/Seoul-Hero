# 서울 히어로 UI 시안 v2

v1에 대한 피드백을 반영한 **시안 수정**입니다. 실제 게임 코드·저장·화면 API는 변경하지 않았습니다. v1 원본도 보존했습니다.

- 로비: 석양의 전망 대신 게이트·연기·비상등이 있는 어두운 서울. 6개 메뉴의 이미지 영역과 이름 명판을 분리했습니다. 길드 메뉴에만 따뜻한 카페와 한서아를 남겼습니다.
- 무기 선택: 크롬 광택과 두꺼운 장식을 줄이고 이미지·명판·성능·선택 버튼의 위치를 나눴습니다. 선택된 무기만 청록 조명이 들어옵니다.
- 자료집: 밝은 종이 대신 어두운 작전 정보 패널. 분류 / 이름 목록 / 이미지 / 수치 / A·B 분기를 분리했습니다. 선택된 이름의 밝은 강조를 유지했습니다.

## 산출물

`http://127.0.0.1:5174/design/ui-premium-v2/index.html`

- `lobby.png`, `weapons.png`, `archive.png`: 각각 1830×824. 논리 크기 915×412.
- `comparison.png`: 세 화면 나란히 비교.
- `index.html`, `preview.ts`, `preview.css`: 편집 가능한 HTML 시안.
- `assets/*-surface.png`: 프레임과 내부 소재·분할선을 함께 제작한 이미지. CSS 단색으로 내부를 덮지 않습니다.
- `assets/provenance.json`: 내장 imagegen 원문 프롬프트와 제작 출처.
- `assets/reused-assets.json`: 기존 콘텐츠 이미지 참조. 일부 v1 참조는 비교 기록으로 포함되어 있습니다.

글자는 Paperlogy, 본문 14~16px·보조 13px, 버튼 높이는 최소 44px입니다. 실제 무기 이름·기본 스탯·분기는 현재 데이터에서 읽습니다. 목록만 내부 스크롤하며, 작은 화면에서는 기본적으로 로비 한 장을 보여주고 위쪽에서 시안을 바꿉니다.

시안 내 선택은 고정 예시이며 게임을 실행하지 않습니다. PNG 렌더링에서 배치와 구획을 확인했으며 실제 스마트폰 플레이 검증은 수행하지 않았습니다.
