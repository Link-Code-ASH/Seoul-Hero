# 서울 아케이드 B · 첫 피드백 단계

915×412에서 상점·로비·전투 HUD를 먼저 적용한다. 밝은 표면, 남색 구조, 주황 주요 동작, 청록 선택 상태를 공유하며 실제 글자는 Godot로 그린다. `concept-b.png`는 선택한 image_gen 방향 참고다. 임의 마스코트·영문 장식·생성 상품 그림은 게임 UI에 사용하지 않는다.

- 상점은 기존 데이터/원화를 사용하는 4칸 한 줄 진열이다. 이름·효과·패널티·가격을 정렬하고 상품 본문에서 상세를 연다. 자물쇠는 진열 유지이며 잠긴 상품도 구매 가능하다. 전체 스탯은 별도 상세에서 읽는다.
- 로비는 기존 배경 선택·밝기 보정·날씨·시설 아이콘과 동작을 유지한다.
- HUD는 기존 HP·웨이브·재화·장비 표시를 새 안내판 구조로 묶는다.
- 선택·성장·자료집·설정·팝업 전체 확장은 이 세 화면의 세부 피드백을 반영하는 다음 단계다. 해당 화면의 기존 팔레트는 유지한다.

실제 Godot 시안 PNG는 `preview/{shop,lobby,hud,shop-states}.png`다. `shop-states`의 큰 재화·긴 상품명·구매 불가 가격은 해당 시안의 메모리 복사본에만 적용한 예시다. 실제 콘텐츠/저장은 수정하지 않는다.

재생성: Godot Compatibility 렌더러로 `res://tools/arcade_preview.tscn`을 실행하고 `-- --ui-preview --output=<이 폴더의 preview 절대 경로>`를 전달한다. 저장 쓰기가 차단되지 않으면 도구는 종료한다. 이 과정은 시안 출력이며 실제 전투/구매/저장 QA가 아니다.

새 맵 원화와 전체 생성/보정 프롬프트는 `assets/environment-sd/`에 보존한다. UI 방향 참고 프롬프트는 이 폴더의 `provenance.json`에 있다.
