# UI 시안 v3

이전 시안과 게임 코드는 보존했습니다. 실제 출동·구매·저장 동작은 연결하지 않은 디자인 미리보기입니다.

- 로비: 서울 배경을 넓게 노출하고 별도 출동 버튼을 배치했습니다. 하단 시설은 새 투명 아이콘 5개로만 표시하며 **배경 프레임이 없습니다**. 약한 채도·명도 보정과 알파 형태의 부드러운 그림자로 배경에 맞췄습니다. 상단 재화·자료집·설정·음악은 각각 별도 소재 영역을 사용합니다.
- 무기 선택: 수치와 ‘선택됨’ 문구를 없앴습니다. 무기를 눌러 이미지 조명과 태그가 바뀌는 것을 볼 수 있습니다. 근접/원거리 강화 적용을 분명히 표시합니다.
- 자료집: 이미지에는 설명을 넣지 않습니다. 설명·태그·기본 성능·성장 표를 분리했습니다. 목록에서 실제 무기를 선택하고 공통/A/B 분기를 전환할 수 있습니다. ‘성장 전체’는 오른쪽 영역을 확대된 표로 전환합니다. 긴 목록과 표만 내부 스크롤합니다.

성장 표는 `src/stats/WeaponStats.ts`와 `DEFAULT_STATS`를 사용해 Lv.1~10 성능과 직전 레벨 대비 증감을 계산합니다. 캐릭터 특성·아이템 등은 제외하고 게임의 기본 피해 보정을 포함합니다. 따라서 raw weapon base.damage와 표의 실제 피해량은 다를 수 있습니다. 무기 태그도 원본 capability를 사용합니다.
