## 화면별 재료

| 화면 | 재료와 배치 | 선택·조작 |
|---|---|---|
| 로비 | 서울 석양 배경, 알파가 있는 은색 유리, 6개의 동일 크기 시설 메뉴 | 메뉴 이름·시설 이미지, 가벼운 화살표 |
| 무기 선택 | 어두운 완충재와 금속 거치대를 한 장으로 제작, 상세 장비 패널 | 마력검 거치대의 조명과 ‘선택됨’; 별도 대형 조작부 |
| 자료집 | 회청색 바인더, 파스텔 섬유 탭, 밝은 미세 섬유 문서 | 이름 행, 선택 강조, 하단 맵 이동 |

프레임과 내부 소재는 생성 이미지에 함께 들어 있습니다. CSS는 위치·글자·이미지 크기와 합성만 담당하며, 패널 내부에 단색이나 그라데이션을 채우지 않습니다. 로비의 시설 장면 가장자리에는 알파 마스크를 사용합니다. 유리 메뉴에는 실제 알파가 있고 배경 도시가 비칩니다.

글꼴은 기존 Paperlogy 400/800을 사용합니다. 게임 본문 14~16px, 보조 정보 13px, 주요 제목 20~27px입니다. 시안 버튼의 터치 영역은 최소 높이 44px입니다. 클릭 확대·체크 아이콘은 없습니다.

## 데이터·이미지

- `preview.ts`: 현재 `src/data/weapons`의 이름·설명·기본 수치·최대 레벨·분기 단계·분기 설명을 직접 읽습니다. 시작 장비는 현재 전투 무기 7종을 표시합니다. 빈 8번째 거치대는 여백이며 신규 콘텐츠가 아닙니다. 자료집 목록은 등록된 무기 전체를 읽습니다.
- `src/data/images.ts`: 기존 고해상도 시설·운영자·무기·재화 이미지를 조회합니다. 원본을 복제하거나 덮어쓰지 않습니다.
- `assets/provenance.json`: 생성 도구, 원문 프롬프트, 에셋 용도.
- `assets/reused-assets.json`: 재사용 이미지 ID와 원본 경로.
- `assets/lobby-background.png`: 패널 없는 서울 배경.
- `assets/glass-menu.png`: 프레임과 내부 반사를 포함한 투명 유리 이미지.
- `assets/weapon-surface.png`, `assets/archive-surface.png`: 목표 화면 비율에 맞춘 완성 소재판.
- `assets/lobby-surface.png`: 최초 구성 참고용. 최종 HTML은 별도 배경과 알파 유리 이미지를 사용합니다.

## 제작·확인 범위

OpenAI 내장 이미지 생성으로 제작하고 HTML 텍스트·실제 콘텐츠를 합성했습니다. 별도 임시 Chrome 프로필의 헤드리스 렌더링으로 세 화면을 2배 출력한 뒤 잘림과 겹침을 확인했습니다. 게임 플레이나 저장에 접근하지 않았습니다. 실제 스마트폰 확인과 게임 전체 적용은 이번 범위가 아닙니다.

시안은 소재와 배치를 비교하기 위한 고정 비율 구성입니다. 무기·자료집 소재판은 현재 한 장이므로 실제 UI 적용 시에는 가변 내용에 맞는 독립 패널·선택 상태 이미지를 만들고 이미지별 9분할 영역을 지정해야 합니다. 그때도 내부 소재를 CSS 색상으로 대체하지 않습니다. 생성 PNG는 디자인 원본이며 모바일 배포용 최적화는 적용 단계에서 진행합니다.
