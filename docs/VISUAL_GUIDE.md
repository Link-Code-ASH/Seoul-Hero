# 비주얼 가이드

## 메인 로비

UI 크기와 배치는 Galaxy S24 Ultra 가로 화면(약 915×412 CSS px, 안전 영역 포함)을 우선 확인합니다. 본문은 Pretendard 계열, 숫자와 계기판 표기는 Barlow Condensed를 사용합니다. 설명 문구보다 이미지·수치·선택 상태를 우선합니다. PWA 아이콘은 일반 아이콘과 마스크 가능한 전용 아이콘을 분리해 삼성 브라우저의 홈 화면 잘림과 흰 여백을 줄입니다.

로비 메뉴는 문자·SVG 기호 대신 `assets/ui/lobby`의 반실사 투명 PNG 오브젝트를 사용합니다. 청회색 금속과 절제된 청록 조명, 현대 서울 작전 장비라는 공통 질감을 유지합니다. 에셋별 생성 설명은 같은 폴더의 `provenance.json`에 기록합니다. 로비 화면에서는 광화문 배경을 저채도·저명도로 낮추고 메뉴 오브젝트의 실루엣이 먼저 읽히게 합니다.

## 현행 화면 분위기

현행 UI는 매끈한 웹 대시보드보다 거친 탑다운 생존 게임의 장비 화면을 지향합니다. 먹색·카키·바랜 종이색을 기본으로 하고, 각진 패널·경고색 테이프·인쇄물 같은 카드·강한 그림자를 사용합니다. 월드는 채도를 낮추고 대비와 가장자리 비네트를 더해 현대 서울의 밤거리와 전투 개체가 분리되어 보이게 합니다. 특정 게임의 화면을 그대로 복제하지 않고 이 원칙을 서울 히어로의 기존 서울 판타지 이미지에 적용합니다.

UI의 최종 표현은 `ui-modern.css`가 담당합니다. 서울의 현대적인 행정·교통 시스템을 연상시키는 짙은 흑청색 패널, 얇은 금속선, 절제된 회청색 강조색을 사용합니다. 종이 문서, 낡은 보급소, 과한 네온 장식은 최종 화면에 사용하지 않습니다. HUD·통합 편의점·메뉴는 같은 간격과 모서리, 글자 계층을 공유합니다.

단일 픽업인 마력석은 연한 보라색의 길쭉한 결정으로 표현합니다. 어두운 서울 배경에서 읽히되 전투 효과보다 튀지 않도록 발광 면적을 제한합니다. 별도의 코인·경험치 결정 이미지는 사용하지 않습니다.

## 스타일과 시점

현대 서울의 평범한 골목과 이계 생물의 대비를 사용합니다. 약간 위에서 내려다보는 3/4 시점의 셀 채색 일러스트이며, 실제 게임 이동과 충돌은 기존 2D 탑다운 좌표를 그대로 사용합니다. 사진, 과도한 갑옷, 관광지의 사실적 재현은 피합니다.

## 대표 에셋

`assets/characters`의 민트 재킷 남성 각성자, `enemies`의 붉은 돌 괴물과 주황색 사냥개, `bosses`의 보라색 파수꾼을 사용합니다. 공격은 무기별 색을 사용하고 마력석은 연보라색 결정입니다.

배경은 가상의 편의점24, 지하철 입구, 버스 정류장, 가로등, 나무 화단입니다. 한글 간판과 생활 시설로 서울 동네를 표현합니다. 실제 상표를 사용하지 않습니다. 모든 소품은 장식이며 플레이어·적·투사체를 막지 않습니다.

## 크기와 가독성

- 캐릭터는 월드 높이 약 56, 일반 적은 42–55, 보스는 163 단위입니다. 충돌 반경은 기존 데이터 값을 유지하며 그림 전체와 정확히 일치하지 않습니다.
- 장식은 고정 배경 타일 크기의 17–57%로 배치하며, 불투명도 60–72%로 전투 개체보다 낮게 표시합니다.
- 새 정적 에셋 권장 원본: 캐릭터 256–512px, 보스/건물 512–1024px, 탄/아이템 64–256px. 생성 도구 출력은 요청 크기와 달라질 수 있습니다. 현재 12종은 생성된 투명 PNG 원본을 보존합니다(전체 약 13.4MB). 모바일 배포 전 리사이즈·압축 및 아틀라스 작업이 후속 과제입니다.
- 투명 배경과 여백을 유지합니다. 캐릭터와 괴물의 발이 잘리지 않게 하고 광원은 좌상단으로 통일합니다.
- 플레이어는 민트·흰색, 적은 붉은색·주황색, 보스는 보라색, 탄은 금색이며 마력석은 연보라색입니다. 색뿐 아니라 사람/덩어리/네발 동물/결정 실루엣으로 구분합니다.
- 바닥과 소품에는 강한 발광·번쩍임을 넣지 않습니다. 적은 피격 시 옅은 분홍색으로 잠깐 표시합니다.

## 연결과 추가 방법

1. 용도별 `assets` 하위 폴더에 명확한 영문 이름으로 PNG를 저장합니다.
2. `src/data/images.ts`에 URL과 크기 비율을 등록합니다.
3. 캐릭터/적/무기의 `visual.sprite`에 등록 키를 지정합니다. 마력석은 WorldRenderer의 공통 표현을 사용합니다.
4. 배경은 `src/data/environment.ts`의 고정 배경 타일 장식 목록에 이미지 키·상대 위치·크기·불투명도를 지정합니다.
5. 실제 1280×720 및 휴대전화 가로 크기에서 확인합니다. 세부 묘사보다 실루엣과 공격의 방향이 먼저 읽혀야 합니다.

`ImageAssets`는 시작 시 한 번 로드하고, 여러 Sprite가 같은 Texture를 공유합니다. 스테이지 변경 시 고정 배경의 표시 객체를 정리하지만 공용 텍스처를 함께 파괴하지 않습니다. 로드 실패 시 기존 도형 렌더링이 비상 표시를 담당합니다.

UI는 기존 CSS 구조를 유지하며 게이트·캐릭터·강화 아이콘과 SVG 체력 아이콘을 적용했습니다. 체력 바는 수치 변화에 맞춰 CSS 너비가 바뀌며 게임 개체를 DOM으로 만들지 않습니다.

## 주인공 절차적 이동 표현

송진우는 사용자가 제공한 `player_awakened_kickboard_02.png` 정적 이미지 한 장만 사용합니다. 현대적인 각성자가 청록색 마력 킥보드를 타고 이동하는 오른쪽 아래 방향의 사선 자세입니다. 생성형 이미지의 프레임 일관성 문제 때문에 전통적인 걷기 스프라이트 시트는 게임에서 로드하지 않습니다. 과거 생성 시트와 출처 기록은 비교 자료로만 보존합니다.

`PlayerMotion`은 실제 이동 거리와 속도에서 미세 모션 주기를 계산합니다. 이동 중에는 진행 방향 기울기, 세로 들썩임, 좌우 흔들림, 약한 눌림/늘어남, 관성 스큐를 작은 범위로 합성합니다. 출발과 정지는 즉시 전환하지 않고 짧게 완화되며, 이동 속도가 빨라지면 같은 거리를 더 빨리 통과하므로 주기도 자연스럽게 빨라집니다. 그림자는 몸과 킥보드가 들릴 때 작고 옅어지고, 킥보드 바닥 잔광과 손의 마력 잔광은 이동 반대쪽으로 짧게 남습니다. 이동 사운드는 재생하지 않습니다.

오른쪽 계열 이동은 원본 이미지, 왼쪽 계열 이동은 같은 이미지를 수평 반전합니다. 위아래 이동에서는 마지막 좌우 방향을 유지합니다. 이 처리는 렌더링 전용이므로 키보드·터치 입력, 이동 속도, 충돌 판정에는 영향을 주지 않습니다.

F3의 좌우 걷기 2초 버튼은 개발 확인용으로 실제 플레이어를 2 게임 초 동안 이동시킵니다. 직접 이동 입력을 하거나 일시정지하면 중단합니다. 무적을 켜면 안전하게 확인할 수 있습니다.


현재 아레나는 사용자가 제공한 붕괴된 서울 교차로 이미지를 16:9 바닥 배경으로 사용합니다. 이 Stage에서는 게이트만 추가로 표시하며, 편의점·지하철 입구·버스 정류장·가로등·화단/나무 장식 데이터와 파일은 보존하지만 그리지 않습니다. 바닥 이미지는 낮은 불투명도로 표시해 전투 개체가 우선 읽히게 합니다. 제거된 각성 에셋의 생성 기록만 assets/archive에 보존하며 게임에서는 로드하지 않습니다.

## 10단계 가독성 확장
마력석은 연보라 결정 하나로 통일합니다. 설치물 탄은 청색 꼬리로 구별합니다. 서울 배경에 주차 차량·화단·아파트 창/간판 도형을 추가하며 전투보다 낮은 대비를 유지합니다. 편의점은 가격표와 계산대, 2열 모바일 진열을 사용합니다. 아래 전투 이미지 확장 전까지 추가 적은 캐시된 도형 실루엣을 사용했으며, 해당 도형은 이미지 로드 실패 시 fallback으로 남깁니다.

## 전투 이미지 확장

2026-09-13에 기존 도형 적을 실제 이미지로 교체했습니다. 철각 거인, 마탄 사수, 군집 벌레, 돌진 뿔짐승, 폭렬 포자, 분열 점액, 치유 사제, 틈새 소환사, 수문 방패병, 그림자 잠복자와 균열 여왕, 자동 포탑은 투명 PNG입니다. 충돌 반경과 게임 규칙은 바꾸지 않고 `visual.sprite`만 연결했습니다. 생성 원본 경로와 최종 프롬프트는 `assets/combat-art-provenance.json`에 보존합니다.

지뢰와 마력장 발생기는 어두운 금속 장비와 연보라·청록 마력 핵을 사용한 투명 PNG로 교체했습니다. 수호 표창은 `assets/weapons/weapon_guardian_shuriken_01.png` 한 장을 전투·상점·자료집·성장 화면에 공통으로 사용하며, 표창 자체 회전과 플레이어 주위 공전은 코드로 처리합니다. 기존 단검 이미지는 제작 이력으로 보존합니다. 연쇄번개도 전용 투명 PNG를 사용합니다. 관통탄·포탑탄은 작은 화면에서 선명한 윤곽을 유지하도록 투명 SVG를 사용합니다. PNG와 SVG 모두 `src/data/images.ts` manifest에서 관리되며 실패 시 기존 도형이 비상 표시가 됩니다.

공격 이펙트는 판정과 분리된 짧은 RunEffect 이벤트로 생성합니다. `CombatVfx`가 진행률을 읽어 발생·변화·여운·소멸 단계를 그리며, 정적 이미지를 잠깐 표시하는 방식은 핵심 전투 효과에 사용하지 않습니다. 마력탄은 발사 섬광과 이동 잔광, 적중은 중심 flash·확장 ring·spark, 크리티컬은 더 큰 십자 flash, 적 사망은 파편과 연무를 사용합니다. 검격은 공격 방향을 따라 펼쳐지는 두 겹의 arc sweep과 끝점 spark로 구성합니다. 폭격·지뢰·적 광역 공격은 중심 flash, 팽창 core, shockwave, 파편, 연기 tail을 시간 순서대로 조합하며 실제 피해 반경과 같은 원형 범위를 사용합니다. 마력장은 반투명 피해층, 육각 회로, 안쪽으로 수축하는 파동과 마력 입자를 조합합니다.

2026-09-20부터 발사·적중·크리티컬·검격·폭발·지뢰 폭발·적 사망·연쇄번개의 중심 표현은 생성형 투명 PNG를 사용합니다. PNG는 단독으로 나타났다 사라지지 않고 기존 타임라인 안에서 확대, 회전, 투명도 변화가 적용됩니다. 코드 기반 ring, spark, smoke, trail은 동작과 범위를 전달하는 보조 레이어로 유지합니다. 그래서 질감은 손으로 그린 게임 이미지에 가깝지만 판정과 발생·여운 타이밍은 기존처럼 정확하게 유지됩니다. 원본 경로와 프롬프트는 `assets/vfx-art-provenance.json`에 기록합니다.

# 주간 규칙과 협회 코인

주간 게이트 특성 5종은 검붉은 침식 계열, 단군의 축복 7종은 옅은 금·청록·강철 계열의 반실사 래스터 아이콘으로 구분합니다. 개별 투명 PNG는 `assets/ui/archive`에 보관하며 자료집과 출동 대기실이 같은 이미지를 사용합니다. 협회 코인은 `assets/ui/ui_association_coin_01.png`를 사용합니다. 생성 원본은 넓은 간격의 아이콘 시트로 제작한 뒤 각 항목을 384px 정사각형으로 분리했으며, 협회 코인은 512px로 정리했습니다.

## 설치물 접지와 마력장 질감 (2026-09-21)

자동 포탑은 특정 방향을 향한 포신 없이, 높은 중앙 기둥과 6방향 발사구가 달린 회전 관부로 표현합니다. 어느 방향의 적도 공격하는 실제 동작과 실루엣이 일치하며, 중심이 맞는 접지 그림자 하나만 사용합니다. 지뢰·마력장 발생기는 바닥 접촉 위치에 이중 타원 그림자를 사용하며 본체 불투명도를 약간 낮춰 서울 배경과 같은 광량에 놓이도록 합니다. 마력장 피해 영역은 `effect_mana_field_aura_01.png` 두 겹을 낮은 불투명도로 서로 반대 방향 회전시키고 호흡하듯 강도를 바꿉니다. 판정 반경과 이미지 지름은 일치하며 기존 육각형·선 기반 마력장 표현은 사용하지 않습니다. 에셋은 OpenAI 내장 이미지 생성으로 제작했고 최종 프롬프트와 원본 경로는 `assets/vfx-art-provenance.json`에 기록합니다.

# 메타 시설 배경
