# 구조·모바일 UI 점검 — 2026-09-25

## 구조 판단

핵심 전투 규칙은 data → state/systems → core → rendering/input/ui 경계로 나뉘어 있다. systems/meta/stats에서 DOM, window, localStorage, Pixi 의존은 발견하지 않았다. 전체가 무구조인 상태는 아니지만, UI에는 여러 차례 개편한 CSS가 중첩되어 실제 선택 표시와 모바일 크기를 덮어쓰는 문제가 있었다.

- 콘텐츠/밸런스: `src/data`; Run/Meta: `src/state`; 순수 규칙: `src/systems`, `src/meta`, `src/stats`.
- 저장과 이관: `src/save`; 클라우드 연결: `src/cloud`; 요약 플레이 기록: `src/analytics`.
- 실행 연결: `src/core`; 플랫폼 입력: `src/input`; 월드 표시: `src/rendering`, `src/world`.
- 메뉴/자료집/시설/상점: `src/ui`; 스타일: `src/styles`; 제작 도구: `scripts`.
- `dist`, `node_modules`, `.npm-cache`, `test-results`는 생성물/도구 캐시이며 Git 제외 대상이다. 콘텐츠 원본이나 저장 데이터로 취급하지 않는다.

## 정리한 항목

- main.ts에서 CSS 18개를 개별 불러오던 구조를 `styles/main.css` 하나로 통일. 기존 화면 스타일 순서를 보존하고 `mobile-viewport.css`를 마지막에 적용한다.
- 모든 버튼에 적용하던 고우선순위 :not 체인이 selected 스타일을 이기던 문제를 :where 기반 기본 재질로 수정했다.
- import 연결을 조사해 실제 main 진입점에서 사용되지 않는 `Neighborhood.ts`, `SceneryTile.ts`, `data/environment.ts`를 제거했다. 과거 편의점/나무 이미지와 생성 출처는 보존했다.
- 현재 화면에서 사용하지 않는 `gate-lobby.css`와 GameUI의 구형 심도 스크롤 코드를 제거했다.
- 고정 원점 카메라와 화면 여백을 현행이라고 설명하던 PLAZA_VISUAL 문서는 `docs/history`로 이동하고 제작 이력임을 명시했다.
- 사용 중인 이미지와 이전 생성 원본이 섞인 assets는 manifest 및 provenance와 연결되므로 일괄 삭제하지 않았다.

## 모바일 수정

- 무기 선택은 4열 자동 행으로 현재 7종 모두 표시. 향후 항목이 늘면 목록 내부만 스크롤한다.
- 모바일에서 숨기던 선택 완료 표시를 복구했다. 금색 테두리/체크, aria-pressed, 자료집/성장 목록 선택 강조를 함께 사용한다.
- 심도 선택의 선택됨 표시, 헤더 높이, 하단 페이지 버튼을 수정했다.
- 캐릭터/무기/축복 선택 시 및 상점 갱신 시 해당 목록 스크롤 위치를 유지한다.
- 협회 인장과 코인 표시를 분리하고, 출동 확인·성장 이미지가 이름/컨테이너와 겹치지 않도록 크기를 제한했다.
- 자료집 첫 두 행이 눌리던 고정 행 설정을 제거했다. 분류/맵 전환은 고정하고 목록/상세만 스크롤한다.
- 상점 전체를 제한 높이의 헤더/본문/하단 버튼으로 나누었다. 상품과 능력치만 내부 스크롤하며 전투 시작은 항상 보인다.
- 웨이브 종료·결과 화면을 모바일 높이에 맞추고 결과의 통계 6개와 3개 버튼을 한 화면에 배치했다.

## 확인 범위

- 실제 Chromium 브라우저 915×412 CSS px에서 로비, 맵/심도/각성자/무기/출동 확인, 성장실 3탭, 협회, 오프라인 보상, 보급 화면, 자료집 캐릭터/몬스터, 설정을 열어 확인했다.
- 실제 무기 선택·다음/이전·로비 이동과 선택 유지도 확인했다.
- 저장에 영향을 주지 않는 렌더링 fixture에서 상점, 내부 스크롤, Lv.5 분기, 보유 축복 7종, 보급 결과, 부활, 일시정지, 웨이브 종료, 결과 화면을 확인했다.
- 800×360에서 상점 내부 스크롤과 고정 버튼을 추가 확인했다.
- TypeScript 통과. 관련 UI/게이트 진입 테스트 4개 파일, 11개 테스트 통과.
- 실제 S24 Ultra의 삼성 인터넷/PWA, OS 키보드·시스템 바 및 터치 드래그는 직접 연결한 기기가 없어 미확인이다. 이번 브라우저 확인은 기기 해상도에 맞춘 렌더링 검증이며 물리 기기 테스트를 뜻하지 않는다.

## 남은 유지보수 과제

- 과거 화면 CSS가 여전히 여러 파일에 분산되어 있다. 한꺼번에 삭제하면 실제 사용 중인 공통 재질/상점 규칙도 없어지므로, 이후 화면 변경 시 해당 화면 규칙을 한 소유 파일로 옮기면서 줄여야 한다. 새 `override-final` 류 파일을 추가하지 않는다.
- AppController는 약 780줄로 화면 명령·저장·오디오 연결이 집중되어 있다. 순수 게임 규칙은 분리되어 있지만 다음 메타 기능을 추가할 때 명령 처리 책임 단위로 분리할 여지가 있다.
- assets 전체를 불필요 파일로 간주하지 않는다. 원본/파생 이미지/생성 출처와 manifest 사용처를 함께 확인한 뒤 정리한다.
- Production build 통과. 주 번들 약 742 KB의 기존 크기 경고는 남아 있다. PC 1440×900에서도 상점 하단 고정 배치를 확인했다.
- 추가 확인: 800×360에서 구형 display:block 규칙이 게이트 하단을 밀어내는 문제를 발견해 명시적 3행 grid로 수정했다. 목록 내부 스크롤 중에도 다음 버튼이 유지되고, 915×412에서는 무기 7종이 모두 한 화면에 표시됨을 재확인했다.
