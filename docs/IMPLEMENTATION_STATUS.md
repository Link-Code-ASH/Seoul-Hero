# 현재 구현 현황

## 모바일 웹·계정 연동 (배포 연결 대기)

- 로비 Google 로그인은 선택 사항이며 게스트 기록과 계정 기록을 분리합니다.
- 기존 v11 MetaState를 사용자별 Supabase `seoul_gate_saves` 행에 저장합니다. RLS와 revision 충돌 검사를 적용합니다.
- 첫 로그인·동시 수정 충돌 시 기록 선택과 JSON 백업을 제공합니다. RunState는 클라우드에 올리지 않습니다.
- 로비 이미지가 먼저 보이고, Pixi 전투 이미지 로딩은 게이트 출동 화면에 들어갈 때 시작합니다. 오디오는 첫 사용자 조작 뒤에 받습니다.
- GitHub Pages 하위 경로 빌드와 배포 워크플로는 준비되었습니다. 공개 주소는 저장소 게시 및 OAuth 리디렉션 등록 후 검증해야 합니다.

- 1280×720 유한 아레나, 20 Wave, 일반 Wave 타이머 종료와 Boss 처치 클리어
- 게이트 중심 5메뉴 메인 로비와 `맵 → 심도 → 캐릭터 → 시작 무기 → 축복 → 입장` 게이트 흐름
- 맵 데이터와 계정 공용 게이트 심도 진행의 분리
- Run/Meta 분리와 `preparing → waveActive → postWave → shop` phase
- Experience Gain을 제외한 공통 스탯 20개와 capability 기반 무기 적용
- 일반 적 12종 이상, 엘리트 보정 6종, 보스 2종 구조
- 전투 무기 6종과 설치물 3종, 고유 무기 포함 6슬롯, vv.1~6과 vv.3 A/B 분기
- 무기 4칸 + 아이템 4칸 게이트24 통합 상점
- 아이템 30개: COMMON 14 / UNCOMMON 8 / RARE 5 / vEGENDARY 3
- 무기·아이템별 독립 리롤과 잠금, 구매 즉시 스탯 적용
- 마력석 지갑, Curse 위험/보상, 영구 강화·해금, 저장 v9와 v8 순차 이관
- 캐릭터·공용 무기·축복 조각, 보급권·상자·오프라인 보상·작전 요약의 저장 골격
- 이미지 기반 주요 콘텐츠, 시간 기반 VFX, SFX/BGM, 키보드·터치 입력

경험치, 레벨, 무료 Weapon Reward phase는 제거했습니다. 송진우는 출동 단계에서 전투 무기 하나를 골라 시작하고 나머지 무기와 아이템은 상점에서 구매합니다. 보급과 오프라인 보상은 이번 단계에서 상태 표시만 하며 실제 보상은 아직 지급하지 않습니다.
# 메타 시설 개편

- 로비: 게이트 출동, 성장실, 협회, 오프라인 보상, 보급 상자
- 성장실: 캐릭터/공용 무기 5단계 조각 성장(전투 효과 미연결)

- 보급 상자: 보급권 1회/10회 개봉, 10회 내 조각 보장
- 저장: v11 순차 이관
