# 성장 구조

한 판의 성장은 마력석을 사용한 상점 구매로 통일했습니다. 적에게서 마력석을 회수하고 Wave가 끝나면 게이트24에서 무기 또는 아이템을 삽니다. 경험치, 레벨, 무료 무기 선택권은 사용하지 않습니다.

- 무기: 신규 획득, vv.2~6 강화, vv.3 A/B 분기
- 아이템: 20개 공통 스탯과 태그 기반 특수효과
- 영구 성장: Run 종료 후 정산된 Meta 마력석으로 별도 구매

한 Wave에서 못 먹은 마력석은 지갑으로 들어가 직후 상점에서는 쓸 수 없습니다. 다음 Wave에서 마력석을 하나 주울 때마다 지갑에서도 하나가 추가 회수됩니다. 새 Run에서는 고유 무기 vv.1만 지급되고 일반 무기, 아이템, 상점 재고는 초기화됩니다. Meta의 영구 강화와 해금은 유지됩니다.
