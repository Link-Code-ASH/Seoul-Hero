# 서울 히어로 게임 디자인

현대 서울의 생활 공간에 게이트가 열리고 각성자가 몬스터를 상대하는 2D 탑다운 자동 전투 게임입니다. 배경은 장식이며 충돌하지 않습니다.

## 한 판의 흐름

메인 로비의 게이트 메뉴에서 `맵 → 심도 → 캐릭터 → 시작 무기 → 단군의 축복 → 입장 확인` 순서로 출동 정보를 정합니다. 출동 뒤에는 PREPARING → WAVE_ACTIVE → POST_WAVE → SHOP → 다음 Wave로 진행합니다. 마지막 Boss Wave는 보스를 처치해야 STAGE_CLEAR가 되고 HP가 0이면 GAME_OVER입니다. 전투 시간은 WAVE_ACTIVE에서만 흐릅니다.

맵과 게이트 심도는 별개입니다. 현재 광화문 맵의 기본 아레나는 1280×720이고 20 Wave입니다. 크기와 Wave 구성은 `src/data/maps`에서 관리하며, 심도 해금은 모든 맵이 공유합니다. 무한맵과 연속 15분 생존 방식은 폐기했습니다.

## 마력석과 지갑

마력석은 게이트 이후 핵심 거래 물질이 된 연한 보라색 결정입니다. 적에게서 회수하면 한 판용 재화가 증가하며 무기와 아이템 구매에 함께 사용합니다. Run은 0 마력석에서 시작합니다. Wave 종료 때 못 먹은 마력석은 직후 상점에서는 쓸 수 없고, 다음 Wave에서 마력석을 하나 주울 때마다 지갑에서도 하나가 추가 회수됩니다.

경험치·레벨·각성 결정 능력치 선택은 사용하지 않습니다. 한 판의 능력 성장은 상점 무기와 아이템으로 통일합니다.

## 무기와 아이템

송진우와 강태훈은 출동 대기실에서 전투 무기 7종 중 하나를 선택해 Lv.1로 시작합니다. 총 6슬롯에 전투 무기와 설치물 무기를 함께 장착합니다. 신규 무기와 Lv.2~10 강화는 게이트24에서 구매합니다. Lv.5 강화 직후 추가 비용 없이 A/B 분기를 고르며 해당 Run에서 고정됩니다.

편의점은 무기 4개와 아이템 4개를 동시에 판매합니다. 아이템은 30개, 4등급입니다. 두 상품군은 구매·리롤·잠금을 독립적으로 관리하며 가격은 Wave에 따라 자동 증가하지 않습니다.

## 위험과 코인샵

Curse는 적 능력치·스폰·엘리트 확률을 높이고 종료 보상도 높입니다. 게이트 공략으로 받은 협회 코인은 로비의 협회 메뉴에서 기초 훈련과 콘텐츠 허가를 구매하는 데 사용합니다. 구매 내역과 해금은 MetaState에 남고 Run 무기·아이템·게이트24 재고는 새 판에서 초기화됩니다.

## 메인 로비

로비는 게이트 출동, 미래전략지원실, 협회, 오프라인 보상, 보급 상자의 다섯 영역으로 나뉩니다. 단군의 축복은 게이트 입장 과정에서 선택하며 자료집에서 전체 내용을 확인합니다. 미래전략지원실에서는 캐릭터·공용 무기·축복의 성장 단계를 저장하지만 전투 수치에는 아직 적용하지 않습니다. 보급권으로 상자를 개봉하고 오프라인 보상을 수령할 수 있습니다.

## 게이트 심도와 주간 규칙

각 게이트는 20 Wave이며 심도 1부터 계정 공용으로 순서대로 해금됩니다. 심도가 오르면 적 체력·공격력·밀도가 선형적으로 증가하고 이동 속도는 상한을 둡니다. 10심도 단위의 몬스터·엘리트·보스 변화는 `src/data/gateProgression.ts`에서 누적 적용합니다.

최초 클리어 보상은 캐릭터별이며 각성자 협회 코인 100개입니다. 높은 심도를 먼저 클리어하면 그 캐릭터가 받지 않은 하위 심도 보상도 함께 지급합니다. 아직 클리어하지 못한 심도에서 사망하면 완료 Wave 수만큼 소량의 협회 코인을 받습니다. 협회 코인은 현장 마력석과 분리되며 메인 메뉴의 코인샵에서 기초 훈련과 콘텐츠 허가를 구매하는 데 사용합니다. 최초 클리어 보상량은 심도·주간 규칙·축복과 무관하게 동일합니다.

주간 게이트 규칙은 한국 시간 일요일 05시에 교체되며 한 사이클 동안 중복되지 않습니다. 각 규칙은 플레이어에게 불리한 패널티와 고정 베네핏을 한 쌍으로 자동 적용하며 별도 선택은 없습니다. 단군의 축복은 미래전략지원실에서 조각 18개로 해금하고 성장시키는 별도 콘텐츠입니다. 출동 전 해금한 축복 하나를 선택하며, 보유 축복이 없으면 축복 없이 입장합니다.
# 메타 시설

로비의 메타 기능은 미래전략지원실, 협회, 오프라인 보상, 보급 상자로 나뉜다. 성장 단계는 전투 수치에 아직 적용하지 않는다. 협회는 협회 코인 영구 강화를 제공한다. 오프라인 보상은 최대 24시간 동안 30분마다 확률적으로 3·4·5·7 협회 코인을 적립하고 생환석을 낮은 확률로 추가한다. 보급 상자는 보급권 기반 1회·10회 개봉을 담당하며 생환석 3등급도 각각 독립 확률로 지급한다. 생환석은 편의점에서 판매하지 않으며 전투 중 쓰러졌을 때 1개를 소비해 부활한다.
