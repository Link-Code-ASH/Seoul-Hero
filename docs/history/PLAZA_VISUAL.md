# 2026-09-14 현행 비주얼

이 규칙은 과거 교차로·스크롤 맵 설명보다 우선합니다. 1280×720 고정 아레나 전체를 화면에 맞추며 비율이 다르면 여백을 둡니다. 카메라는 원점 고정입니다. 적은 바깥 경계에서 생성되어 안으로 들어오고 플레이어 경계는 그대로 적용합니다.

광화문 광장의 차분한 청회색 바닥, 셀 셰이딩 각성자·12종 적·보스 2종, 청록/금색 UI를 사용합니다. 과거 교차로와 별도 동네 장식은 표시하지 않습니다. 움직임·접지 그림자는 기존 절차적 표현을 유지합니다.

assets/backgrounds, characters, enemies, ui에 새 원본을 보관합니다. InventoryArt.ts는 8×6 아이콘 시트의 상품/무기/잠금 순서를 관리합니다. ImageAssets.ts는 적 시트를 공유 텍스처로 잘라 사용합니다. plaza.css가 모든 화면의 최종 공통 스타일입니다. COMMON 회청색 / UNCOMMON 민트 / RARE 파랑 / LEGENDARY 금색.

아이템 구매·리롤·잠금과 무기 분기 규칙은 그대로입니다. 광범위한 테스트 및 브라우저 플레이 검증은 이번 요청에 따라 수행하지 않습니다. 화면 크기별 카드 배치와 적 진입 난이도는 직접 플레이 확인 대상입니다.
