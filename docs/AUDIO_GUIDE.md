# 오디오 가이드

## 플레이와 설정

처음 화면의 버튼을 누르거나 키를 누르면 브라우저가 소리 재생을 허용합니다. 자동 재생 제한을 우회하지 않습니다. 설정에서 전체·음악·전투 효과음·UI 효과음을 따로 조절하며 즉시 저장합니다. 화면의 사운드 버튼으로도 음소거를 전환합니다.

메뉴 음악, 전투 음악, 보스 음악을 재생합니다. 편의점에서는 전투 음악을 이어갑니다. 음악 전환은 약 0.35초 동안 부드럽게 이루어집니다. 일시정지·강화 선택에서는 음악을 25%로 낮추고, 탭이 숨겨지면 오디오를 중지합니다. 배속은 음악의 속도나 음높이를 바꾸지 않습니다. 결과 화면에서는 음악을 멈추고 클리어 또는 게임 오버 효과음을 재생합니다.

## SFX 설계와 제작 방식

SFX는 스마트폰 시스템음처럼 짧고 정돈되어 있으면서도 사건의 시작이 분명한 음색을 목표로 한다. 단순히 부드럽고 흐릿한 소리를 만들지 않는다. 모든 핵심음은 짧은 저중역 어택, 둥근 음정 중심부, 짧고 깨끗한 여운으로 구성한다. 날카로운 고주파 beep, 긴 sparkle, 거친 distortion은 피하며 전투 중 반복되어도 피곤하지 않게 한다. SFX는 48kHz, 24비트 PCM WAV로 만든다.

- 발사: 짧은 저중역 어택과 250~650Hz의 빠른 하강음
- 피격·처치: 100~500Hz 중심의 둥글고 분명한 충격
- 폭발: 짧은 시작점, 50~210Hz 몸체, 저역으로 제한한 연기성 여운
- 검격: 짧은 바람층 뒤에 붙는 작은 접촉 충격
- UI·알림: 360~715Hz 안에서 정리된 짧은 음정과 따뜻한 저역 받침

`scripts/generate-clear-sfx.mjs`가 SFX 원본 생성기다. 특정 기기의 원음을 복사하지 않고 짧은 공명음, 제한된 대역의 noise, 저중역 충격을 새로 합성한다. 부드러운 saturation으로 밀도를 더하되 최종 peak에는 충분한 여유를 둔다. 발사·일반 피격·처치 등 반복음은 2~3개 variation을 순환하며 작은 pitch/volume 변화만 추가한다.

## 믹싱

- Master: 전체 출력
- BGM: 메뉴·전투·보스 음악
- Combat SFX: 무기, 적중, 폭발, 피격, 마력석, 경고
- UI SFX: 버튼, 구매, 리롤, 잠금, 보상, Wave 알림

Combat SFX 버스에는 9.5kHz의 완만한 low-pass filter를 적용해 거친 고역을 줄인다. 생성 원음의 주요 에너지는 대부분 50~2200Hz에 두어 필터에 기대지 않고도 편안하게 들리게 한다. 최종 compressor/limiter는 겹친 순간의 피크만 부드럽게 잡으며, 개별 효과음 자체에도 충분한 여유 음량을 둔다. 최대 16 voice 중 4개는 중요 알림을 위해 남겨 둔다. 보스 경고·플레이어 피격·무기 구매·결과음은 낮은 우선순위 소리에 묻히지 않도록 처리한다.

## 파일

`assets/audio/sfx`에는 27개 게임 사건에 대응하는 효과음과 반복음을 위한 variation 파일이 있습니다. 마력석 획득음은 사용하지 않습니다. 플레이어의 마력 킥보드 이동에도 주행음·바퀴음·발걸음 같은 이동 SFX를 사용하지 않습니다.

`assets/audio/bgm`에는 메뉴용 `seoul_after_dusk_01`(24초), 전투용 `gate_patrol_01`(약 17.14초), 보스용 `the_gate_keeper_01`(15초) 루프가 있습니다. Gate24에서도 별도 곡으로 바꾸지 않고 전투 BGM을 이어갑니다.

SFX는 48,000Hz 모노 24비트 PCM WAV, BGM은 22,050Hz 모노 16비트 PCM WAV이며 Web Audio API로 재생합니다. BGM은 베이스·패드·아르페지오·타악기와 루프 경계에 이어지는 딜레이로 구성한 오리지널 곡입니다.

SFX를 다시 만들려면 `node scripts/generate-clear-sfx.mjs`, BGM을 다시 만들려면 `node scripts/generate-audio.mjs`를 실행합니다. 음색 개선 시 청각적으로도 확인하고 음량 피크와 루프 연결을 검사하세요.

## 구조와 교체

- `src/data/audio.ts`: variation 파일, 그룹, 개별 음량, 반복 제한, 동시 재생 수, 우선순위, pitch 범위.
- `src/audio/AudioManager.ts`: 로딩·디코딩·브라우저 재생 허용·볼륨 그룹·variation·limiter·음악 전환·숨김·정리.
- `src/audio/AudioPolicy.ts`: 화면별 음악 선택과 동시 재생 제한.
- `src/core/GameEvents.ts`: 전투에서 발생한 사건을 프레임 단위로 전달합니다. 같은 프레임의 중복 사건을 합칩니다. 전투 로직은 오디오 API를 참조하지 않습니다.
- `AppController`: 사건을 실제 SFX에 연결하고 화면과 음악을 동기화합니다.

파일을 교체하거나 데이터의 URL 목록을 바꾸면 같은 이벤트 연결을 재사용할 수 있습니다. 효과음은 최대 16개 동시 재생이며 일반 효과음은 12개까지 허용해 중요한 알림의 여유를 남깁니다. 반복 제한은 실제 오디오 시간 기준이므로 10배속에서도 소리가 과도하게 쌓이지 않습니다. 오디오 로드 실패는 게임을 중단시키지 않습니다.

F3 개발자 패널에서 등록된 모든 효과음을 선택해 재생할 수 있습니다. 현재 음악, 로드 수, 오디오 상태, 최근 효과음, 누적 재생 수, 동시 음성 수와 출력 신호의 크기도 표시합니다. 출력 수치는 브라우저 내부 신호이며 기기의 실제 스피커 음량까지 확인하는 값은 아닙니다.


무기 성장 알림은 Wave 뒤 WEAPON_REWARD 진입 시 재생합니다. POST_WAVE/WEAPON_REWARD/SHOP에서는 음악을 낮춰 이어갑니다. 각성 전용 효과음과 이벤트·생성 정의는 제거했습니다.

## 10단계 추가 소리
구매·리롤·잠금·무기 선택·분기·치명타·엘리트·Wave 시작/종료·검격·표창·연쇄·폭격·관통·포탑·지뢰 설치/폭발·마력장 SFX를 사용합니다. 폭격과 지뢰는 짧은 저음 충격파·노이즈 감쇠를 합성한 전용 폭발음을 실제 폭발 판정 시점에 재생합니다. BGM은 메뉴·일반 전투·보스 3종이며 SHOP에서도 일반 전투 BGM을 그대로 유지합니다.

연쇄번개는 얇게 찢어지는 전기 노이즈 대신 짧은 저중역 충격이 연속되는 방식으로 표현합니다. 포탑은 작지만 중심이 분명한 공명 타격을 사용하며, 반복 사격이 귀에 걸리지 않게 개별 출력은 낮게 유지합니다. 두 소리 모두 통합 생성기에서 variation까지 다시 만듭니다.
## 반복 전투음 조정 (2026-09-20)

- 수호 표창은 반복 타격 피로를 줄이기 위해 출력과 최소 재생 간격을 강하게 낮췄다.
- 연쇄번개는 밝은 전자음 대신 저중역 방전 레이어를 사용한다.
- 메뉴 클릭음은 variation과 피치 변화를 쓰지 않습니다. 660Hz 기준음과 정확한 옥타브 배음으로 만든 단일 48kHz/24bit 세라믹·유리 계열 클릭을 사용합니다.



## 마력석 획득음

`magic_stone_chime_01~03.wav`는 48kHz 단음 WAV입니다. 짧은 금속·유리 몸통과 빠른 감쇠를 사용하며 UI 버스 gain 0.075, 최소 재생 간격 0.09초, 동시 재생 1개로 제한합니다.

## 보급 상자 개봉

보급 개봉음은 `scripts/generate-supply-audio.mjs`로 생성합니다. `ui_supply_latch_01.wav`는 지속음 없이 0.12초 안에서 끝나는 차가운 금속 접점의 `찰칵 → 철컥` 두 충격이며 개봉 즉시 재생합니다. `ui_supply_fanfare_01.wav`는 상자가 완전히 열린 시점에 재생하는 짧고 따뜻한 2단 팡파르입니다. 기존 `ui_supply_open_01.wav`는 이전 합본 원본으로 보관하지만 현재 재생에는 사용하지 않습니다.
