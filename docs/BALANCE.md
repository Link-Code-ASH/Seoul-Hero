# 밸런스 기준

현재 밸런스 버전은 `2026.09-gwanghwamun-depth1-v4`입니다. 모든 원본 수치의 기준은 **송진우 + 광화문 + 게이트 심도 1**이며, 영구 강화·Run 아이템·주간 특성·단군의 축복·저주가 없는 상태를 100%(배율 1.0)로 봅니다.

## 계산 순서

- 플레이어: 송진우 기본값 → 캐릭터별 상대 보정 → 영구 강화 → 단군의 축복 → Run 아이템과 임시 효과
- 적과 Wave: 광화문 심도 1 Enemy/Wave 데이터 → 스테이지 상대 보정 → 게이트 심도·10심도 이정표 → 주간 특성·저주
- 무기: 무기 기본값 → 레벨과 고정된 A/B 분기 → 계산된 플레이어 스탯

`balanceConfig.ts`의 baseline ID가 공식 기준을 가리킵니다. 광화문 `balanceModifiers`는 모두 1.0입니다. 새 캐릭터나 스테이지는 기준값을 몰래 복제해 조정하지 말고 기준 대비 증가·감소를 명시합니다.

캐릭터 전투 특성은 `src/data/characters`의 `trait`로 정의합니다. 송진우는 모든 무기 피해 +5%, 강태훈은 `family: 'firearm'` 무기(관통 사격·마력 샷건) 피해 +15%입니다. 이 보너스는 다른 피해 증가율과 기본 피해 기준으로 합산하며 공통 20개 스탯에는 넣지 않습니다.

## 게이트와 Wave

심도 1의 HP·피해·속도·생성 배율은 정확히 1.0, 엘리트 추가 확률은 0입니다. 심도마다 적 HP +6%, 피해 +3.5%, 생성량 +2%, 속도 +0.1%, 엘리트 확률 +0.2%p를 적용합니다. 속도 110%, 생성량 300%, 엘리트 확률 25% 상한을 유지하며 10심도 단위 콘텐츠 변화는 별도로 누적합니다.

광화문 심도 1은 일반 적 초당 등장 수를 Wave 1의 약 1.27에서 Wave 20의 약 4.5까지 단계마다 완만하게 늘립니다. 배치 수가 바뀌는 Wave에서도 생성 간격을 함께 조정해 갑작스러운 폭증을 피합니다. Wave 5·10·15에는 각각 거대 추적형, 장갑 방어형, 광폭·재생 속도형 고정 엘리트가 출현합니다.

## 마력석

각 몬스터의 원본 마력석 보상은 v2 대비 30% 낮춘 값이며 이 값이 광화문 심도 1 기준입니다. 실제 엘리트·스테이지 보정 후 드랍 가치로 1~5단계 색과 크기를 결정합니다. 마력석 획득음은 여러 픽업이 겹쳐도 짧은 간격 제한과 단일 동시 재생으로 제어합니다.

## 무기와 상점

10개 무기는 Lv.1~10, Lv.5 A/B 분기를 사용합니다. Lv.2~4는 공통 성장, Lv.5는 분기 선택, Lv.6~9는 분기 발전, Lv.10은 최종 형태입니다. 기존 Lv.6의 기능적 특징은 유지하되 송진우·광화문·심도 1에서 신규 Lv.10의 실전 화력 목표를 기존 최종 화력의 약 85%(허용 80~90%)로 둡니다.

강화 가격은 Lv.2부터 `20 / 26 / 33 / 40 / 48 / 54 / 62 / 69 / 77`입니다(v2 대비 10% 인상, 마력석 단위 올림). 신규 전투 무기는 40, 신규 설치물은 49입니다. 아이템 가격도 v2 기준 10% 인상 후 올림하며 상점과 자료집은 같은 실제 가격을 표시합니다. 패널티 없는 일반 아이템은 작은 단일 효과 또는 동급의 두 효과로 구성합니다. 다수 공격·설치 한도·간접 흡혈처럼 전투 성능이 크게 달라지는 효과에는 다른 능력치 감소와 보유 상한을 함께 적용합니다. 기본 보유 상한은 일반 5, 고급 3, 희귀 2, 전설 1개이며 개별 아이템에 명시한 상한이 우선합니다.
