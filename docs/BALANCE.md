# 서울 히어로 1차 통합 밸런스

현재 버전은 `2026.10-gwanghwamun-balance-v1`이다. Godot 런타임이 기준이며 수치 원본은 `src/data`, 반영은 `node scripts/export-godot-content.mjs`로 한다. 아래 값은 실제 성공률이 검증된 결과가 아니라 첫 플레이 조정의 출발점이다.

## 플레이 목표

처음에는 배우면서 버티고, 빌드가 완성되면 쓸어버리며, 성장한 계정은 예전 층을 확실히 압도한다. 영구 강화 없이 2~3판 적응 후 1층 클리어, 5층마다 성장·빌드를 보완할 고비를 목표로 한다. 주간 변화는 비슷한 총난도 안에서 빌드와 회피 방법을 바꾼다.

20웨이브, 웨이브 사이 전체 회복, 마지막 보스 처치 완료 조건을 유지한다. 생환석은 등급과 관계없이 출동당 1회이며 불사 성냥의 치명적 피해 생존은 별도다. 길드·조각·회수·보급·축복 레벨은 비활성 상태를 유지한다.

## 캐릭터·축복·협회

13명의 역할을 유지한다. 백나리는 치명타 확률 +10%p·치명타 피해 배율 +0.30·HP −8, 박도준은 모든 무기 피해 +5%와 기존 생존·이동 보정을 사용한다. 나머지는 기존 수치다. 캐릭터·축복의 조건부 무기 피해는 공통 피해 증가율과 합산하며 capability/family 조건을 검사한다.

축복은 해금한 고정 1단계 효과를 적용한다.

| 축복 | 효과 |
|---|---|
| 천부인의 맹세 | 모든 피해 +8% |
| 불굴의 장승 | 최대 HP +8%, 방어 +4 |
| 삼족오의 날개 | 이동속도 +5%, 공격속도 +6% |
| 백호의 눈 | 치명타 확률 +6%p, 치명타 피해 배율 +0.20 |
| 도깨비 대장간 | 설치물 무기 피해 +15% |
| 풍요의 매듭 | 마력석 획득량 +8%, 획득 반경 +15% |
| 역린의 계약 | 모든 피해 +20%, 저주 +6 |

협회는 현재 구매 횟수를 n이라 할 때 일반 가격 `20+4n`, 주요 가격 `30+6n`이다. 기존 일반·주요 분류와 구매 횟수·재화는 보존한다. 한계가 있는 능력치는 `한계×누적값÷(한계+누적값)`을 적용하며 한계는 추가 보너스의 단위다.

| 능력치 | 1회 증가량 | 점감 한계 |
|---|---|---|
| HP / 방어 / 초당 재생 | +3 / +2.5 / +0.08 | 없음 |
| 공통 / 근접 / 원거리 피해 | +3 / +3.5 / +3.5%p | 없음 |
| 공격속도 / 치명타 확률 | +3 / +1.2%p | +300 / +65%p |
| 치명타 피해 배율 | +0.08 | 없음 |
| 회피 / 흡혈 | +3 / +0.3%p | +50 / +12%p |
| 사거리 / 공격 범위 | +3 / +2.5%p | 각각 +150%p |
| 지속시간 / 투사체 속도 | +4 / +5%p | 각각 +200%p |
| 이동속도 / 마력석 획득량 | +1.5 / +3%p | +50 / +150%p |
| 획득 반경 / 행운 | +5 / +2 | +200 / +100 |

최종 회피 상한은 60%다. 기존 흡혈 회복 예산(공격당 5, 최대 HP의 5%)과 설치물·소환의 기본 흡혈 금지를 유지한다. 피해·공속 각각 5회/25회 구매의 명목 화력은 약 1.31배/2.80배, HP·방어 같은 구매 규모의 생존력은 약 1.29배/2.84배다. 치명타·피해 반올림·범위 적중은 이 단순 비교에서 제외한다.

## 한 판의 성장

목표 흐름은 첫 상점 구매 1번 → 7웨이브 전후 첫 분기 → 후반 주력 1~2개 최종 강화다. 무기 6슬롯과 기존 가격을 유지한다. 신규 전투 무기 40·설치물 49, Lv.2~10 강화 가격은 `20 / 26 / 33 / 40 / 48 / 54 / 62 / 69 / 77`이다. 무기·아이템 각각 4칸, 독립 유료 리롤·잠금을 유지한다.

10개 무기와 20개 분기는 직접 수정 가능한 Lv.1~10 표를 사용한다. Lv.1은 기존 기본값, Lv.2~4는 기본 피해의 110%·120%·130%다. Lv.5는 기존 첫 분기 형태이며 발사 수·연타를 포함한 명목 출력이 Lv.4보다 최소 10% 높도록 필요한 피해를 보정한다. Lv.6~10은 첫 분기와 기존 최종 형태 사이를 20% 간격으로 보간하고 개수·관통·연타는 정수 반올림한다. 공통 피해 배율 0.85를 유지하며 최종 단계에만 붙던 추가 15% 피해 감소는 제거했다.

성장 확인은 `피해÷주기×개수×연타`를 기본으로 한다. 개수는 투사체·표창·연쇄에만 곱하며, 연쇄는 밀집 대상 총량이고 샷건은 근접 전탄 적중 가정이다. 단일 대상·밀집 적중·관통·설치 가동률을 같은 DPS로 해석하지 않는다. 유료 단계마다 출력은 감소하지 않고 피해·주기·범위·개수 중 하나가 실제로 개선되어야 한다.

연속 폭격은 예약 연타를 실행하고 반복 공격의 흡혈 예산을 공유한다. 중량 표창의 범위는 실제 충돌에 반영한다. 설치물은 수명 만료 시 제거하며 기본 수명은 마력장 12초·포탑 12초·지뢰 20초다.

아이템 55종의 가격·등급·보유 상한·고유 발동을 유지하며 다음 10종만 조정했다.

| 아이템 | 새 효과 또는 패널티 |
|---|---|
| 재생 붕대 | 초당 회복 +0.18 |
| 정밀 안경 | 치명타 확률 +6%p |
| 예리한 숫돌 | 치명타 피해 배율 +0.25 |
| 헌터 혈액팩 / 흡혈 회로 | 흡혈 +1% / +2% |
| 관성 릴 / 지평 거울 | 기존 이득 유지, 최대 HP −12 |
| 개문 승차권 | 기존 이득 유지, 공격속도 −6% |
| 분광 렌즈 | 투사체 추가 유지, 공격속도 −12% |
| 새벽 보온병 | 웨이브 첫 20초 동안 초당 HP 1 회복, 기존 공속 패널티 유지 |

협회의 ‘두 번째 기회’를 해금하면 출동당 무료 리롤 1회가 무기·아이템 진열에 공유된다. 무료 사용은 유료 리롤 횟수와 가격을 올리지 않는다. 모든 슬롯이 잠겼거나 무료 정예 보급이면 사용할 수 없으며, 분기 선택 중에는 기존 구매·리롤·다음 웨이브 제한을 유지한다.

## 층·웨이브·주간

층 d의 곡선은 다음과 같다. 맵·주간·저주 보정은 이후 적용한다.

- 적 HP: `(1+0.03×(d−1))×1.08^floor(d/5)`
- 적 피해: `1+0.025×(d−1)`
- 생성량: `min(1.35, 1+0.01×(d−1))`
- 추격 속도: `min(1.06, 1+0.001×(d−1))`
- 일반 강화 확률: `min(0.12, 0.002×(d−1))`

10·20층 생성량 추가 배율은 없다. 일반 강화 개체에는 5층마다 FAST → ARMORED → BERSERK → CURSED_AURA를 반복 교체하여 하나만 적용한다. 5층 미만의 강화 개체는 FAST를 사용한다. 고정 정예에는 누적하지 않으며 돌진·탄속·공격 예고 시간은 유지한다.

1층 고정 정예 HP는 7웨이브 1,200, 14웨이브 각 1,000, 20웨이브 각 1,200이다. 보스 HP는 6,000이다. 기존 출현 시각·정예 생존 중 일반 생성 감소·14웨이브 폭주는 유지한다.

주간 몬스터는 기존 3종 주간 순환과 3·6·9·12·15·18웨이브 출현을 유지한다. 비중은 해당 웨이브 생성 구성 중 비중이다.

| 몬스터 | 비중 | 본체 HP·자식 제한 |
|---|---|---|
| 가로등 반딧불 | 35% | HP 40, 자폭 유지 |
| 틈새 소환사 | 10% | HP 60, 5초마다 1마리, 동시 2마리·누적 3마리 |
| 분열 점액 | 10% | HP 44, 2마리씩 2세대, 자식 HP ×0.35 |

주간 본체 마력석은 1.2474다. 소환 자식은 일반 보상 ×0.25, 분열 자식은 부모 보상 ×0.15를 지급한다. 자식은 협회 코인·생환석을 드랍하지 않는다. 강화 일반 몬스터의 계정 드랍은 일반과 같고 고정 정예 5코인·보스 25코인은 유지한다.

| 주간 특성 | 적 변화 | 플레이어 이득 |
|---|---|---|
| 경화 | HP ×1.16 | 피해 +8% |
| 난폭 | 피해 ×1.12 | 방어 +6 |
| 과밀 | 생성 ×1.10 | 획득 반경 +20% |
| 추격 | 속도 ×1.06·피해 ×1.04 | 이동속도 +4% |
| 정예 | HP ×1.04·강화 확률 +4%p | 행운 +10 |
| 소모 | HP ×1.10·피해 ×1.06 | 최대 HP +10% |
| 범람 | 생성 ×1.10·속도 ×1.03 | 공격속도 +5% |

## 저장·기록·후속 조정

출동 체크포인트 v5는 `revivals_used`와 `free_rerolls_remaining`을 저장한다. 구형 출동은 두 값을 0으로 순차 이관하고 HP·재화·장비·보정·소모한 아이템 효과를 보존한다. 더 새로운 버전은 덮어쓰지 않는다. 영구 저장 형식은 v4를 유지하며 협회 구매 횟수와 보유 재화를 초기화하지 않는다.

Godot `analytics.json`은 최근 50판의 합계만 기록한다. 시작 밸런스 버전·협회 강화량·시작 스탯·주간 몬스터·부활 횟수·무료 리롤 사용량·이어하기 여부를 포함한다. 구형 기록은 유지하고 알 수 없는 시작 정보는 비워 둔다. 이어하기는 새 콘텐츠와 저장된 상태가 섞일 수 있으므로 첫 평가는 새 출동으로 한다.

구현 확인은 강화 역전·빈 구매·효과 누락·보상 분류·Godot 가져오기와 문법 오류에 집중한다. 실제 플레이 QA는 사용자가 담당한다. 후속 조정은 첫 클리어까지 판 수, 막힌 웨이브, 첫 분기 시점, 보스 처치 시간, 생존을 위해 산 아이템을 중심으로 한다. 재접속 후 이미 쓴 부활·무료 리롤이 다시 생기지 않는지도 확인한다.
