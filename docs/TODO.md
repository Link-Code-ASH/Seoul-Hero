# 다음 개선 후보

- 실제 사람이 기본 능력치로 20 Wave를 반복 플레이하며 생존 난이도·마력석 수급·무기와 아이템 상점 가격을 조정한다.
- Android/iOS 실제 브라우저에서 조이스틱, 손가락 가림, 오디오 재개, 발열과 FPS를 확인한다.
- 아이템 30종의 전용 아이콘과 두 번째 캐릭터의 전용 외형을 제작한다. 적 10종·두 번째 보스·설치물·주요 무기 효과 이미지는 완료했다.
- 이미지 파일 크기와 오디오 로딩 비용을 측정하고 필요하면 압축/지연 로딩한다.
- Item Special Effect의 조건부 이벤트(처치 누적, 낮은 HP, 첫 피격 방어 등)를 후속 요청 범위로 추가한다. 현재 구현은 스탯, 태그별 투사체/연쇄 수, 설치 한도, 간접 흡혈 허용이다.
- 보스 2종과 무기 분기의 장시간 실전 밸런스 및 접근성(색각·터치 크기)을 개선한다.

현재 Run 중간 저장은 제공하지 않는다. 무한맵·각성 결정·연속 15분 생존 구조를 다시 구현할 계획은 없다.
