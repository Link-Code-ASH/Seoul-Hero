# Wave 시스템

기본 광화문 맵은 1280×720 유한 아레나와 20개 Wave를 사용합니다. 크기, 시간, 적 구성, 최대 적 수, 엘리트와 Boss는 `src/data/maps`에서 수정합니다. 맵의 전투 콘텐츠와 계정 공용 게이트 심도 진행은 서로 분리되어 있습니다.

## 흐름

`preparing → waveActive → postWave → shop → preparing → 다음 waveActive`입니다. waveActive에서만 전투 시간과 공격이 진행됩니다. paused는 이전 전투로 돌아가고 stageClear/gameOver는 결과 상태입니다.

일반 Wave 타이머가 끝나면 스폰을 멈추고 적·탄·설치물·예약 공격·공간 검색 참조를 보상 없이 정리합니다. 남은 바닥 마력석은 지갑으로 모은 뒤 POST_WAVE를 약 1초 보여줍니다. 진행 버튼은 항상 게이트24 상점을 열며 별도 경험치나 무료 무기 보상 단계는 없습니다.

다음 Wave에서 마력석 하나를 주울 때마다 지갑에 보관된 마력석 하나가 추가로 회수됩니다. 직전 상점에서는 지갑 잔량을 쓸 수 없습니다.

마지막 Wave는 Boss 처치 전까지 끝나지 않습니다. Boss가 죽으면 남은 픽업 정리와 결과 정산 후 STAGE_CLEAR가 됩니다.

## 개발자 기능

F3에서 현재 Wave 종료, 특정 Wave 이동, Boss Wave 이동, 적 전체 제거, 무적, 배속, 상점 강제 진입을 사용할 수 있습니다. 강제 이동은 기존 전투 개체를 보상 없이 정리합니다.
