## 데이터와 행동 책임
src/data/enemies/index.ts의 EnemyDefinition은 id/name/maxHp/moveSpeed/contactDamage/magicStoneDrop/radius/behavior/visual/tags를 갖는다. radius는 충돌 크기(size)의 반지름이며 visual.sprite가 이미지 식별자다. 현재 일반 적 12종과 보스 2종 모두 전용 이미지가 연결되어 있다. 새 적은 `assets/enemies` 또는 `assets/bosses`에 이미지를 추가하고 `src/data/images.ts`와 visual.sprite를 함께 갱신하며, visual의 색·도형은 로드 실패용으로 유지한다.

같은 행동 콘텐츠는 데이터만 추가한다. 새 행동은 EnemyBehaviors의 처리기와 행동 타입을 추가하고 테스트한다. EnemySystem은 업데이트·격자 검색·소환 대기열, EnemyFactory는 생성/엘리트/Curse, HostileAttackSystem은 적 탄·바닥 공격 수명/방어 경로를 맡는다. 적 ID별 분기를 만들지 않는다.

## 마력석
- 보상을 지급하는 적은 사망 시 마력석을 100% 드랍하며 `magicStoneDrop`이 기본 가치다. 값 1/2/3/8/20을 경계로 1~5등급이 자동 결정되고, 등급이 높을수록 보라색이 진해지고 조금 커진다. 새 적을 추가할 때 보상량과 시각 등급을 함께 검토하며, 엘리트 보정 후의 실제 가치에도 같은 규칙을 적용한다.
- 스폰 위치는 아레나 전체 외곽선에서 길이 비례로 무작위 선택한다. 플레이어 바로 옆은 최소 안전 거리로 제외한다.
- 획득 시 `Currency Gain`을 적용한 값이 한 판용 마력석에 더해진다. 상점 구매는 이 재화만 차감한다.
- Pickup Range로 흡수하며 가까운 픽업은 반경 70 안에서 가치를 합산한다. 30초 후 자동 회수하고 최대 픽업 수에서는 기존 묶음에 합산한다. 일반 Wave 종료는 미처치 적 보상을 만들지 않는다.
- 최종 보스 처치 시 남은 바닥 드랍을 일괄 회수하고 결과를 정산한다.
- 분열/소환 자식의 마력석 가치는 25%다. 한 부모의 생애 생성 수 6, Wave 개체 상한을 함께 지킨다. 현재 자식은 재소환하지 않는 종류만 사용한다.

## 엘리트와 보스
eliteModifiers.ts에 GIANT(크기/체력), BERSERK(속도/공격), REGENERATING(재생), ARMORED(방어), CURSED_AURA(예고 범위 피해), FAST(속도)를 정의한다. modifiers 배열은 중복 제거 후 조합한다. Wave 10은 GIANT, Wave 15는 BERSERK+REGENERATING을 사용한다. 기존 Wave hpMultiplier/rewardMultiplier는 추가 배율로 유지한다.

보스는 일반 엘리트와 별도 boss 플래그와 bossPatterns 배열을 사용한다. 게이트 파수꾼/균열 여왕 2종 데이터가 있으며 첫 Stage는 파수꾼만 사용한다. aoe/charge/volley/summon 패턴을 warning→공격→cooldown 순서로 반복한다. 보스 소환도 수량 상한을 지킨다. 이미 발사된 탄/생성된 바닥 공격은 시전자 사망 후에도 수명까지 유지하며 Wave 정리 시 모두 제거한다.

## Curse 확장
Curse 1당 HP/피해 +1%, 속도 +0.2%, 생성 빈도 +0.5%, 엘리트 확률 +0.1%p. 각 배율 최대 5, 확률 최대 25%. CURSE_RULES로 조정하며 최종 밸런스가 아닌 확장용 초기 공식이다. 현재 확률 엘리트는 FAST를 사용한다. 기본 Curse 0은 아무 영향이 없다. Luck은 아이템 상점 등급 가중치에 사용하며 적 드랍에는 적용하지 않는다.

## 성능과 개발 검증
충돌과 주변 동료 검색은 공간 격자, 픽업 합산은 셀 검색을 사용한다. 모든 적 쌍을 무조건 비교하지 않는다. 플레이어 탄/적 탄/바닥 공격/픽업은 재사용 풀을 사용한다. Wave 정리 시 배열·격자·후보 참조를 비운다. 적 탄 400, 바닥 공격 100 상한. 신규 효과는 Pixi에서 그리고 적별 DOM을 만들지 않는다.

F3에서 적 14종과 엘리트 보정을 선택해 생성할 수 있다. Wave 10/15 및 Boss Wave 이동으로 확인한다. 모든 적 처치는 보상을 지급하고 분열도 발생하므로 완전 정리는 Wave 이동을 쓴다. 적 탄과 예고 수도 표시한다.

## 표현과 성능 확인
10단계에서는 적별 motif 도형과 엘리트 출현음을 연결했습니다. PC 개발자 시험에서 약 500개 적의 렌더링을 관찰했고, 1000개 생성 후 Wave 정리는 자동 테스트로 확인합니다. 성능 수치는 FINAL_QA.md에 기록하며 기기별 보장값이 아닙니다.
