- 사용자 MP3 6개(22,813,801바이트)를 변환 없이 복사하고 원본과 복사본 SHA-256 일치를 확인했다. 메뉴 3곡·길드 1곡·게이트/보스 2곡으로 연결했다.

## 폭격 방향·캐릭터 그림자·상점 문구 수정 · 2026-09-26

- 폭격탄은 낙하 높이를 기준으로 탄두가 목표 지면을 향하도록 회전하고, 꼭대기 부근에서 방향을 부드럽게 전환한다.
- 전투 플레이어·모든 적/보스·길드 캐릭터의 이중 원형 그림자를 오른쪽 아래로 길어지는 단일 그림자로 교체했다.
- 무기 구매 후 빈 진열 카드의 문구가 작은 가로 화면에서 줄바꿈되도록 카드 배치와 흰 공간 규칙을 조정했다.
- `tsc --noEmit` 통과. 사용자가 담당하는 실제 플레이·모바일 화면 QA는 이번 수정에서 수행하지 않았다.

## 성능과 한계
PC 개발자 기능으로 약 506개 적 생성 시 144FPS/6.9ms 표시를 관찰했습니다. 이후 적265/설치물9/투사체2/Pickup21에서도 같은 표시였습니다. 짧은 샘플이며 모든 기기의 성능 보장이 아닙니다. 1000개 적 생성과 Wave 후 참조 정리는 자동 검사에 포함합니다.

개발 중 서버 중단과 localhost 실시간 갱신 WebSocket 연결 오류가 브라우저 로그에 남았습니다. 새로고침 후 위 플레이를 완료했으며 새 게임 코드 예외는 관찰되지 않았습니다. 변경 자동 반영이 멈추면 서버 상태를 확인하고 새로고침하세요. 기본 플레이 주소는 127.0.0.1:5174입니다.

전체 기본 난이도 20 Wave를 사람 조작으로 완주하는 장시간 밸런스 검증, 모든 무기 분기의 주관적 타격감, 모바일 발열/오디오 품질은 남아 있습니다. 적·보스·설치물과 주요 무기 효과는 모두 이미지가 연결되었으며 기존 도형은 로드 실패용 비상 표시로 남아 있습니다. 개발자 조작이 포함된 테스트를 일반 난이도 완주로 간주하지 않습니다.
