# 길드 본부

로비의 `길드 본부`에서 서울 길드 카페를 탑다운 화면으로 탐색한다. 전투는 기존 PixiJS 2D 화면을 유지한다. 본부에서는 오퍼레이터 한서아만 조작한다.

한서아는 사방향 이미지 상체와 별도의 스카이콩콩 스프링·접지부를 사용한다. 상체·스프링·접지부가 시간에 따라 움직이고, 그림자는 접지부 아래에 남는다. 시설은 길드 바닥 이미지에 결합되어 있으며 각 기능 구역을 바닥 경계와 조명으로 구분한다.

시설 데이터는 `src/data/guild.ts`, 구매·이동·접근 판정은 `src/systems/GuildSystem.ts`, 화면 출력은 `src/rendering/GuildRenderer.ts`에 둔다. 시설은 협회 코인 40/80/160을 지불해 최대 3단계까지 올린다.

- 훈련실: 단계마다 기본 최대 체력 +2%. 다른 기본값 기준 퍼센트 효과와 합산한다.
- 회수실: 오프라인 정산의 완료된 30분 구간마다 협회 코인 +1.
- 보급 정비대: 보급 상자 1개를 열 때마다 협회 코인 +1.

저장 v13은 v12에 길드 기본값을 더한다. 해금된 캐릭터 목록이 길드원 명부이며 별도로 중복 저장하지 않는다. 시설 단계만 영구 저장하고 길드 안의 위치는 저장하지 않는다.
