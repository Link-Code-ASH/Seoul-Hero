# 수탐자 본부

로비의 `수탐자 본부`에서 서울 작업실을 이미지 기반 2.5D 화면으로 탐색한다. 전투는 기존 PixiJS 2D 화면을 유지한다. 길드에서도 송진우는 마력 킥보드, 강태훈은 소형 마력 트럭을 타고 이동한다.

본부에서는 전투 이미지와 별도의 귀여운 픽셀 캐릭터를 사용한다. 탑승 캐릭터의 기준점은 바퀴가 닿는 지면이며 그림자와 충돌 위치가 같다. 이동 중에는 작은 기울기, 상하 움직임, 짧은 픽셀 잔광을 적용하되 이미지를 걷기 프레임으로 만들지 않는다. 시설은 각자 바닥 면적에 맞는 그림자를 사용하고, 지면 위치에 따라 캐릭터와 앞뒤 순서를 바꾼다. 전경 난간은 별도 투명 이미지로 가린다.

시설 데이터는 `src/data/guild.ts`, 구매·이동·접근 판정은 `src/systems/GuildSystem.ts`, 화면 출력은 `src/rendering/GuildRenderer.ts`에 둔다. 시설은 협회 코인 40/80/160을 지불해 최대 3단계까지 올린다.

- 훈련실: 단계마다 기본 최대 체력 +2%. 다른 기본값 기준 퍼센트 효과와 합산한다.
- 회수실: 오프라인 정산의 완료된 30분 구간마다 협회 코인 +1.
- 보급 정비대: 보급 상자 1개를 열 때마다 협회 코인 +1.

저장 v13은 v12에 길드 기본값을 더한다. 해금된 캐릭터 목록이 길드원 명부이며 별도로 중복 저장하지 않는다. 조작 캐릭터와 시설 단계만 영구 저장하고 길드 안의 위치는 저장하지 않는다.
