# 게이트24 통합 상점

Wave 흐름은 `POST_WAVE → SHOP → 다음 Wave`입니다. 별도 경험치 레벨업과 무료 무기 선택 화면은 없습니다. 출동 전에 선택한 전투 무기 Lv.1만 지급하며 이후 신규 무기·강화·아이템은 모두 한 판용 마력석으로 구매합니다.

## 진열

상점은 무기 4칸과 아이템 4칸을 동시에 보여줍니다. `RunState.shop.weaponStock`과 `itemStock`은 각각 상품, 잠금, 리롤 횟수를 관리합니다. 두 진열을 리롤해도 상대 진열이나 비용은 바뀌지 않습니다. 산 칸은 비고, 잠근 칸은 리롤과 다음 Wave 상점에서도 유지됩니다. 후보가 부족한 칸은 잘못된 상품으로 채우지 않고 품절로 둡니다.

## 무기

무기 상품은 신규 획득 또는 현재 레벨 바로 다음 강화입니다. 다른 캐릭터 고유 무기, 미해금 무기, 보유 무기의 신규 카드, 최대 레벨 강화, 슬롯이 찼을 때 신규 무기, 같은 진열의 중복 무기를 제외합니다. 총 슬롯은 고유 무기 포함 6개입니다.

가격은 `src/data/shopConfig.ts`에서 관리합니다.

- 일반 신규 36, 설치물 신규 44 마력석
- Lv.2~10: 14 / 18 / 23 / 28 / 33 / 38 / 43 / 48 / 54 마력석
- 무기 리롤 7 → 14 → 21…

Lv.5 강화를 사면 결제 직후 상점 위에 A/B 분기 선택이 열립니다. 추가 비용은 없고 선택 전에는 다른 구매, 잠금, 리롤, 다음 Wave 이동을 막습니다. 선택한 분기는 해당 Run에서 되돌릴 수 없습니다.

## 아이템

아이템 30개를 COMMON 14 / UNCOMMON 8 / RARE 5 / LEGENDARY 3으로 제공합니다. 가격은 각 `ItemData.basePrice`이며 Wave에 따라 자동으로 오르지 않습니다. maxStacks와 해금 조건을 검사하고 구매 즉시 스탯과 특수효과를 다시 계산합니다. 아이템 리롤은 5 → 10 → 15…입니다.

Luck은 현재 해금된 범위 안에서 높은 아이템 등급 확률만 높입니다. 무기 칸 수나 무기 등장 확률에는 적용하지 않습니다.

## 상태와 저장

무기·아이템·상품·잠금·리롤 횟수는 RunState에만 있습니다. 리롤 횟수와 상승 비용은 Wave가 바뀌어도 유지되고, 새 게이트 Run을 시작할 때만 초기화됩니다. Meta 저장에는 들어가지 않습니다.

## 코드 위치

- 상품과 구매 규칙: `src/systems/ShopSystem.ts`
- 가격과 칸 수: `src/data/shopConfig.ts`
- 아이템 데이터: `src/data/items/index.ts`
- 무기 데이터: `src/data/weapons`
- 화면: `src/ui/ShopScreen.ts`
