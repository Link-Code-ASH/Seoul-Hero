# Godot 이식판 작업 규칙

- 사용자의 Godot 전환 요청에 따라 이 폴더는 Godot 4.7.2 Standard, GDScript, 2D Compatibility를 사용한다. 상위 웹게임은 별도 원본으로 보존한다.
- 화면 기준은 Galaxy S24 Ultra 가로 915×412이다. 긴 목록만 내부 스크롤을 허용하고, 버튼의 크기가 누를 때 변하지 않게 한다.
- 밸런스 원본은 현재 상위 `src/data`이며 `scripts/export-godot-content.mjs`로 이 폴더의 데이터를 갱신한다. JSON과 TS에 같은 수치를 각각 수정하지 않는다. 추후 원본 소유권 변경은 명시적으로 정한다.
- 아이템은 수치만 다른 복제품 대신 고유 조건·기능 또는 큰 이득과 패널티를 갖게 한다. 설명과 이미지를 함께 연결하고 발동 상태는 Run/체크포인트에만 둔다.
- `systems`는 게임 규칙, `state`는 Run, `core`는 실행 연결, `presentation`은 화면/소리, `input`은 입력, `save`는 저장, `ui`는 Control 화면을 담당한다.
- 영구 상태와 Run/체크포인트를 구분한다. 웹 저장을 자동 복사하거나 초기화하지 않는다. 미래 버전 파일을 자동 덮어쓰지 않는다.
- 현재 에셋·출처를 보존하고 퇴역 원본은 상위 archive와 이동 기록으로 분리한다. 플레이어·인간/NPC의 새 원화는 큰 머리·작은 몸통·아주 짧은 팔다리의 빈손 SD로 통일한다. PNG 한 장과 공용 모션을 사용하고 캐릭터별/무기별 공격 리그를 만들지 않는다. 전투의 주변 무기 이미지는 표시하지 않으며 공격은 투사체/VFX 계층이 맡는다. 몬스터도 다리 없는 단일 PNG와 공용 모션을 사용하며 구형 부위 리그·3D/Blender는 추가하지 않는다. 제작 규칙은 docs/SD_PIPELINE.md와 docs/COMBAT_ART.md를 따른다.
- 자동 전체 테스트나 수동 플레이 QA를 기본 절차로 하지 않는다. 실행을 막는 Godot 가져오기·스크립트 오류만 필요한 범위에서 확인한다. 실제 모바일/청음 미확인 사항을 완료 보고에 밝힌다.
- Google 로그인/Supabase·APK 배포·개발자 도구 전체·UI 연출 완전 일치가 아직 이식되지 않았다. 다음 작업자는 README의 경계를 확인하고 완료로 오인하지 않는다.
