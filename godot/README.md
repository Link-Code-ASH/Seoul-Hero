# 서울 히어로 · Godot판

Godot **4.7.2 Standard / GDScript / 2D Compatibility** 프로젝트입니다. 기존 웹게임은 상위 폴더에 그대로 있고, Godot판은 여기에서 독립 실행합니다.

## 실행

1. Godot 프로젝트 관리자에서 이 폴더의 `project.godot`을 가져옵니다.
2. 프로젝트를 열고 **F6이 아닌 F5**로 게임을 실행합니다.
3. `시작하기/이어하기 → 작전 투입 → 맵 → 심도 → 각성자 → 무기 → 축복 → 편성 확인`으로 전투에 들어갑니다. 축복이 없을 때도 독립 선택 화면에서 ‘축복 없음’을 선택합니다.

키보드 **WASD / 방향키**, 화면 어디에서나 시작하는 터치 조이스틱, PC 마우스 드래그를 지원합니다. **Escape**는 이전 화면 또는 일시정지입니다. 길드 본부는 왼쪽 건물을 세로 스크롤하고 사무실을 선택해 오른쪽 고정 패널에서 관리합니다. 관리·직원·작업 탭을 사용하며 길드의 Escape는 관리창을 먼저 닫습니다. 상점에서도 오른쪽 `Ⅱ`를 눌러 출동을 종료할 수 있습니다.

편집기 없이 실행하려면 저장소 루트의 `Play-Seoul-Hero.cmd`(로비) 또는 `godot/tools/play.cmd`(타이틀)를 더블클릭합니다. PC·노트북의 저장소 위치와 사용자 이름은 달라도 됩니다. Godot **4.7.2 Standard** ZIP을 압축 해제해 두면 다운로드 폴더·문서의 Godot 폴더·저장소 주변에서 자동으로 찾습니다. 찾지 못하면 최초 한 번 실행 파일 선택창이 열립니다. 선택 경로는 이 기기의 `.godot/launcher/engine-path.txt`에만 기록되어 Git에 올라가지 않습니다. 실행 전에 새 PNG·WAV를 창 없는 에디터로 가져오므로 첫 실행은 조금 걸릴 수 있습니다. Node.js나 기존 PC의 저장 복사는 게임 실행에 필요하지 않습니다.

수정 후에는 실행 중인 게임을 닫고 다시 실행해야 최신 코드가 표시됩니다. 브라우저의 5174 주소는 웹 원본이며 Godot 변경을 표시하지 않습니다.

송진우 빈손 SD와 주변 공격 효과 샘플은 **설정 → SD 캐릭터 샘플** 또는 `tools/play.ps1 -Screen sd-sample`로 확인합니다. 본체 PNG 한 장·손발 공용 최소 모션·투사체/VFX의 확장 규칙은 [SD_PIPELINE.md](docs/SD_PIPELINE.md), 원화 제작 방법은 [캐릭터 제작 가이드](../assets/characters-sd/CHARACTER_GUIDE.md)에 있습니다. 기존 송진우·강태훈·박도준과 신규 10명을 합친 플레이어 13종, 길드 한서아 1종이 동일한 공용 SD 모션을 사용합니다. 윤하린은 2026-10-12 사용자 요청으로 퇴역했습니다.

## 현재 화면과 확인 도구

- 승인된 PNG 프레임·유리 카드·실제 폰트로 타이틀·로비·출동 선택·성장·자료집·상점·설정·팝업을 구성합니다. 선택 목록은 4열 내부 스크롤과 오른쪽 상세판을 사용하며, 새로운 UI는 시안 승인 후 적용합니다.
- 전투 HUD는 작은 체력바·재화·무기 아이콘/레벨·중앙 웨이브와 시간을 사용합니다. 무기 본체를 캐릭터 주변에 띄우지 않으며 공격 투사체/VFX만 표시합니다.
- 광화문은 직각 도로와 동상이 포함된 단일 원화입니다. 고정 카메라로 화면을 채우고 모든 지형을 통과할 수 있습니다. 별도 동상·차량·바닥 타일 표시 경로는 없습니다.
- UI 기준은 915×412이며 PC에서도 같은 배치를 비례 확대합니다. 저장 없이 화면을 캡처하려면 `tools/ui_preview.tscn`, `tools/image_skin_capture.tscn`, 전투 표현만 확인하려면 `tools/combat_feedback_capture.tscn`을 `-- --ui-preview`로 실행합니다. 실제 플레이 QA를 대신하지 않습니다.
- 전투·로비·메뉴 VFX는 [VFX_PIPELINE.md](docs/VFX_PIPELINE.md)의 공용 데이터·셰이더·풀을 사용합니다. 움직이는 실제 표시 캡처는 `tools/vfx_reborn_capture.tscn -- --ui-preview`, 결과 갤러리는 상위 `design/ui-image-skins/vfx-reborn-01`입니다.
- 회수·보급은 승인한 서울 배송 거점·협회 데스크 PNG와 접촉 그림자를 사용합니다. 낮은 드론 부유와 약 0.85초의 분리 뚜껑 개봉은 보상 지급·저장 후 표시하며, 완료/확인/이탈에서는 다시 지급하지 않습니다. 운영 화면 확인 도구는 `tools/support_runtime_capture.tscn -- --ui-preview`, 갤러리는 상위 `design/ui-image-skins/seoul-support-01`입니다.
- 현재 확인 갤러리 원본은 상위 `design/ui-image-skins/runtime-feedback`, `enamel-glass-01`, `combat-feedback`입니다. 구형 시안과 승인 기록은 유지합니다. 소재 규칙은 [UI_GUIDE.md](docs/UI_GUIDE.md), 전투 표현은 [COMBAT_ART.md](docs/COMBAT_ART.md)를 참고하세요.

`tools/open.ps1`로 편집기를 열 수 있습니다. 실행 파일을 옮겼다면 `-EnginePath`로 지정합니다. 개발 화면 바로 열기: 엔진 실행 인수 뒤에 `-- --open=guild`처럼 붙입니다. `lobby / gate / combat / growth / association / offline / supply / settings / archive / guild / graphics / sd-sample`를 지원합니다.

## 데이터와 파일

| 경로 | 책임 |
|---|---|

| `scripts/presentation` | 2D 전투, 길드, 오디오 버스 |
| `scripts/ui` | Godot Control 화면과 공통 이미지 소재 |
| `scripts/save` | 새 로컬 저장·백업·진행 중 출동 복원 |

| `assets` | 실제 사용 이미지·음원·폰트 사본 |

길드 본부는 승인된 고정 패널 시안으로 층마다 사무실 3개를 표시합니다. 새 길드는 3칸, 운영실 Lv.2/3에서 6/9칸을 열며 직원·탐험·공방과 전투 조합법은 유지합니다. 현재 길드는 초기화하지 않고 기존 4/8칸 저장을 최소 2/3층으로 보존합니다. 화면·입력 책임은 [GUILD_OFFICES.md](docs/GUILD_OFFICES.md), 경영 규칙은 [GUILD_SYSTEM.md](docs/GUILD_SYSTEM.md)를 봅니다.

광화문 몬스터 구성(2026-10-10): 일반 몬스터는 모든 층에서 균열체(근거리)·마탄 사수(원거리)·질주체(돌진)·철갑 점액(땅울림) 4종으로 고정하며 층은 난이도 수치만 올립니다. 정예는 맵마다 2종(광화문: 돌진 뿔뱀·해태 균열두)이고 한 판에 1종만 뽑아 7웨이브 1마리, 14웨이브 2마리, 20웨이브 보스와 함께 2마리로 나옵니다. 보스는 전용 패턴 하나만 쓰고 20웨이브에도 일반 몬스터가 계속 나옵니다. 주간 몬스터는 틈새 소환사(소환)·분열 점액(분열)·가로등 반딧불(자폭) 3종이며, 주마다 1종이 모든 맵 공통으로 3·6·9·12·15·18웨이브 선두에 섭니다. 3주 한 묶음 안에서 3종이 무작위 순서로 한 번씩 나오고 같은 몬스터가 2주 연속 나오지 않습니다(웹 `weeklyMonster`와 Godot `HeroRoster.weekly_monster`가 같은 값). 예전 주간 몬스터 10종은 `WEEKLY_MONSTER.reserve`에 데이터만 남아 있습니다. `src/data/gateProgression.ts`의 `WEEKLY_MONSTER.enabled`를 `false`로 바꾸고 다시 내보내면 출현·맵 선택 표시·자료집 목록이 함께 꺼집니다. 정예·보스 출현과 정예 도주는 화면에 문구를 띄우지 않습니다(정예 처치 보급과 균열 폭주 문구만 남음). 규칙은 `src/data/maps/index.ts`·`src/data/gateProgression.ts`, 확인은 `tools/run_structure_capture.tscn`에서 합니다.

현재 콘텐츠는 플레이어 13종, 길드 SD NPC 1종, 무기·설치물 10종, 다리 없는 몬스터 19종, 아이템 55종과 광화문 20웨이브입니다. 웨이브 지갑, 무기 분기·성장, 독립 진열·리롤·잠금, 설치물, 생환석, 심도·주간 규칙, 조각형 축복과 메타 시설을 연결했습니다.

신규 10명의 v02 원화·이름·서울 일상 배경·고유 능력은 상위 `src/data/characters/index.ts`를 원본으로 선택·전투·성장·자료집·아바타·조각 목록에 연결했습니다. 기본 해금으로 기존 저장에서도 바로 선택할 수 있으며 강태훈·박도준의 기존 Godot 뽑기 정책은 유지합니다. 패시브는 기존 20스탯과 설치물 무기 피해 조건을 사용하고 별도 무기·리그는 추가하지 않습니다. 능력 요약은 [제작 계획의 게임 연결 항목](../design/characters-sd/seoul-civilians-01/PLAN.md)에 있으며 게임 플레이·밸런스 QA는 사용자가 담당합니다.

재화 개편은 [ECONOMY.md](docs/ECONOMY.md)를 따릅니다. 계정 최초 완료·반복 완료·사망·포기 보상을 구분하고, 협회 19스탯 반복 강화·조각과 코인 동시 성장·접속 여부와 무관한 30분 회수·1~3종 보급·길드 전문 재료 4종을 사용합니다. 새 화면의 승인 상태는 `design/ui-image-skins/economy-01`에 기록합니다.

무기별 피해·적중·처치, 웨이브별 피해·처치·회수량·최대 적 수, 구매·리롤·지갑·FPS 요약을 메모리에서 합산합니다. 런 종료 시 한 번만 별도 `analytics.json`에 기록하고 최근 50판만 유지합니다. 프레임별 공격 기록을 파일에 남기지 않습니다. 설정의 저장 폴더에서 JSON을 꺼낼 수 있습니다.

현재 이관 단계에서는 상위 웹게임의 `src/data`가 밸런스 원본입니다. 변경 후 저장소 최상위에서 다음 명령을 실행하면 Godot 데이터와 사용 에셋이 갱신됩니다.

```powershell
node scripts/export-godot-content.mjs
```

원본 생성·라이선스 기록은 상위 `assets`와 문서에 보존하며, `.godot` 캐시는 버전 관리하지 않습니다. 퇴역 원화·관절 리그의 원본과 이동 목록은 상위 `archive`로 분리했습니다. 콘텐츠 exporter는 현행 Godot에 필요한 사본만 연결합니다. 파일 소유권과 정리 내역은 [CLEANUP.md](../docs/CLEANUP.md)를 봅니다.

`tools/prepare_vfx_assets.py`는 보존된 VFX 원본에서 공용 효과 PNG만 추출하며 캐릭터·몬스터 프로필이나 맵 원화를 변경하지 않습니다.

## 저장과 배포 경계

- 웹 LocalStorage와 별개로 **새 게임**을 시작합니다. Windows 저장 위치는 `%APPDATA%/SeoulHeroGodot/`입니다.
- `profile.json`은 영구 상태, `run.json`은 진행 중 출동입니다. 5초 간격과 일시정지/앱 중단 시 체크포인트를 기록하고, 재시작 시 `이어하기`에서 일시정지 상태로 복원합니다.
- 전투 체크포인트 v2는 아이템의 발동 카운터·생존 효과 소모 상태를 포함합니다. v1을 순차 이관하며 잘못된 데이터는 복원을 중단하고, 더 새로운 체크포인트는 자동으로 덮어쓰지 않습니다. 길드 경영 지원 스냅샷을 포함한 출동 v3으로 순차 이관합니다.
- 형식 `formatVersion: 4`와 출동 v4를 사용합니다. v2의 층 해금 이관과 v3의 시설·공사·재화·직원·작업 시각을 보존하고, 전문 재료·회수 누적·계정 최초 완료·출동 정산 ID를 추가합니다. 구형 협회 스탯 강화만 환급 없이 0으로 이관합니다. v1은 기존 이관 규칙대로 옛 길드만 초기화합니다. 기존 웹 v13 콘텐츠 구조를 재사용하되 웹 저장 이관은 수행하지 않습니다. 미래 저장 버전을 자동 덮어쓰지 않으며, 이전 저장·백업·내보내기 파일을 보존합니다.
- 배경음악 ON/OFF는 BGM 버스만 제어합니다. 효과음은 Combat/UI 버스와 재생 간격·동시 수 제한을 사용합니다. 로비·길드·전투 음악은 한 플레이어에서 전환합니다.
- **Google 로그인/Supabase 계정 연동, Android APK/AAB 빌드·실기기 검증은 아직 이관하지 않았습니다.** 기존 웹 서비스는 변경하지 않습니다. APK에는 Godot export template, Android SDK/JDK와 서명이 추가로 필요합니다.
- 기존 개발자 도구 전체와 웹 UI의 세부 전환 연출은 동일 기능까지 이식하지 않았습니다. 오프라인 시간 조작·보급권 지급과 화면 바로 열기는 제공하며, 로컬 코어 게임과 시설을 먼저 이전했습니다.

타이틀·로비·출동·시설·자료집·HUD·상점·팝업을 Godot OpenGL로 915×412에서 렌더링하여 이미지 잘림과 프레임·텍스트 배치를 확인했습니다. 읽기 전용 `tools/ui_preview.tscn`을 `-- --ui-preview`로 실행하면 저장을 변경하지 않고 `exports/ui-preview`에 화면 이미지를 만듭니다. 음량·터치 플레이·Android 실기기·장시간 플레이·전체 회귀는 확인하지 않았습니다.
