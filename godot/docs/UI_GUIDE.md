기존 선택 카드의 원본·유리·선택 테두리, 자료집의 책등과 `codex/panel`, 게이트24의 편의점 원화와 구매·잠금 표시, 회수·보급 장면 원화를 유지한다. `cstore/*`는 게이트24 상점, `codex/panel`은 자료집 책 프레임, `support/panel`은 회수·보급 장면, `spy/deploy`는 로비의 작전 단말에만 사용한다. 길드의 선택 탭을 `cstore/next`로 표시하거나 일반 관리 행동에 상점 전용 소재를 연결하지 않는다.

공용 역할은 기능을 기준으로 고른다. 화면명·시설명·보상 종류별로 공용 버튼 외형을 다시 만들지 않는다. 전용 장면 소재를 유지하되 일반 제목·목록·행동·팝업의 역할은 공통 기준으로 맞춘다.

`compact`는 짧은 조작을 위해 테두리를 약 1~2px로 낮춘 PNG 4종이다. 큰 `ops/info`·`ops/popup` 프레임은 유지하며 타이틀 로고 면도 `ops/info`로 맞춘다. 4배 표시용 원본의 모서리 분할은 24px(표시 6px)이다. 내용 여백은 복귀 좌우 8px/상하 6px, 보조 좌우 6px/상하 4px, 탭 좌우 8px/상하 4px, 주 행동 좌우 10px/상하 4px이다. 작은 버튼에도 44px 조작 영역과 기존 16px/타이틀 19px 글자를 유지한다. 기본·선택·눌림·비활성에서 같은 원본·분할·내용 영역을 사용하며 상태는 색조·채도만 바꾼다. 생성 원본·추출 영역·표시용 마스터는 `assets/ui/image-skin/operations-light-controls-02`의 출처 기록에 보존한다.

`compact`의 `preserve_source_color`는 텍스처와 캔버스 색을 중복 곱하지 않게 하여 승인 PNG의 명도를 유지한다. 기존 소재의 상태 셰이더 경로는 바꾸지 않는다. 실제 확인 기록은 `design/ui-image-skins/operations-light-controls-02/runtime/QA.md`에 있다.

게이트24는 승인된 `cstore_bright/*`와 `assets/ui/office-day-01/gate24-bright-01` 소재를 사용한다. 낮 편의점 배경·크림 진열대·노란 가격표·민트 선택·주황 진행 버튼은 상점 전용이며, 남색 글자색도 `HeroShopScreen` 안에서만 적용한다. 상품·인물과 네이티브 폰트, 4칸·44px 입력 영역은 유지한다. 원본·프롬프트·atlas 영역·9분할·실제 캡처 기록은 `design/ui-image-skins/office-day-01/gate24-bright-01`에 보존한다.

게이트24 상단 탭·리롤은 44px 입력 영역과 보이는 PNG 면을 분리한다. 탭은 72×30px, 리롤은 120×30px로 그리며 중앙 y49·글자 16px을 유지한다. `HeroImageSkin.image_button`의 마지막 `visual_inset` 인자는 PNG만 줄이고 입력·글자·상태·콜백은 그대로 둔다. 기본값은 0이며 다른 승인 소재의 표시 크기는 바꾸지 않는다.

## 글자와 행동 이름

- 화면 제목 24px, 섹션 제목 18px, 버튼·탭 16px, 본문 14px, 보조 13px, 기본 숫자 18px을 사용한다. HUD·상점·타이틀의 승인된 밀도 예외를 유지한다.
- BMJUA는 화면 제목, 해옹산스는 섹션 제목, Paperlogy는 본문·버튼·탭, Barlow Condensed는 숫자를 맡는다. 실제 TTF와 기존 출처·라이선스를 사용하고 기능 텍스트는 네이티브로 렌더링한다.
- 제목·버튼·탭은 중앙, 본문은 좌측 상단, 수량·가격·시간의 숫자는 지정된 숫자 칸에 정렬한다. 효과·패널티·조건을 숨기거나 글자를 줄여 프레임 안에 억지로 맞추지 않는다.
- 화면 이름과 콘텐츠 이름을 유지한다. 준비 선택 화면으로 들어가는 행동은 `출동 준비`, 최종 출동 행동은 `작전 투입`이다. 버튼은 `직원 배치`, `채용`, `연구 시작`, `작업 가속`, `보상 수령`처럼 결과가 보이는 동사로 이름을 짓고 탭은 `관리`, `직원`, `작업`처럼 내용 이름을 쓴다.
- 아이콘은 정보와 조작 의미가 있을 때 사용한다. 모호한 조건·횟수·패널티는 글자를 유지하며 타이틀을 기능 아이콘으로 장식하지 않는다. 일반 조작 영역은 최소 44px이며 눌림 상태에서 크기나 글자 위치가 바뀌지 않는다.

## 상태와 승인 경계

기본·선택·잠금·눌림·비활성·위험 상태는 같은 기본 PNG의 기하·9분할·안전 여백·글자 영역을 유지한다. 선택은 민트 강조와 기존 테두리, 비활성은 채도·명도와 상태 글자, 위험은 위험색과 명확한 행동 이름으로 구분한다. 탭 선택을 주 행동 버튼으로 바꾸거나 성장 행 선택을 진행 단계 소재로 바꾸지 않는다.

승인된 여섯 대표 화면과 소재판은 원본으로 보존한다. 실제 구현 캡처와 확인 범위는 `design/ui-image-skins/operations-standard-01/runtime/QA.md`에 기록한다. 새 원화나 배치 변경은 별도로 시안 승인을 받되, 승인된 공용 역할을 같은 기능에 연결할 때 중복 승인을 요청하지 않는다. 저장 초기화·복사 없이 필요한 가져오기·스크립트 오류와 화면 배치만 확인한다.

`HeroImageSkin.header`는 일반 화면의 제목·복귀·재화를 맡는다. 재화는 네이티브 HBox의 자연 폭과 6px 간격으로 묶어 값 갱신에도 함께 정렬한다. `HeroImageSkin.image_button(..., "ops/tab", ..., selected)`는 같은 PNG를 유지하고 선택 색조만 바꾼다. 일반 네이티브 컨테이너는 `HeroUI`가 입력·텍스트·스크롤을 담당하고 승인 PNG 표면을 연결한다.
