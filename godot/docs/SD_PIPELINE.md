# 빈손 SD와 주변 공격 효과

현역 플레이어 13명(송진우·강태훈·박도준과 신규 10명), 길드 한서아 1명 모두 빈손 SD PNG와 공용 모션을 사용한다. 윤하린은 2026-10-12 사용자 요청으로 퇴역했다. 전투·선택·성장·자료집·조각 보상은 동일한 원화를 사용하며 타이틀은 작은 빈손 SD와 다리 없는 괴물 무리가 등장하는 서울 게이트 전투 전경이다. 한서아의 이동·시설 상호작용은 유지하고 방향별 상체와 포고 스프링 표시를 제거했다. 이후 플레이어·인간형 NPC의 새 원화에도 이 기준을 적용한다. 새 원화 제작 전 [캐릭터 제작 가이드](../../assets/characters-sd/CHARACTER_GUIDE.md)를 읽는다.

## 원화와 본체

- 머리는 전체 높이의 약 60%, 몸통은 작게, 팔다리는 아주 짧게 만든다. 굵고 둥근 외곽선과 단순한 셀 채색을 사용한다. 살짝 위에서 보면서 얼굴이 보이는 빈손 전투 인형이다.
- 캐릭터성은 머리·색·마스크/고글·얼굴·작은 액세서리로 구분한다. 긴 다리, 사실적인 인체, 무기 든 포즈, 복잡한 주름과 발광 배경은 만들지 않는다.
- 필요한 원화는 투명 PNG **한 장**이다. 두 신발을 구분하고 밑창 높이를 맞춘다. 팔은 짧게 몸 옆에 붙인다. 바닥 그림자는 그리지 않는다. 프레임 시트·방향별 원화·부위 추출·Skeleton2D는 필요 없다.
- `assets/characters-sd/*_sd_01.png` 원본과 `provenance.json`·`provenance-02.json`의 내장 image_gen 전체 프롬프트를 보존한다. 송진우는 스타일 기준, 옛 인물 원화는 정체성·색상 참고다. 상위 `src/data/images.ts`에 연결한 후 `node scripts/export-godot-content.mjs`로 가져온다.
- `actors.json/characters/<id>`의 `rig: sd`, `sprite`, `portrait`를 설정한다. `feetTop`과 `footLift`는 짧은 발의 교대 들기, `handRegions`는 손/손목 변형 영역(정규화된 x/y/폭/높이), `handMotion`은 손끝 움직임, `bounce/cadence`는 공용 보행 조정이다. 모든 캐릭터에 같은 `HeroSDVisual`과 `sd_feet.gdshader`를 사용한다. 손목 위를 고정하고 손끝만 작게 변형하며, 대기 중에는 더 약한 손발 꼼지락을 사용한다.
- 생성물에 거의 투명한 점이 남아 있으면 검토한 `region: [x,y,width,height]`로 표시 영역만 지정한다. 원본 PNG는 수정하지 않으며 본체·메뉴 초상·발 기준·발사점에 같은 영역을 사용한다.
- 발을 원점으로 삼아 원래 비율의 `displayScale: 0.8`을 유지한다. 소켓·그림자도 함께 축소한다. 이동 한계와 표시 발사점은 현재 본체 경계를 사용하며 충돌 반경은 그대로다.
- 13명 플레이어는 `characters/<id>`, 한서아는 `npcs/hanSeoa` 프로필을 사용한다. 인간형의 높이·배율·바운스·주기·발 움직임·손 움직임 강도는 동일하며 개체별 차이는 PNG/표시 영역/손 영역뿐이다.
- `seoul-civilians-01`의 방향 수정본 v02 10명은 후속 사용자 승인으로 이름·배경·고유 능력과 함께 게임에 연결했다. 신규 10명은 기존 저장에서도 기본 해금으로 즉시 선택 가능하며 강태훈·박도준의 기존 Godot 뽑기 정책은 유지한다. `src/data/characters/index.ts`가 데이터 원본이고, 기존 선택·전투·성장·자료집·아바타·조각 목록에 같은 ID로 연결한다. 패시브는 기존 20스탯과 설치물 무기 피해 조건을 사용하며 별도 무기·개별 리그는 추가하지 않는다.

## 공용 최소 모션

| 상태 | 표현 |
| --- | --- |
| idle | 아주 작은 호흡과 약한 손끝·발끝 꼼지락 |
| move | 이동 거리/속도로 진행하는 바운스, 짧은 두 발 교대와 작은 손끝 움직임, 작은 좌우 기울기 |
| hit | 0.16초 흰색 플래시와 작은 표시 반동 |
| death | 0.42초 바닥으로 주저앉기·기울기·소멸 |
| attack reaction | 모든 공격에서 같은 0.12초 미세한 squash와 바운스 |

본체는 무기 각도를 따라 팔을 움직이지 않는다. 좌우 이동에만 반전하고 상하 이동은 마지막 좌우 방향을 유지한다. 전투 시간 변화량을 사용하므로 일시정지 중 모든 모션이 멈춘다.
부활 선택/결과로 전투가 멈춘 순간에는 본체의 0.42초 사망 표시만 끝까지 재생한다. 게임 시간·투사체·피해 계산을 진행하지 않는다. HP가 0인 체크포인트에서도 SD 본체의 사망 상태를 복원한다.

## 본체 / 투사체 / VFX

- `HeroSDVisual`: 빈손 캐릭터, 그림자, 공용 상태 반응만 담당한다.
- 캐릭터 주변에 검·총 등의 무기 스프라이트를 띄우지 않는다. 공격 유형별로 검기·탄·마력구·번개·폭발만 표시한다. 캐릭터 수×무기 수의 포즈 조합을 만들지 않는다. 무기 아이콘은 메뉴/상점 콘텐츠로 보존한다.
- 수호 표창의 궤도 공격은 무기 데이터의 `visual.sprite: guardianShuriken` 원화를 회전시키는 **공격 투사체**로 표시한다. 캐릭터가 들거나 휘두르는 무기 오브젝트는 만들지 않는다. 표시 궤도는 발 좌표 대신 본체 가시 경계 중심에 맞추고 위쪽 통과 지점에 머리 여백을 확보한다. 지상 궤도·피해 판정은 유지한다.
- `HeroCombatPresentation`이 발사 방향의 본체 경계에 투사체 크기와 화면상 2px를 더해 출발점을 계산한다. 투사체·섬광은 발사 순간 위치를 공유하고 고정한다. 피해·사거리·탄 충돌·실제 발사 좌표는 게임 규칙의 기존 값을 사용한다. 검기·번개·폭발은 기존 VFX 계층이 처리한다.
- `effects.json/projectiles/displayScale: 1.5`를 플레이어·적 탄, 궤도 표창, 폭격탄의 표시 크기에 공통 적용한다. 표시 출발점은 커진 원화를 반영하지만 충돌 반경·사거리·피해는 확대하지 않는다.
- 마력검은 실제 공격 원점과 부채꼴 각도에 맞춰 `slash_sweep.gdshader`가 시간에 따라 앞끝·곡선 폭·꼬리를 생성하고 수축하는 에너지 리본을 만든다. PNG 전체 회전은 사용하지 않는다. 공용 표시 주기는 0.30초이며 본체에 새 검 전용 모션을 넣지 않는다. 공격 대기 중 쿨타임은 0 아래로 누적하지 않고, 공격 후 계산된 주기로 재설정한다. 마력검 Lv.1의 기본 1초와 기존 공격속도·강화 보정은 유지한다.
- 연쇄번개는 연결마다 정확한 발신·수신 착탄점을 양 끝으로 삼는다. `displayScale: 1.7`은 굵기와 옆 가지에 적용하고 연결 길이는 두 점 사이 거리로 제한한다. `hopIndex`와 0.045초의 `hopDelay`, 연결 안의 0.05초 전파로 다음 대상에 순차적으로 이어지는 빛을 표시한다. 피해·연쇄 수·대상 선정에는 표시 지연을 적용하지 않는다.
- 지뢰와 마력장 발생기는 [새 지상 설치물 PNG](../../assets/visuals/structures/ground_installations_01.png)의 각 영역과 `actors.json/structures`의 바닥 앵커·접지/사선 그림자를 사용한다. [제작 프롬프트·출처](../../assets/visuals/structures/provenance.json)를 함께 보존한다. 마력장 색·불투명도는 비주얼 프로필에서 조절하며 파동은 3.4초 주기로 바닥 타원 안에서 천천히 퍼지고, 발생기와 파동 모두 전용 지면 계층에 놓아 모든 캐릭터·몬스터 뒤에 표시한다. 지뢰의 실제 설치·발동 규칙은 유지한다.
- 새 무기는 기존 콘텐츠와 공격 효과 정의를 확장한다. 새 본체 모션은 필요 없다. Wave cleanup은 남은 표시와 공격 반응을 정리한다.

## 샘플 확인

설정의 **SD 캐릭터 샘플**, 또는 `-- --open=sd-sample`로 연다. 대기·이동·피격·사망·공용 공격과 검기/산탄/회전 표창/번개 효과를 볼 수 있다. 확대 보기와 실제 915×412 아레나 배율을 함께 표시하며 샘플 화면은 전투·영구 저장을 쓰지 않는다. 실제 출동의 송진우도 같은 렌더러를 사용한다.

설정의 **전체 캐릭터·몬스터 모션** 또는 `tools/play.ps1 -Screen graphics`는 현역 인간형 14종과 몬스터 19종을 페이지별로 보여 준다. 방향·대기·이동·돌진·공격·피격·사망 버튼은 같은 공용 렌더러에 상태를 전달한다. 이 화면도 프로필/전투 저장을 쓰지 않는다. 게임 플레이와 밸런스 QA는 사용자가 담당한다.

새 캐릭터를 추가할 때 필요한 작업은 빈손 SD PNG 제작, 이미지 manifest 연결, `actors.json` 공용 SD 프로필 추가뿐이다. 공용 손발 모션과 공격 효과는 재사용한다. 옛 원화·리그의 생성 출처는 보존한다. 구형 Skeleton2D 파츠 렌더러와 재생성/조립 캡처 도구는 퇴역했으며 런타임·그래픽 샘플 모두 공용 단일 이미지 렌더러만 사용한다.

## 다리 없는 몬스터

19종 모두 `assets/monsters-sd/<id>_sd_01.png` 한 장을 사용한다. 큰 눈·둥근 몸·단순한 색 면과 작은 뿔/송곳니/균열로 귀여움과 위협을 함께 표현한다. 다리·발·보행 관절·인간형 팔을 추가하지 않는다. 날개·해파리 리본·연속된 뱀/점액 몸은 허용한다. 전체 프롬프트와 생성 출처는 같은 폴더의 `provenance.json`에 보존한다.

`actors.json/enemies/<id>`에는 `rig: legless`, PNG 경로, 검토한 표시 영역을 기록한다. `HeroGroundedVisual`과 `enemy_locomotion.gdshader`가 단일 이미지를 변형하며 균열체·질주체·군집 벌레의 옛 파츠 리그 코드는 제거했다. 지상 설치물은 같은 클래스의 별도 바닥 앵커 경로를 사용한다.

| 공용 이동 모션 | 개체 |
| --- | --- |
| hop · 통통 튀기/착지 압축 | 균열체, 철갑 점액, 분열 점액, 수문 방패령 |
| fly · 날갯짓/부유 | 군집 벌레, 신호등 나방 |
| float · 부유/그림자 변화 | 마탄 사수, 폭렬 포자, 치유 꽃해파리, 유리 해파리, 틈새 소환사, 그림자 잠복자, 사슬 문지기 |
| slither · 몸의 물결 | 질주체, 돌진 뿔뱀, 철엄니 점액, 동관 고리충 |
| bossFloat · 큰 부유 실루엣 | 게이트 파수꾼, 균열 여왕 |

개체별 주기·눌림·흔들림·표시 크기는 `src/data/enemyPresentation.ts`에서 설정한다. 공격 반응·피격 플래시·사망 수축/소멸은 공용이며 돌진 예고에는 압축, 돌진에는 전진 변형을 더한다. 내부 ID·공격 행동·능력치·충돌·웨이브·저장은 그대로다. 신규 적도 기존 모션 데이터를 선택하며 별도 리그와 ID 조건문을 추가하지 않는다.

## UI와 로비

새 UI의 제작 기준은 `UI_GUIDE.md`를 따른다. 프레임·버튼·기본 표면은 제작한 래스터 PNG와 9분할 이미지로 구성하고, `StyleBoxFlat`·SVG·코드 광택을 기본 미술 소재로 사용하지 않는다. 기능 텍스트는 실제 폰트로 렌더링하며 아이콘은 정보와 조작의 의미를 전달한다. 메인 타이틀에는 아이콘을 장식으로 채우지 않는다. 모든 새 UI는 `design/ui-image-skins`의 시안을 먼저 제시하고 사용자가 승인한 뒤 게임에 연결한다. 아래 기존 API·배치·팔레트 설명은 현재 런타임의 연결 기준이며 승인 전 시안 작업에서 런타임을 교체하지 않는다.

상점·로비·전투 HUD는 `root("arcade")`를 사용한다. 밝은 상품 표면·남색 안내판·주황 주요 버튼·청록 선택 표시를 구분하며 두께와 광택은 구조/버튼에 집중한다. `arcade_sheet`와 `arcade_button`의 product/dock/status/primary/secondary 역할을 사용한다. `HeroShopScreen`은 4칸 진열과 핵심/전체 스탯 표시를 맡고 구매·잠금·리롤은 기존 `HeroShop` 규칙을 호출한다. 잠금 상태와 구매 가능 여부는 독립적이다. 실제 글자는 Godot로 그리며 시안의 임의 마스코트/영문/생성 상품 원화를 사용하지 않는다. 첫 피드백 시안은 `design/seoul-arcade/`에 있다. 전체 화면 배치는 유지하며 서울 도시 작전풍 공통 색·폰트·아이콘을 사용한다. `HeroUI.root()` 기본 `light`와 상점/로비/HUD의 `arcade` 역할 구분은 유지한다.

`HeroUI.ink(parent,"scene")`는 남색 안내판/장면 배경 위 글자, 기본 text/muted는 밝은 상품 표면의 글자다. 팔레트는 루트 메타데이터에서 상속한다. 로비의 기존 배경 선택·밝기 보정·날씨를 유지하며 아이콘은 `assets/ui/urban-operation/facilities_01.png`의 개별 영역으로 표시한다. 버튼 상태 변화에 크기/위치 이동을 넣지 않는다.

전체 화면의 텍스트 배치는 공용 `HeroUI`를 사용한다. `fixed_text`/`text_block`의 마지막 options는 `align`, `valign`, `lines`, `overflow`(`none`/`wrap`/명시적 `ellipsis`)를 받으며 기존 호출과 반환 Label은 유지한다. 자동으로 박스 높이만큼 줄을 잘라 숨기지 않는다. `lines_height`로 실제 글꼴 높이·줄 간격을 예약하고, 제목/버튼/배지는 중앙, 본문은 좌측 상단, 숫자는 우측에 둔다. 본문14px·보조13px·버튼44px 이상은 915×412 기준이다. 프레임 소유의 여백/행/열로 아이콘과 수치를 묶고 모든 버튼 상태의 내용 여백을 동일하게 유지한다. 스크롤은 숫자와 세로 바 사이10px을 확보한다. 팝업의 제목과 하단 버튼을 먼저 배치하고 가운데 내용만 스크롤한다. 다른 메뉴의 새 미술 테마 확장과 텍스트 배치 수정은 별개다.

아이템55종의 `shopText: {effects: string[], penalties: string[]}`는 `src/data/items/index.ts` 작성 함수에서 생성하고 콘텐츠 내보내기에 함께 포함한다. 일반 스탯은 수치에서, 고유 발동은 조건/결과/횟수에서 작성한다. 카드 이름/효과는 각각2줄, 패널티1줄, 구매/잠금44px을 예약하고 남은 높이에 이미지를 맞춘다. 중요한 이름·효과·패널티·정확한 가격에는 말줄임을 사용하지 않는다. 전체 설명·가격·보유 수량/상한·구매 불가 사유는 상품 상세에서 제공한다. 긴 무기 설명은 카드 내부 스크롤에도 연결한다. 새 아이템은 이 짧은 문구와 원본 전체 설명을 함께 작성한다.

기존 아이템은 투명 배경의 `inventoryAtlasTransparent` 8×6 아틀라스를 사용한다. 로비 아이콘의 이전 출처 `assets/lobby-sd/provenance.json`와 신규 도시 작전풍 `assets/ui/urban-operation/provenance.json`, 아이템 배경 제거 `assets/ui/inventory-transparent-provenance.json`을 보존한다. 정적 시안 도구는 `tools/ui_preview.tscn -- --ui-preview --stress`이며 `Profile.writable:false`를 확인해야 실행한다. 캡처와 글꼴 기준 범위/겹침/스크롤바 진단을 기록하되 실제 캡처를 직접 확인해야 한다.

광화문은 `assets/environment-sd/gwanghwamun_sd_03.png` 한 장에 작은 세종/이순신/해치와 도로·포장·그림자를 함께 그린다. 궁궐 건축물은 사용하지 않는다. `maps/seoul`의 `fit: cover`로 비율을 유지하며 중앙 크롭하고 바닥을 반복하지 않는다. 기존 props/groundDetails와 source objects는 제거해 화면 전체를 이동 가능하게 한다. 새 도로 배치 가이드와 전체 프롬프트/출처는 같은 폴더의 `provenance-03.json`이며 이전 `provenance.json`도 보존한다. 균열체는 이전 대비 0.6배, 마력석은 1.3배를 유지한다. 연쇄번개의 현재 표시 규칙은 위의 ‘본체 / 투사체 / VFX’를 따른다. 연결 길이에 확대 배율을 곱해 실제 목표를 넘기지 않는다. 피해·사거리·충돌·획득 판정은 바꾸지 않는다.

로비 배경은 실제 진입 시 선택하고 새로고침 때 유지한다. `lobby_atmospheres.json`의 배경별 2~3개 레이어를 `HeroLobbyAtmosphere`가 화면 전체에 순환시킨다. 비/물결/안개, 바람/잎/먼지, 마력 입자/게이트 맥동, 눈/안개, 옥상 바람/안개를 낮은 불투명도로 사용한다. 합계 상한 160개, 입력 통과, 숨겨진 동안 처리 정지다.

## 서울 도시 작전풍 보강 (2026-10-02)

- 공용UI는 아이보리/청회색 표면, 남색 구조, 연보라 게이트, 민트 선택, 주황 주요 버튼을 사용한다. 지도 패턴은 헤더와 빈 삽화 영역에만 낮은 불투명도로 둔다. 본문/효과 뒤에는 장식하지 않는다. 기존 arcade/light 루트와 화면 배치는 유지한다.
- `fixed_text`/`text_block` 옵션의 `font_role`은 body/control/heading/number를 받는다. Paperlogy 본문·버튼, 해옹산스 제목, Barlow Condensed 숫자를 사용하고 실제 FontVariation+한글fallback 높이로 줄 공간을 예약한다. `apply_font`, `icon`, `fixed_icon`, `icon_button`, `icon_value`는 같은 역할을 공유한다. 반환 Label과 HUD 이름은 유지한다.
- `urbanIconsAtlas`는 8×4 투명 PNG다. 셀 크기는 실제 텍스처 크기에서 계산하며 순서/프롬프트는 `assets/ui/urban-operation/provenance.json`에 있다. 로비6종은 같은 폴더 `facilities_01.png`의 3×2영역을 사용한다. 의미가 모호한 메뉴와 효과 조건/횟수/패널티는 글자를 유지한다.
- 타이틀은 `title_battlefield_01.png`에 기능 글자를 구워 넣지 않는다. 네이티브 로고와 부제,19px 입장/이어하기를 얹는다. 기존 큰 캐릭터 초상은 타이틀에서 표시하지 않는다.
- 광화문03은 먼저 확정한 직각 도로 가이드를 따라 만든 새 원화다. 직선 세종대로/직교 교차로/횡단보도와 작은 세종·이순신·해치를 한 장에 포함한다. 모든 영역은 계속 통과 가능하며 cover/고정카메라와 이전원본을 유지한다. 출처는 environment-sd/provenance-03.json이다.
- 전투 BGM gain0.12, 일반 웨이브 간격÷0.7/상한×0.7, 기본드랍×1.2, 신규무기·설치물·강화가격×0.9내림은 원본src/data에서 내보낸다. 소환·분열·지정엘리트·보스수, 픽업단위, 저장형식은 유지한다.
