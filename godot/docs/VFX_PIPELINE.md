# VFX 공용 표시 파이프라인

2026-10-04 사용자 승인: 전투·로비·메뉴 전체의 화려한 SD 액션 VFX를 실제 적용했다. 빈손 SD, 다리 없는 몬스터, 고정 카메라/HUD, 승인 PNG UI·배치·폰트는 유지한다. 콘텐츠 수치·피해·공격 횟수·쿨타임·가격·새 오디오 연결은 변경하지 않는다.

## 전투

- `HeroRun.visual_event → HeroCombatPresentation → HeroTimedVfx/HeroProjectileVisual`이 표시를 소유한다. 기존 이벤트를 유지하고 `weaponId/stage/contextId/sourceActor/targetActor/angle`을 필요한 곳에 전달한다. 적 예고·설치 작동·픽업도 실제 발생 순간에만 발행한다.
- `data/visuals/effects.json`은 효과별 곡선·단계·색·입자·우선순위, `weapons`의 10종/default/hostile 궤적 프로필을 소유한다. `stageVariants`는 반복 마력장 피해와 설치 등장/포탑 발사/지뢰 발동을 구분한다. 표시 수치는 밸런스 원본에 넣지 않는다.
- 마력검은 한 셰이더의 주 검흔 + 보조 2개 + 잔광이다. 주/보조 종료는 0.18/0.20/0.23초, 전체 종료는 0.30초다. 모든 검흔은 실제 부채꼴·사거리 안에 있고 보조 표현은 피해나 소리를 발행하지 않는다.
- 번개는 양 소켓 사이의 절차적 연결이다. 살아 있는 소켓을 따라가며 죽거나 사라진 대상은 마지막 좌표를 사용한다. 이동하는 탄은 최대 8지점의 보간 리본을 사용한다. 적 탄의 표시 ID는 별도 카운터이며 저장할 때 제외하고 복원 후 재생성한다.
- 실제 원형 위험 예고는 동일한 반경의 원이다. 돌진은 실제 방향의 짧은 표식만 표시한다. 마력장·설치 접지·바닥 예고는 모든 배우보다 뒤에 있다.
- 효과 64개·입자 192개·투사체 표시 160개를 유지한다. 위험 예고/플레이어 피격은 장식보다 우선하며, 여유가 없으면 보조 광편을 줄인다.
- 표시의 유일한 전투 시계는 전달된 `dt`다. 풀 안의 Sprite/Material/입자 슬롯을 재사용하고 `clear()`에서 잔상·지연·참조를 제거한다. 입자는 엔진의 별도 벽시계 대신 최대 12개의 Sprite 슬롯을 같은 효과 시계로 계산한다. 일시정지·배속·지연·네이티브 프레임 캡처를 일치시키기 위한 최소 구현 예외이며 공용 별도 입자 시스템은 추가하지 않았다.

## 로비·메뉴

- `HeroUIEffects`는 화면과 별도의 입력 통과 장식층이다. `queue_effect(kind,payload)`로 성공한 UI 작업의 앵커/값을 잡고, `bind_view(view,key,enter)`로 새 화면의 앵커에 연결한다. `show_effect`는 즉시 연출, `advance_for_capture`와 `snapshot`은 저장 없는 표시 확인용이다.
- 클릭과 선택은 드래그 취소 이후 처리한다. 구매·성장·분기·리롤은 실제 성공 반환값을 확인한다. 잠긴 리롤 카드와 실패한 구매는 획득 효과를 받지 않는다.
- 같은 화면 refresh에서는 진입 애니메이션을 반복하지 않는다. 다른 화면으로 이동하면 이전 예약 효과를 취소한다. UI 입자는 48개·효과 20개·예약 16개 상한이며 반복 입력은 같은 영역의 반응으로 합친다.
- 선택/잠금 광택은 승인 PNG의 실제 9분할 가장자리와 알파에 제한한다. 아틀라스 UV를 정규화하고 원화 영역/스크롤 클립을 지킨다. 본문·가격·숫자 뒤에는 움직이는 광택을 추가하지 않는다.
- 로비는 기존 배경별 2~3층과 160개 입자 상한을 유지한다. 환경용 난수는 게임 난수와 분리하고 숨김·앱 중단 시 갱신을 중지한다.

## 소재·확인

새 캐릭터·몬스터·UI 일러스트는 만들지 않았다. 승인된 VFX/유리/선택/보급 PNG를 재사용하고 셰이더와 궤적 코드를 작성했다. 실제 캡처·소스 해시는 상위 `design/ui-image-skins/vfx-reborn-01/provenance.json`에 기록한다.

`tools/vfx_reborn_capture.tscn -- --ui-preview`는 실제 화면 클래스/렌더러에 움직이는 메모리 fixture를 넣어 915×412 프레임을 캡처한다. 저장 쓰기와 전투 시뮬레이션은 차단한다. `--scene=slash`처럼 한 장면만 다시 확인할 수 있다. 상위 `package_captures.py`는 네이티브 프레임을 수정하지 않고 애니메이션 WebP로 묶는다. 이 표시 확인은 실제 전투·실기기 성능 검사를 대신하지 않는다.
