# 길드 본부 경영 · Godot

현재 Godot 영구 저장과 출동 체크포인트는 v4이다. v3→v4는 길드 상태·작업·확정 보상을 보존하며 전문 재료 키와 회수 누적·출동 정산 ID를 추가한다. 구형 협회 스탯 강화만 환급 없이 0으로 이관한다. 재화·성장의 현행 규칙은 [ECONOMY.md](ECONOMY.md)를 따른다. v1 영구 저장은 기존 규칙대로 옛 길드만 기본 사무소로 초기화한다. 웹 저장을 자동 이전하지 않는다.

- src/data/guildManagement.ts: 공용 시설 8종, 연구, 직원, 탐험, 조합법, 비용·시간·생산·지원 수치. exporter로 Godot 콘텐츠에 가져온다. 보존 웹판 guild.ts는 유지한다.
- scripts/state/guild_state.gd: 영구 길드 기본 상태와 중첩 저장 검증.
- scripts/systems/guild_clock.gd: 인자로 받은 Unix 초 단위 시간으로 작업 완료·직원 레벨 상승 경계를 먼저 정산한다. 분수 생산량과 수령 전 24~72시간을 저장한다. 창고 상한과 작업 완료는 독립이고 근무 경험은 상한 뒤에도 쌓인다.
- scripts/systems/guild_rules.gd: 시설·무료 이동·채용·배치·교육·연구·탐험·제조·합성·상품 강화·등장 제외·옵션 선택·단축. 변경 전 과거 생산을 정산한다. 탐험과 제조는 시작 시 결과를 확정한다. Profile.guild_action이 명령 후 저장한다.
- scripts/systems/guild_support.gd: 출동 시작 때 상품 강화·무기 피해 성장·제외 목록·조합법·첫 클리어 지원을 복사한다. 캐릭터 돌파와 옵션도 초기 보정에 복사해 출동 중 변화가 소급되지 않는다.
- scripts/systems/item_crafting.gd: 편의점 조합은 재료와 결과를 한 번에 교체하고 스탯을 한 번 재계산한다. 기존 아이템 55종을 사용한다.

운영실 Lv.1과 빈 방 2칸, 직원 2명, 길드 코인 200·자재 100·자료 20으로 시작한다. 운영실 Lv.2에서 2층 6칸, Lv.3에서 3층 9칸, Lv.4에서 동시 공사 2개. 기존 v2의 열린 4/8칸은 최소 2/3층으로 보존한다. 연구는 별도 1개. 생산실은 코인과 캐릭터·무기·축복 지정 채널을 동시에 생산한다. 출동 성과는 자재·가속권만 길드에 지급한다. 협회 코인은 운영비로 쓰지 않는다.

## 화면 연결 상태

2026-10-05 고정 관리 패널 시안을 승인받아 `HeroGuildOfficeScreen`으로 연결했다. 층마다 3칸인 건물을 스크롤하고 시설을 선택하면 오른쪽 관리·직원·작업 탭을 연다. 운영실에서 전체 직원·작업·수령·작전 투입을 관리하며 편의점 전투 조합창은 유지한다. 화면 책임은 [GUILD_OFFICES.md](GUILD_OFFICES.md)를 따른다. 기존 걷는 시안과 원화는 보존한다.

승인 원화는 assets/ui/guild-management와 godot/assets/ui/guild-management에서 사용한다. data/visuals/guild.json이 시설 8종의 행 순서와 Lv.1·4·7·10 영역, 빈 방·공사·미증축 층 상태 영역을 기록한다. PNG 원본과 built-in image_gen 프롬프트·출처는 design/ui-image-skins/guild-management-01에 보존한다. exporter가 원화와 출처 사본을 다시 가져온다. 연결 복도·건물 외곽·승강기·난간은 승인된 `assets/ui/guild-walk` 원화를 사용하고 같은 manifest의 `walk` 영역에 기록한다.

시안: 위 폴더 index.html. Godot 독립 캡처: tools/guild_preview.tscn -- --ui-preview. 저장 확인: tools/guild_save_check.tscn -- --ui-preview. 두 도구는 메모리 상태만 사용하며 사용자 저장을 쓰지 않는다.

2026-10-04 경영 화면 연결 당시: 필수 스크립트 로드, v1→v2 이관·미래 형식 거부·중첩 손상 거부·분수 생산/직원 레벨 경계·창고 상한·직원 예약·확정 보상·재접속·중복 수령/옵션 비용 등 18개 저장 경계 확인 통과. 길드 실제 진입 경로를 오류 없이 로드했으며, 915×412 길드·조합 화면 8장과 상점 조합 버튼 1장을 런타임 에셋으로 캡처했다. 전체 테스트·수동 플레이·터치/모바일 실기기·청음은 하지 않았다.
