# Godot 전투 표시 구조

현재 기준은 [SD_PIPELINE.md](./SD_PIPELINE.md)다. 플레이어 4종과 길드 한서아는 빈손 SD PNG 한 장, 몬스터 19종은 다리 없는 PNG 한 장으로 표시한다. 공격 표현은 본체와 분리하고 캐릭터 주변에 검·총 스프라이트를 붙이지 않는다.

## 책임과 데이터

- `HeroWorld`는 고정 아레나 맞춤 배율, 단일 배경의 중앙 크롭, 마력석 픽업과 지갑 비행을 담당한다. 동상·도로·접지 그림자는 배경 원화에 포함되며 별도 조형물·차량·반복 타일 표시 경로는 없다. 전체 땅을 통과할 수 있는 규칙을 유지한다.
- `HeroCombatPresentation`은 플레이어·적·설치물의 표시 수명과 풀, 발 Y 정렬, 투사체 표시 좌표와 공격 이벤트를 연결한다. 지면→개체→투사체→공격 효과 순서다. 표시 상한은 공격·피해 계산과 무관하다.
- `HeroSDVisual`과 `sd_feet.gdshader`는 공용 대기·이동·손발 꼼지락·피격·사망·짧은 공격 반응을 처리한다. `actors.json/characters`와 `npcs`의 원화·검토 영역·손 영역·바운스·소켓을 사용한다.
- `HeroGroundedVisual`과 `enemy_locomotion.gdshader`는 단일 이미지의 점프·부유·날갯짓·몸 물결을 처리한다. 적 원화는 `actors.json/enemies`, 공용 모션 수치는 원본 `src/data/enemyPresentation.ts`에서 가져온다. 같은 표시 클래스의 설치물 경로는 고정 바닥 앵커와 접지/사선 그림자를 사용하고 몬스터 보행 변형을 받지 않는다.
- `HeroProjectileVisual`과 `HeroTimedVfx`는 실제 공격 데이터의 표시만 담당한다. `effects.json`은 표시 배율·시간·레이어·파티클 상한을 관리한다. 스탯·피해·충돌·사거리·저장 원본은 게임 시스템에 있다.

## 현재 공격 표현

- 마력검은 `slash_sweep.gdshader`가 0.30초 동안 곡선의 앞끝·폭·꼬리를 생성하고 수축하는 리본이다. PNG 전체를 회전시키는 이전 검기 경로는 제거했다. 공격 대기 중 쿨타임을 0 아래로 누적하지 않고 공격 후 계산된 주기로 재설정한다. 기본 1초와 공격속도·강화 보정은 유지한다.
- 일반·적 탄, 폭격탄, 수호 표창의 표시 크기는 `effects.json/projectiles/displayScale: 1.5`다. 수호 표창은 무기의 `visual.sprite`를 사용하는 공격 투사체이며 본체 가시 경계 중심의 표시 궤도와 머리 위 여백을 사용한다. 실제 지상 궤도·피해 판정은 바꾸지 않는다.
- 발사점은 현재 본체 경계 밖으로 투사체 크기와 기준 화면 2px 여백을 더해 계산한다. 투사체·섬광은 발사 순간 위치를 공유하고 고정한다. 지면의 실제 피해·충돌 계산에는 표시 보정을 넣지 않는다.
- 연쇄번개는 발신·수신 착탄점을 정확히 연결한다. 길이는 두 점 사이 거리이며 1.7배 강조는 굵기·옆 가지에만 적용한다. 현재 굵기는 22, hop 간격은 0.045초, 연결 내 전파는 0.05초다. `chain_link.gdshader`가 아틀라스 영역과 푸른 가장자리를 처리한다.
- 지뢰와 마력장 발생기는 `assets/visuals/structures/ground_installations_01.png`의 검토 영역을 사용한다. 마력장 발생기와 파동은 모든 캐릭터·몬스터 뒤의 지면 계층에 놓으며 3.4초 주기로 퍼진다. 색·불투명도·투영·속도는 `actors.json/structures`에서 조절한다.
- 표시 시간은 Run의 전투 시간 변화량이다. 일시정지 시 공용 모션·VFX·파티클이 멈추고 Wave 정리 이벤트가 남은 표시를 지운다. 부활/결과 화면에서는 본체의 짧은 사망 표시만 끝내며 전투를 진행하지 않는다.

## 확장과 확인 도구

새 인간형은 SD PNG·manifest·공용 SD 프로필, 새 몬스터는 다리 없는 PNG·manifest·공용 이동 모션 데이터만 추가한다. Skeleton2D/Bone2D·부위 아틀라스·개별 공격 리그는 다시 연결하지 않는다. 이미지 원본·프롬프트·출처는 상위 `assets`의 provenance 파일에 보존한다.

설정의 **전체 캐릭터·몬스터 모션** 또는 `-- --open=graphics`는 현행 공용 렌더러로 인간형 5종과 몬스터 19종을 확인한다. **SD 캐릭터 샘플** 또는 `-- --open=sd-sample`은 본체와 공격 효과를 함께 보여 준다. `tools/combat_feedback_capture.tscn -- --ui-preview`는 저장 쓰기와 전투 시뮬레이션 없이 실제 표시 클래스를 캡처한다. 과거 부위 리그/조립 초상 캡처 도구는 퇴역했다.

최근 실제 캡처는 `exports/combat-feedback`와 `design/ui-image-skins/combat-feedback`에 있다. 검증 범위와 미확인 사항은 상위 [FINAL_QA.md](../../docs/FINAL_QA.md)에 기록한다. 이 문서는 테스트·실기기·플레이 QA 완료를 의미하지 않는다.
