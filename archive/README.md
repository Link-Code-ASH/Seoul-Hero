# 퇴역 제작 자료

현행 SD/다리 없는 몬스터와 이미지 UI에서 쓰이지 않는 제작 자료입니다. 게임 런타임과 웹 이미지 glob의 바깥에 보관합니다.

- `retired-art/assets/`: 미사용 원화·초기 효과·축복·환경 소품. 폴더별 출처와 원본 PNG/WebP를 함께 보존합니다.
- `legacy-godot-visuals/`: 이전 파츠 리그·제작 소스·이전 바닥/조형물. `source/vfx-source.png`는 현재 VFX 추출 도구의 재료로 계속 보존합니다.
- `relocations-2026-10-03.json`: 원래 경로, 현재 경로, 크기, SHA-256. 복구할 때 해당 항목의 `archive` 파일을 `original` 경로로 되돌립니다.
- [윤하린 퇴역 기록](relocations-2026-10-12-yoon-harin.json): 사용자 삭제 요청에 따라 원화·Godot 사본·import 설정을 보존했습니다.

기존 프롬프트/출처 기록에 적힌 원래 경로는 이 목록으로 찾습니다. 승인 시안 및 갤러리 캡처, 현행 PNG 고해상도 원본은 각 원래 폴더에 유지합니다. 웹 원본에서 계속 사용하는 길드 포고 파츠·전투 이미지·CSS 프레임은 삭제하지 않습니다.
